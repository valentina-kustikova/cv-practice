# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

Библиотека фильтров изображений на Python. Все фильтры реализованы через базовые матричные
операции `numpy` над матрицей интенсивностей пикселей; OpenCV используется только для чтения
и записи файлов (`cv.imread`, `cv.imwrite`). Высокоуровневые функции обработки
(`cv.resize`, `cv.cvtColor`, `cv.Sobel` и т. п.) не применяются.

## Структура проекта

```
1_ImageProcessing/
├── main.py              # точка входа: разбор аргументов → чтение → фильтр → сохранение
├── cli.py               # cli_argument_parser(): аргументы командной строки
├── image_io.py          # read_image(), save_image(): чтение и запись изображений
├── requirements.txt     # зависимости (numpy, opencv-python)
├── filters/             # библиотека фильтров
│   ├── base.py          # абстрактный класс ImageFilter с фабричным методом get_filter()
│   ├── geometry.py      # Resize
│   ├── color.py         # RGB2GrayScale, Antique, FadeColor, Infrared
│   └── effects.py       # Matte, AgedPhoto, NeonEffect
├── README.md
└── data/
    ├── input_img/       # тестовые изображения
    └── output_img/      # результаты применения фильтров
```

## Запуск

Команды выполняются из папки `1_ImageProcessing`:

```bash
python main.py -i <входной_файл> -f <фильтр> [-o <выходной_файл>] [параметры фильтра]
```

| Аргумент | Описание |
|---|---|
| `-i`, `--input` | путь к входному изображению (обязательный) |
| `-f`, `--filter` | фильтр: `resize`, `grayscale`, `antique`, `fade`, `infrared`, `matte`, `aged`, `neon` (обязательный) |
| `-o`, `--output` | путь для сохранения результата (по умолчанию `output.jpg`); недостающие папки создаются автоматически |

Параметры фильтров (все необязательные):

| Параметр | Фильтр | По умолчанию | Описание |
|---|---|---|---|
| `--scale_x`, `--scale_y` | `resize` | `0.5`, `0.5` | коэффициенты масштабирования по осям, > 0 |
| `--alpha` | `fade` | `0.6` | доля исходного цвета, 0..1 (меньше — сильнее выцветание) |
| `--fade_level` | `fade` | `150` | уровень серого, с которым смешивается изображение, 0..255 |
| `--ir_gain` | `infrared` | `1.3` | усиление «инфракрасного» канала, > 0 |
| `--matte_radius` | `matte` | `0.8` | нормированный радиус овала, с которого начинается побеление, > 0 |
| `--matte_softness` | `matte` | `0.2` | ширина плавного перехода к белому (`0` — резкая граница) |
| `--noise` | `aged` | `0.02` | доля пикселей, закрашиваемых чёрным, и такая же доля, закрашиваемая белым, 0..0.5 |
| `--scratches` | `aged` | `15` | количество царапин, ≥ 0 |
| `--neon_gain` | `neon` | `2.0` | яркость подсветки контуров, > 0 |

Справка по всем аргументам: `python main.py -h`.

### Примеры запуска для каждого фильтра

**Выцветание (`fade`)** — с параметрами по умолчанию и с более сильным выцветанием к светлому серому:

python main.py -i data/input_img/cat.jpg -f fade --alpha 0.4 --fade_level 200 -o data/output_img/fade_strong_cat.jpg

python main.py -i data/input_img/cat.jpg -f infrared -o data/output_img/infrared_cat.jpg

## Последовательность работы скрипта

1. `cli_argument_parser()` (`cli.py`) — разбор аргументов командной строки (`argparse`).
2. `read_image()` (`image_io.py`) — чтение изображения. Если файл не существует,
   выбрасывается `FileNotFoundError`; если файл не удаётся декодировать как изображение — `ValueError`.
3. `ImageFilter.get_filter()` (`filters/base.py`) — фабричный метод создаёт объект нужного фильтра,
   `apply_filter()` применяет преобразование. Некорректные параметры фильтра приводят к `ValueError`.
4. `save_image()` (`image_io.py`) — сохранение результата; если запись не удалась,
   выбрасывается `IOError`.

Все исключения перехватываются в `main()`: выводится сообщение об ошибке, скрипт завершается с кодом 1.

## Архитектура фильтров

Абстрактный класс `ImageFilter` (`filters/base.py`) содержит абстрактный метод
`apply_filter(img, **kwargs)` и статический фабричный метод `get_filter(name)`, который по имени
фильтра возвращает объект нужного класса-наследника. Чтобы добавить новый фильтр, нужно написать
класс-наследник и добавить его в словарь внутри `get_filter()` и в список имён в `cli.py`.

## Математическое описание алгоритмов

Далее $I(x, y)$ — значение пикселя исходного изображения, $I'(x, y)$ — результирующего,
$W \times H$ — размеры изображения. OpenCV хранит каналы в порядке **B, G, R**, это учтено
в реализации. Все результаты обрезаются до диапазона $[0, 255]$:
$\mathrm{clip}(v) = \min(\max(v, 0), 255)$.

### 1. Изменение разрешения (Resize)

Интерполяция методом ближайшего соседа. Размер результата:

$$W' = \lfloor W \cdot S_x \rfloor, \quad H' = \lfloor H \cdot S_y \rfloor,$$

где $S_x, S_y > 0$ — коэффициенты масштабирования. Каждому пикселю результата ставится
в соответствие ближайший (слева сверху) пиксель исходного изображения:

$$I'(x', y') = I\left(\left\lfloor \frac{x'}{S_x} \right\rfloor,\ \left\lfloor \frac{y'}{S_y} \right\rfloor\right).$$

Индексы вычисляются сразу для всех строк и столбцов векторно, выборка выполняется
расширенной индексацией массива.

### 2. Оттенки серого (RGB2GrayScale)

Взвешенная сумма каналов (стандарт ITU-R BT.601), учитывающая разную чувствительность глаза
к цветам:

$$Y = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B.$$

Значение $Y$ округляется и записывается во все три канала.

### 3. Эффект «Антиквариат» / сепия (Antique)

Линейное преобразование цвета каждого пикселя:

$$
\begin{pmatrix} R' \\ G' \\ B' \end{pmatrix} =
\begin{pmatrix}
0.393 & 0.769 & 0.189 \\
0.349 & 0.686 & 0.168 \\
0.272 & 0.534 & 0.131
\end{pmatrix}
\begin{pmatrix} R \\ G \\ B \end{pmatrix}.
$$

Так как изображение хранится в порядке BGR, в коде используется та же матрица с переставленными
строками и столбцами (порядок B, G, R), а преобразование применяется ко всему изображению одним
матричным умножением.

### 4. Выцветание (Fade Color)

Линейная интерполяция между исходным пикселем и константным серым уровнем $C$
(параметр `--fade_level`) с весом $\alpha$ (параметр `--alpha`):

$$I' = \alpha \cdot I + (1 - \alpha) \cdot C, \quad \alpha \in [0, 1].$$

Контраст уменьшается в $1/\alpha$ раз, а все цвета сдвигаются к серому — изображение
выглядит выгоревшим.

### 5. Имитация инфракрасной плёнки (Infrared)

Имитация цветной ИК-плёнки (Kodak Aerochrome), которая записывает
ИК-излучение → красный слой, красный → зелёный, зелёный → синий. Настоящего ИК-канала
у обычной фотографии нет, поэтому его роль играет зелёный канал: растительность сильно отражает
ИК-излучение и на обычном снимке как раз зелёная. Преобразование каналов:

$$R' = \mathrm{clip}(k \cdot G), \quad G' = R, \quad B' = B,$$

где $k$ — усиление «ИК-канала» (параметр `--ir_gain`). В результате зелень становится
красной/розовой, а красные объекты — зелёными, как на настоящей ИК-плёнке.

### 6. Эффект маски (Matte)

Для каждого пикселя вычисляется нормированное эллиптическое расстояние от центра
$(x_c, y_c) = (W/2,\ H/2)$:

$$d(x, y) = \frac{(x - x_c)^2}{x_c^2} + \frac{(y - y_c)^2}{y_c^2}.$$

Линии $d = \text{const}$ — эллипсы, вписанные в кадр ($d = 1$ касается его краёв). Вес белого цвета:

$$w(x, y) = \mathrm{clip}_{[0,1]}\left(\frac{d(x, y) - r}{s}\right),$$

где $r$ — радиус, с которого начинается побеление (`--matte_radius`), $s$ — ширина плавного
перехода (`--matte_softness`). При $s = 0$ используется резкая граница: $w = [d > r]$.
Результат — смешивание с белым:

$$I' = (1 - w) \cdot I + w \cdot 255.$$

Внутри овала изображение не меняется, к краям плавно переходит в белый.

### 7. Состаренная фотография (Aged Photo)

Эффект состоит из трёх шагов.

**Шаг 1.** К изображению применяется сепия (п. 3).

**Шаг 2.** Добавляется шум в виде случайных чёрных и белых точек. Для каждого пикселя независимо
генерируется число $u \sim U(0, 1)$, после чего:

$$
I'(x, y) =
\begin{cases}
0, & u < p, \\
255, & u > 1 - p, \\
I(x, y), & p \le u \le 1 - p,
\end{cases}
$$

где $p$ — доля пикселей каждого вида (параметр `--noise`). Значение $0$ или $255$ записывается
во все три канала пикселя, поэтому точки получаются чёрными или белыми.

**Шаг 3.** Добавляются царапины. Выбираются $N$ случайных номеров столбцов
$x_k$ ($0 \le x_k \le W-1$, параметр `--scratches`), и каждый выбранный столбец
закрашивается светло-серым цветом:

$$I'(x_k, y) = I(x_k, y) * 0.7 + 255 * 0.3, \quad y = 0, \dots, H-1.$$

### 8. Неоновый эффект (Neon)

**Шаг 1.** Изображение переводится в оттенки серого (п. 2), получаем яркость $Y$.

**Шаг 2.** Градиент яркости оценивается конечными разностями, которые вычисляются сдвигом
массива на один пиксель:

$$G_x(x, y) = Y(x+1, y) - Y(x, y), \quad G_y(x, y) = Y(x, y+1) - Y(x, y).$$

В последнем столбце и в последней строке разность не определена, там принимается $G_x = 0$
и $G_y = 0$ соответственно.

**Шаг 3.** Модуль градиента показывает силу контура:

$$|G| = \sqrt{G_x^2 + G_y^2}.$$

**Шаг 4.** Контуры подсвечиваются неоновым циановым цветом на исходном затемненном изображении:

$$B' = G' = \mathrm{clip}(g \cdot |G|), \quad R' = 0,$$

где $g$ — усиление яркости (параметр `--neon_gain`).
