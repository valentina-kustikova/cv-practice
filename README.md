## Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

### Цели работы

*Цель работы* – разработать библиотеку фильтров на языке Python с использованием базовых матричных операций над изображениями в OpenCV.

### Задачи работы

Данная цель предусматривает выполнение следующих задач.

1. Реализовать функции обработки изображений.

   - Функция изменения разрешения изображения.
   - Функция перевода изображения в оттенки серого.
   - Функция применения фотоэффекта "антиквариат" (Antique) к изображению.
   - Функция выцветания (Fade Color) изображения.
   - Функция имитация пленки (например, инфракрасная пленка или другая).
   - Функция, обеспечивающая наложение эффекта маски (Matte). Этот эффект делает края
     фотографии белыми, создавая овальную рамку вокруг центральной ее части
     ([пример](http://pikabu.ru/view/yeffekt_vinetki_v_photoshop_437864)).
   - Функция добавления царапин и шума, обеспечивающих эффект состаренной фотографии.
   - Функция неонового эффекта (выделение контуров объектов и их последующее подсвечивание).

1. Реализовать скрипт с аргументами командной строки для запуска приложения, обеспечивающего
   применение заданных фильтров с их параметрами.
1. Подготовить README.md (Markdown) с описанием реализованных функций и инструкцией
   для запуска скрипта.

### Требования

Перечень требований к выполнению практической работы:

1. Язык разработки – Python.
1. При разработке фильтров можно использовать только базовые операции над изображениями.
   Например, для функции изменения разрешения нельзя использовать высокоуровневую функцию
   библиотеки OpenCV `resize()`.
1. Скрипт запуска должен реализовывать следующую последовательность действий:

   1. Разбор аргументов командной строки.
   1. Чтение входного изображения с обработкой возможных исключений.
   1. Применение фильтра к изображению.
   1. Сохранение результирующего изображения.

1. Скрипт должен сопровождаться файлом README.md с математическим описанием алгоритмов, используемых при реализации фильтров.

### Система оценивания работы

1. Наличие корректной реализации отдельной функции обработки изображения и демонстрация
    ее работоспособности – 2 балла (максимум – 16 баллов).
1. Наличие README, соответствующего требованиям, – 4 балла.
1. Максимальное количество баллов за практическую работу – 20 баллов.

### Общая последовательность действий

Выполнение работы предусматривает следующую последовательность действий.
1. Подготовить набор тестовых изображений.
1. Подготовить виртуальное окружение с необходимыми установленными библиотеками.
1. Реализовать функцию для разбора аргументов командной строки (функция `cli_argument_parser(…)`).
   Приложение принимает на вход флаг, обозначающий тип фильтра, набор параметров фильтров,
   а также название изображения, к которому применяется этот фильтр.
1. Реализовать функцию чтения изображения (функция `read_image(…)`). Функция принимает на вход
   название изображения, к которому применяется фильтр, и возвращает матрицу интенсивностей
   пикселей.
1. Реализовать заданный набор фильтров. Предлагается разработать абстрактный класс
   `ImageFilter`, содержащий статический фабричный метод `get_filter(…)` для создания
   конкретного типа фильтра и метод `apply_filter(…)` для применения преобразования
   к заданному изображению. Предполагается, что далее необходимо реализовать набор
   наследников, отвечающих каждому типу фильтра (например, `Resize`, `RGB2GrayScale`).


## Практическая работа №2. Классификация изображений с использованием библиотеки OpenCV

### Цели работы

**Цель работы** – разработать приложение для классификации изображений на основе подхода
"мешок визуальных слов" (bag-of-words, BoW) с использованием классических дескрипторов
и признаков, извлекаемых с использованием обученных сверточных нейронных сетей, а также
различных методов машинного обучения.

### Задачи работы

Данная цель предусматривает выполнение следующих задач:

1. Изучить и выбрать классические методы извлечения признаков из изображений для построения
   словаря визуальных слов. Разработать классы-обертки для извлечения признаков средствами
   выбранных методов, реализованных в библиотеке OpenCV.
1. Изучить и выбрать нейронные сети, обеспечивающие классификацию изображений. Понять параметры
   предварительной обработки изображений и постпроцессинга выхода для выбранных моделей.
   Разработать классы-обертки для извлечения признаков с заданного слоя выбранных нейросетей.
1. Реализовать скрипт для обучения и применения классификатора. Скрипт предусматривает три
   режима выполнения:

   - `train` – обучение модели на наборе данных.
   - `test` – тестирование классификатора на тестовой выборке.
   - `predict` – классификация одного изображения с возможностью визуализации BoW-гистограммы.

   Скрипт должен предусматривать следующую последовательность действий:

   1. Разбор аргументов командной строки.
   1. Выбор режима запуска.

      - В режиме `train` выполняется построение словаря визуальных слов с использованием метода K-средних,
        построение гистограмм для изображений тренировочной выборки, обучение выбранного классификатора
        и его сохранение.
      - В режиме `test` выполняется загрузка обученной модели и изображений тестовой выборки, оценка
        качества классификации с использованием загруженной модели.
      - В режиме `predict` выполняется загрузка обученной модели, вычисление BoW-гистограммы для входного
        изображения, классификация изображения, визуализация гистограммы и самого изображения.

   1. Подготовить README в формате Markdown с описанием реализованных классов и функций, а также
      инструкцией для запуска скрипта.

### Требования

Перечень требований к выполнению практической работы:

1. Язык разработки – Python.
1. Для извлечения классических локальных признаков необходимо использовать библиотеку OpenCV.
   Для извлечения признаков с слоев нейросетевых моделей – библиотеку PyTorch.
1. Результат работы скрипта зависит от режима запуска.

   - В режиме `train` результат – сохраненный файл модели, содержащий словарь визуальных слов
     и обученный классификатор.
   - В режиме test результат – точность классификации на тестовом наборе данных, опционально
     файл с результатами классификации тестовых изображений.
   - В режиме predict результат – предсказанный класс для входного изображения, а также график
     BoW-гистограммы и/или изображение с наложенной гистограммой.

1. Программное решение должно сопровождаться файлом README.md, который содержит мини-отчет
   о проделанной работе (постановка задачи, использованные алгоритмы, запуск приложения, программная
   реализация). Примечание: для каждой выбранной нейросетевой модели необходимо дать описание
   реализованных алгоритмов предварительной обработки изображений и обработки выхода сети.

### Система оценивания

1. Наличие возможности извлечения признаков с использованием классических методов – 5 баллов (максимум – 2 метода).
1. Наличие возможности извлечения признаков с использованием моделей глубокого обучения – 5 баллов (максимум – 2 модели).
1. Корректная реализация метода BoW – 10 баллов.
1. Наличие README в формате Markdown – 5 баллов.
1. Дополнительный балл за качество работы модели определяется по формуле: (10 * <процент качества>) баллов.
1. Предельный максимум – 40 баллов.

### Общая последовательность действий

1. Настройка виртуального окружения и установка необходимых библиотек (OpenCV, NumPy, scikit-learn,
   PyTorch, torchvision, matplotlib).
1. Подготовка данных (тренировочная и тестовая выборка, отдельные тестовые изображения)
   и нейросетевых моделей.
1. Реализация парсера аргументов командной строки с поддержкой трех режимов работы:

   - обучение модели на тренировочной выборке входного набора данных;
   - тестирование модели на тестовой выборке входного набора данных;
   - классификация одного изображения.

1. Реализация вспомогательных утилит и интерфейсов для работы с изображениями:

   - функция чтения изображения (`read_image`);
   - класс `FeatureExtractor` – абстрактный класс, обеспечивающий интерфейс для извлечения признаков
     из изображения (метод `detect_and_compute` принимает изображение и вычисляет дескрипторы);
   - классы `ClassicalExtractor` и `CnnExtractorBase` – абстрактные наследники класса `FeatureExtractor`
     для извлечения дескрипторов с использованием классических методов и нейросетевых моделей соответственно.

1. Реализация класса `ClassicalExtractor` и его наследников в соответствии с выбранными методами.
1. Реализация класса `CnnExtractorBase` и его наследников в соответствии с выбранными нейросетевыми моделями.
1. Реализация класса `BagOfWords`, обеспечивающего следующий функционал:

   - построение словаря визуальных слов с использованием метода K-средних;
   - вычисление нормализованной BoW-гистограммы для изображения;
   - обучение классификатора с поддержкой выбора метода машинного обучения;
   - предсказание класса изображения (метод `predict`);
   - сохранение и загрузку модели (методы `save_model` и `load_model`).

1. Реализация функций отображения результатов:

   - `plot_histogram` обеспечивает отрисовку BoW-гистограммы с возможностью сохранения в файл;
   - `visualize_image_with_histogram` обеспечивает совместную визуализацию изображения и его
     BoW-гистограммы.

1. Реализация фабричного метода `FeatureExtractor::create` для автоматического выбора нужного
   класса-наследника в зависимости от выбора метода извлечения признаков.
1. Реализация пайплайнов, отвечающих разным режимам запуска скрипта:

   - `run_train` – обучение модели на наборе данных;
   - `run_test` – запуск модели на тестовом наборе данных с возможностью подсчета точности;
   - `run_predict` – предсказание класса для одного изображения с визуализацией промежуточной информации.

1. Разработка интерфейса `DataLoader` для загрузки данных, которые хранятся в разных форматах.
1. Разработка наследника `<ВашНаборДанных>DataLoader` интерфейса `DataLoader` для загрузки
   заданного в задаче набора данных.
1. Интеграция всех разработанных компонентов в главной функции `main` с обработкой ошибок и логированием
   хода выполнения (пакет `logging`).
