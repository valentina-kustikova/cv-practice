## Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

### Цели работы

*Цель работы* – разработать библиотеку фильтров на языке Python с использованием базовых матричных операций над изображениями в OpenCV.

### Задачи работы

Данная цель предусматривает выполнение следующих задач.

1. Реализовать функции обработки изображений.

   - Функция изменения разрешения изображения.
   - Функция перевода изображения в оттенки серого.
   - Функция применения фотоэффекта "антиквариат" (Antique) к изображению.
   - Функция выцветания (Fade Color) изображения.
   - Функция имитация пленки (например, инфракрасная пленка или другая).
   - Функция, обеспечивающая наложение эффекта маски (Matte). Этот эффект делает края
     фотографии белыми, создавая овальную рамку вокруг центральной ее части
     ([пример](http://pikabu.ru/view/yeffekt_vinetki_v_photoshop_437864)).
   - Функция добавления царапин и шума, обеспечивающих эффект состаренной фотографии.
   - Функция неонового эффекта (выделение контуров объектов и их последующее подсвечивание).

1. Реализовать скрипт с аргументами командной строки для запуска приложения, обеспечивающего
   применение заданных фильтров с их параметрами.
1. Подготовить README.md (Markdown) с описанием реализованных функций и инструкцией
   для запуска скрипта.

### Требования

Перечень требований к выполнению практической работы:

1. Язык разработки – Python.
1. При разработке фильтров можно использовать только базовые операции над изображениями.
   Например, для функции изменения разрешения нельзя использовать высокоуровневую функцию
   библиотеки OpenCV `resize()`.
1. Скрипт запуска должен реализовывать следующую последовательность действий:

   1. Разбор аргументов командной строки.
   1. Чтение входного изображения с обработкой возможных исключений.
   1. Применение фильтра к изображению.
   1. Сохранение результирующего изображения.

1. Скрипт должен сопровождаться файлом README.md с математическим описанием алгоритмов, используемых при реализации фильтров.

### Система оценивания работы

1. Наличие корректной реализации отдельной функции обработки изображения и демонстрация
    ее работоспособности – 2 балла (максимум – 16 баллов).
1. Наличие README, соответствующего требованиям, – 4 балла.
1. Максимальное количество баллов за практическую работу – 20 баллов.

### Общая последовательность действий

Выполнение работы предусматривает следующую последовательность действий.
1. Подготовить набор тестовых изображений.
1. Подготовить виртуальное окружение с необходимыми установленными библиотеками.
1. Реализовать функцию для разбора аргументов командной строки (функция `cli_argument_parser(…)`).
   Приложение принимает на вход флаг, обозначающий тип фильтра, набор параметров фильтров,
   а также название изображения, к которому применяется этот фильтр.
1. Реализовать функцию чтения изображения (функция `read_image(…)`). Функция принимает на вход
   название изображения, к которому применяется фильтр, и возвращает матрицу интенсивностей
   пикселей.
1. Реализовать заданный набор фильтров. Предлагается разработать абстрактный класс
   `ImageFilter`, содержащий статический фабричный метод `get_filter(…)` для создания
   конкретного типа фильтра и метод `apply_filter(…)` для применения преобразования
   к заданному изображению. Предполагается, что далее необходимо реализовать набор
   наследников, отвечающих каждому типу фильтра (например, `Resize`, `RGB2GrayScale`).
