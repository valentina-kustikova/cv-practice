# Лабораторная работа №1

Небольшая консольная программа на Python, которая применяет фильтры к фотографиям. Делал в рамках курса по компьютерному зрению. Берёшь картинку из папки `Images`, выбираешь фильтр, и результат показывается в окне.

## Что умеет

Всего 9 пунктов в меню:

1. Resize. Изменение размера (ширину и высоту вводишь с клавиатуры).
2. Gray. Чёрно-белое изображение. Яркость считается по формуле из лекции: 0.299R + 0.587G + 0.114B.
3. Antique. Под старину: картинка слегка размывается через пирамиду (`pyrDown` и `pyrUp`), потом накладывается сепия и виньетка.
4. Fade. Выцветание, то есть смешивание с белым цветом.
5. Infrared. Псевдоинфракрасный эффект, делается через матрицу преобразования каналов.
6. Negative. Негатив (255 минус значение пикселя).
7. Matte. Фото в овале с размытыми краями на белом фоне.
8. Old. Старая плёнка: добавляется шум, падает контраст и рисуются случайные царапины.
9. Neon. Контуры находятся оператором Лапласа, красятся в неоновый цвет и немного "светятся" за счёт размытия.

## Что нужно для запуска

- Python 3
- OpenCV-python
- NumPy

Установка:

```
pip install opencv-python numpy
```

## Как запускать

1. Скачать проект:

```
git clone <ссылка на репозиторий>
cd <папка проекта>
```

2. Положить свои фотографии (jpg, jpeg, png или bmp) в папку `Images`.

3. Запустить:

```
python main.py
```

4. Ввести номер фотографии из списка, потом номер фильтра. Откроется окно с результатом, чтобы закрыть его, нужно нажать любую клавишу.

Пример:

```
Выберите фотографию:
1 - cat.jpg
2 - city.png
Введите номер фотографии: 1

Выберите фильтр:
1 - Resize
2 - Gray
...
9 - Neon
Введите номер фильтра: 9
```

## Структура

```
main.py      - запуск программы, показ результата
Filters.py   - все фильтры и меню выбора
Images/      - сюда класть фотографии
```

## Параметры, которые можно поменять

В `Filters.py` у некоторых фильтров есть настройки:

- `fade`: параметр `strenght` (от 0 до 1), чем больше, тем сильнее выцветание.
- `neon`: цвет линий (`B`, `G`, `R`) и `threshold`, от которого зависит, сколько контуров найдётся.

## Известные проблемы

- Папка `Images` должна существовать, иначе программа упадёт при старте.
