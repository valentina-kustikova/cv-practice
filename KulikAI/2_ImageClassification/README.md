## Постановка задачи и данные

По фотографии нужно определить архитектурную достопримечательность. Классические методы OpenCV и предобученные нейросети PyTorch извлекают локальные дескрипторы. Метод Bag of Visual Words (BoW) преобразует дескрипторы одного изображения в гистограмму фиксированной длины. По этой гистограмме классификатор предсказывает класс.

В каталоге `KulikAI/2_ImageClassification` находятся код и README работы. Данные распаковываются отдельно. Аргумент `--dataset` указывает на каталог, содержащий оба разбиения. Название каталога объекта служит меткой класса. [Скачать набор данных ННГУ](https://cloud.unn.ru/s/MPfwfnbB6HaSXLC)

```text
Dataset/
├── trainval/                     # обучение словаря и классификатора
│   ├── NNSUDataset/<класс>/
│   └── ExtDataset/<класс>/
└── test/                         # оценка сохранённой модели
    ├── NNSUDataset/<класс>/
    └── ExtDataset/<класс>/
```

В итоговом эксперименте использованы оба источника. Загрузчик рекурсивно читает JPG, JPEG, PNG, BMP, TIFF и WEBP. В режимах `train` и `test` пустые и нечитаемые файлы пропускаются с записью пути и причины в журнал. Флаги `--no-external` и `--exclude-other` позволяют отдельно провести эксперимент на основном источнике или без класса «Другие».

## Извлечение признаков

Каждый экстрактор возвращает матрицу `N × p`, где `N` — число локальных дескрипторов изображения, а `p` — размерность одного дескриптора.

| Экстрактор | Как получены признаки одного изображения |
|---|---|
| SIFT (`sift`) | OpenCV находит ключевые точки на полутоновом изображении. Гистограммы направлений градиента в окрестности каждой точки образуют дескриптор из 128 значений. |
| KAZE (`kaze`) | OpenCV находит ключевые точки в нелинейном масштабном пространстве полутонового изображения. Для каждой точки вычисляется 64-мерный дескриптор. |
| ResNet18 (`resnet18`) | Forward-хук считывает выход выбранного модуля. При окне 224×224 выход `layer4` имеет форму 512×7×7 и даёт 49 дескрипторов по 512 значений. |
| ResNet50 (`resnet50`) | Тот же способ извлечения. При окне 224×224 выход `layer4` имеет форму 2048×7×7 и даёт 49 дескрипторов по 2048 значений. |
| MobileNetV3 Small (`mobilenet_v3_small`) | Выход модуля `features` перед глобальным пулингом при окне 224×224 даёт сетку 7×7 и 49 дескрипторов по 576 значений. |
| DINOv2 ViT-B/14 (`dinov2`) | Трансформер делит окно 224×224 на сетку 16×16 патчей размером 14×14. После нормализации выхода выбранного блока в словарь поступают 256 векторов по 768 значений. Глобальный CLS-токен исключается. |

### Классические признаки фасадов

**SIFT.** На нескольких масштабах детектор ищет экстремумы разности гауссовых сглаживаний. Для каждой устойчивой точки определяется характерная ориентация. Окрестность разбивается на сетку 4×4, в каждой ячейке накапливается гистограмма из восьми направлений градиента. Отсюда размерность дескриптора — $4\times4\times8=128$. В `SIFTExtractor` по умолчанию `nfeatures=0`: число точек определяет детектор. [Описание SIFT в OpenCV](https://docs.opencv.org/4.x/da/df5/tutorial_py_sift_intro.html)

**KAZE.** Детектор строит масштабное пространство с нелинейной диффузией. Сглаживание зависит от локального перепада яркости, что помогает сохранять границы между участками фасада. В проекте `KAZEExtractor` использует порог отклика 0,001 и обычный 64-мерный дескриптор OpenCV. У SIFT и KAZE число найденных точек меняется от снимка к снимку. Однородная стена и стена с орнаментом могут дать существенно разные по размеру множества признаков. [Параметры KAZE в OpenCV](https://docs.opencv.org/4.12.0/d3/d61/classcv_1_1KAZE.html)

### Подготовка изображения для нейросетей

Для ResNet, MobileNet и DINOv2 изображение переводится из BGR в RGB. Меньшая сторона масштабируется до `round(window_size × 8/7)` с сохранением пропорций. Из центра вырезается квадрат со стороной `window_size`. В итоговом запуске это масштабирование до 256 пикселей по меньшей стороне и окно 224×224. Значения пикселей переводятся в диапазон [0, 1]. Каждый канал нормализуется по формуле $x'_c=(x_c-\mu_c)/\sigma_c$, где $\mu=(0.485,0.456,0.406)$ и $\sigma=(0.229,0.224,0.225)$. Сети работают в режиме `eval()` с отключённым вычислением градиентов. Обучение на фотографиях достопримечательностей изменяет словарь и классификатор.

### Выход CNN и выбор слоя

**ResNet18 и ResNet50.** Остаточные соединения передают признаки между блоками сети. В начале сети карта сохраняет мелкую пространственную сетку, в последних блоках одна позиция обобщает более крупную область входа. Например, на ResNet50 при окне 224×224 выход `maxpool` даёт 3 136 позиций с 64 каналами, а `layer4` — 49 позиций с 2 048 каналами. Смена слоя одновременно меняет содержимое признака, его размерность и число наблюдений для словаря. После такой смены требуется заново обучить словарь и классификатор. [He et al., Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)

**MobileNetV3 Small.** Компактная архитектура даёт ещё один вариант извлечения свёрточных признаков. Обёртка возвращает карту `base.features`. Перестановка осей превращает тензор `[1, 576, 7, 7]` в матрицу `[49, 576]`. Словарь получает отдельное наблюдение для каждой позиции карты. [Howard et al., Searching for MobileNetV3](https://arxiv.org/abs/1905.02244)

**Нумерация модулей.** У ResNet индекс 3 соответствует раннему `maxpool`, индекс 6 — `layer3`, индекс 7 — `layer4` (по умолчанию). Хук сохраняет карту до последующих операций, изменяющих тензор на месте. Каждая пространственная позиция карты даёт один дескриптор.

### Патчи DINOv2

ViT-B/14 получает последовательность из патчей 14×14. Механизм самовнимания позволяет признаку каждой позиции учитывать другие участки снимка. Например, на входе участок с окном занимает один или несколько патчей, а в позднем блоке его описание уже зависит от окружающего фасада. В реализации `forward_intermediates` возвращает нормализованную карту выбранного блока. Визуальному словарю передаются только пространственные позиции. [Oquab et al., DINOv2](https://arxiv.org/abs/2304.07193)

У DINOv2 `--layer` задаёт индекс блока трансформера от 0 до 11. В эксперименте взят последний блок, `blocks.11`. Сторона окна для DINOv2 должна быть кратна 14.

```bat
python main.py layers --extractor resnet50
python main.py layers --extractor dinov2
```

## Визуальный словарь и классификация

### 1. Построение словаря

Из дескрипторов `trainval` случайно выбирается до `--max-descriptors` векторов. K-means делит их на $K$ кластеров. На каждом шаге вектор относится к ближайшему центру по евклидову расстоянию, а центр пересчитывается как среднее векторов кластера. Полученные центры $\mu_1,\ldots,\mu_K$ образуют словарь. В итоговом запуске $K=180$, лимит выборки — 25 000 дескрипторов.


Реализация использует алгоритм Ллойда с десятью инициализациями и ограничением 100 итераций на каждую. Центр $j$ после назначения дескрипторов равен их среднему $\mu_j=|C_j|^{-1}\sum_{d\in C_j}d$. Из десяти решений K-means выбирает словарь с наименьшей суммой квадратов расстояний дескрипторов до их центров. Если дескрипторов меньше запрошенного числа кластеров, размер словаря уменьшается до числа доступных дескрипторов. Для обучения нужны как минимум два дескриптора и изображения двух классов. [Документация KMeans](https://scikit-learn.org/stable/modules/generated/sklearn.cluster.KMeans.html)

### 2. Кодирование изображения

Каждый из $N$ дескрипторов $d_i$ получает номер ближайшего слова $q(d_i)$. Нормализованная частота слова $j$ задаёт элемент гистограммы $h_j$.

$$
q(d_i)=\arg\min_{1\le j\le K}\|d_i-\mu_j\|_2^2,
\qquad h_j=\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}[q(d_i)=j].
$$

Для DINOv2 все 256 патчей каждого изображения участвуют в кодировании, а на вход классификатора поступает вектор из **180 частот**. Сумма частот равна единице. Для изображения без ключевых точек классический экстрактор даёт пустой набор дескрипторов, и BoW возвращает нулевую гистограмму.

Например, для словаря из четырёх слов последовательность назначений `[2, 0, 2, 3, 2]` даёт счётчики `[1, 0, 3, 1]` и вектор частот `[0.2, 0.0, 0.6, 0.2]`. Так можно сравнивать фотографии с разным числом ключевых точек. При любой перестановке тех же пяти назначений гистограмма останется прежней. Это ограничивает способность BoW различать фасады, элементы которых расположены по-разному.

### 3. Обучение и применение

По гистограммам и меткам `trainval` обучается SVM с RBF-ядром (`C=10`, `gamma="scale"`). Через `--classifier` также доступны `random_forest` (300 деревьев) и `knn` (5 соседей с весами по расстоянию). При тестировании каждое изображение кодируется по сохранённым центрам, после чего классификатор предсказывает его класс.

| Классификатор | Как принимается решение | Параметры реализации |
|---|---|---|
| SVM | RBF-ядро измеряет близость гистограмм. Чем меньше квадрат евклидова расстояния, тем больше значение ядра. Опорные векторы определяют границы классов. | `SVC`, `C=10`, `gamma="scale"` |
| Random Forest | Деревья разделяют изображения по значениям частот отдельных слов. Модель усредняет предсказанные деревьями вероятности классов. | 300 деревьев, `max_features="sqrt"`, `class_weight="balanced_subsample"` |
| k-NN | Для тестовой гистограммы находятся ближайшие обучающие гистограммы. Более близкие соседи получают больший вес при голосовании. | `n_neighbors=5`, `weights="distance"` |

### Размер представления и расход памяти

В итоговой конфигурации путь одной фотографии имеет вид `224×224 RGB → 256×768 дескрипторов → 180 частот → 1 метка`. Первое число 256 задаёт геометрия сетки патчей, а длину гистограммы 180 задаёт число кластеров. Например, если 16 патчей получили один номер слова, высота его столбца будет равна $16/256=0{,}0625$.

Матрица дескрипторов одного снимка DINOv2 занимает 768 КиБ в формате `float32` (256 × 768 × 4 байта). Только такие матрицы для 1 333 снимков занимают около 1 000 МиБ. На этапе обучения программа хранит дескрипторы в списке, объединяет их через `np.vstack` и затем выбирает до 25 000 строк для K-means. Таким образом, лимит сокращает работу кластеризации, но пиковый расход памяти включает и полную объединённую матрицу. При тестировании дескрипторы обрабатываются по одному изображению.

| Режим | Вход | Последовательность операций | Результат |
|---|---|---|---|
| `train` | Пути и метки из `trainval`, параметры экстрактора | Чтение → дескрипторы → обучение K-means → гистограммы всех прочитанных изображений → обучение классификатора | Один файл модели с параметрами, словарём и классификатором, а для нейросети также с весами |
| `test` | Модель и размеченный `test` | Загрузка экстрактора и словаря → предсказание для каждого файла → сопоставление с меткой каталога | Accuracy, отчёт по классам, опционально CSV и матрица ошибок |
| `predict` | Модель и одно изображение | Извлечение дескрипторов → гистограмма → предсказание → визуализация | Метка в консоли, график частот и фотография рядом с графиком |

`_load_descriptors` добавляет метку и признаки обучающего изображения только после успешного чтения. Так пропуск повреждённого JPEG сохраняет соответствие строк обучающей матрицы меткам. Прогресс и причины пропуска видны в журнале. Если в разбиении нет доступных для чтения файлов, обработка завершается с диагностическим сообщением.

Встроенная справка по параметрам обучения доступна командой `python main.py train --help`. Тесты запускаются из корня лабораторной работы командой `python -m unittest discover -s tests -v`. Проверяются обучение и сериализация BoW, размеры карт признаков, считывание тензора хуком до изменения ReLU на месте, загрузка ранее сохранённой ResNet и обработка нечитаемых файлов.

```bat
python main.py train --dataset "Dataset" --extractor dinov2 --window-size 224 --layer 11 --classifier svm --clusters 180 --max-descriptors 25000 --device auto --model-out models\dinov2_b14_bow_svm.joblib
```

При первом запуске DINOv2 загружает предобученные веса Meta в кеш PyTorch. Параметр `--device auto` выбирает CUDA при её доступности, иначе CPU. Параметр `--seed` по умолчанию равен 42. Файл `.joblib` содержит словарь, классификатор, веса экстрактора, номер блока и размер окна. При загрузке модель восстанавливает эти настройки автоматически.

### Тестирование

```bat
python main.py test --dataset "Dataset" --model models\dinov2_b14_bow_svm.joblib --device auto --save-results outputs\dinov2_b14_bow_test.csv --save-confusion-matrix outputs\dinov2_b14_bow_confusion.png
```

Команда выводит accuracy и отчёт по классам. В CSV одна строка соответствует одному изображению и содержит путь, истинный класс, предсказанный класс и признак правильного ответа. На матрице ошибок строки соответствуют истинным классам, столбцы — предсказанным. Оба файла сохраняются по указанным флагам.

### Предсказание для одной фотографии

```bat
python main.py predict --model models\dinov2_b14_bow_svm.joblib --image "Dataset\test\NNSUDataset\00_Other\20251124_134921.jpg" --output-dir outputs\predict
```

Приложение выводит класс в консоль и сохраняет `bow_histogram.png` с гистограммой и `image_and_histogram.png` с фотографией рядом с гистограммой. Флаг `--show` также открывает графики на экране.

## Аргументы командной строки

### Выбор данных и устройства

| Аргумент | Режим | Значение по умолчанию и назначение |
|---|---|---|
| `--dataset` | train, test | Обязательный путь к корню с `trainval` и `test` |
| `--device` | train, test, predict | `auto`. Для нейросетей также доступны `cpu`, `cuda`, `cuda:0`. K-means и классификатор выполняются в scikit-learn на CPU |
| `--no-external` | train, test | По умолчанию используются оба источника. Флаг оставляет только `NNSUDataset` |
| `--exclude-other` | train, test | По умолчанию включены все классы. Флаг исключает `00_Other` из выбранного разбиения |

### Обучение и выбор слоя

| Аргумент | По умолчанию | Назначение |
|---|---|---|
| `--extractor` | `sift` | Метод из таблицы экстракторов. В команде `layers` обязателен, доступны `resnet18`, `resnet50` и `dinov2` |
| `--window-size` | 224 | Сторона квадратного окна нейросети. Для DINOv2 нужна сторона, кратная 14 |
| `--layer` | ResNet 7, DINOv2 11 | Индекс модуля ResNet или блока DINOv2. Список имён и индексов выводит режим `layers` |
| `--no-pretrained` | Выключен | Инициализировать нейросеть случайными весами. В итоговом эксперименте использованы предобученные веса |
| `--clusters` | 128 | Число визуальных слов и длина гистограммы |
| `--max-descriptors` | 100 000 | Предельное число дескрипторов при обучении K-means. Значение 0 использует все доступные дескрипторы |
| `--classifier` | `svm` | Классификатор гистограмм. Альтернативы — `random_forest` и `knn` |
| `--seed` | 42 | Начальное состояние генератора при выборе дескрипторов и обучении K-means, а также Random Forest при его выборе |
| `--model-out` | `models/bow_model.joblib` | Выходной файл, в который `train` сохраняет модель |

### Оценка и визуализация

| Аргумент | Режим | Назначение |
|---|---|---|
| `--model` | test, predict | Обязательный путь к обученной модели |
| `--save-results` | test | Путь для записи CSV с полями `image`, `true_label`, `predicted_label`, `correct` |
| `--save-confusion-matrix` | test | Путь для сохранения матрицы ошибок в PNG |
| `--image` | predict | Обязательный путь к одной фотографии |
| `--output-dir` | predict | Каталог визуализаций, по умолчанию `outputs/predict` |
| `--show` | predict | Открыть графики в интерактивном окне. По умолчанию графики сохраняются в файлы |

## Результаты на тестовой выборке

**Лучший результат в проведённых экспериментах показала DINOv2 ViT-B/14 — 79,18% accuracy.** С признаками из последнего слоя (перед функцией активации), словарём из 180 визуальных слов и классификатором SVM удалось правильно классифицировать 1 864 из 2 354 фотографий. В экспериментах с другими моделями accuracy не превышала 61%.

### Метрики по классам

| Показатель | Значение |
|---|---:|
| Изображений / классов | 2 354 / 29 |
| Верных предсказаний / ошибок | 1 864 / 490 |
| Accuracy | **79,18%** |

| Усреднение по классам | Precision | Recall | F1 |
|---|---:|---:|---:|
| Все классы имеют равный вес (macro) | 0,85 | 0,86 | 0,84 |
| Вес пропорционален числу изображений (weighted) | 0,88 | 0,79 | 0,81 |

Точность класса (precision) показывает, какая доля предсказаний с этой меткой верна. Полнота (recall) показывает, какую долю реальных снимков объекта модель нашла. F1 — их гармоническое среднее. В macro F1 вклад Смольного собора с 14 тестовыми снимками такой же, как вклад Нижегородского кремля с 270 снимками. В weighted F1 вес каждого класса пропорционален этим числам.

Основной источник ошибок — пара кремлей. Из 270 фотографий Нижегородского кремля **149 отнесены к Московскому кремлю**. Эта пара в одном направлении дала около 30% всех ошибок (149 из 490). Для Московского кремля полнота составила 0,98, а точность — 0,18. Класс распознаётся почти на всех собственных фотографиях, но модель часто присваивает его другим объектам. Для здания Госбанка F1 составил 0,93 на 161 фотографии, для Чкаловской лестницы — 0,91 на 163.
