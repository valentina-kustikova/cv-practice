## 5. Математическое описание алгоритмов

Изображение рассматривается как матрица:

$$I \in [0,255]^{H\times W\times 3},$$

где третий индекс соответствует каналам B, G, R (порядок OpenCV).

### 5.1. Изменение разрешения (Resize)

Поддерживаются два метода интерполяции: `nearest` и `bilinear`.

Для каждой координаты результата вычисляются непрерывные координаты исходного изображения:

$$x_j = j\cdot\frac{W_s-1}{W_d-1},\qquad y_i = i\cdot\frac{H_s-1}{H_d-1}.$$

Обозначим:

$$x_0=\lfloor x\rfloor,\; x_1=\min(x_0+1,W_s-1),\qquad y_0=\lfloor y\rfloor,\; y_1=\min(y_0+1,H_s-1),$$

$$t_x = x - x_0,\qquad t_y = y - y_0.$$

**Nearest** — берётся ближайший пиксель:

$$I'(i,j) = I(\mathrm{round}(y_i),\,\mathrm{round}(x_j)).$$

**Bilinear** — линейная интерполяция по четырём соседям:

$$I'(i,j) = (1-t_x)(1-t_y)\,I(y_0,x_0) + t_x(1-t_y)\,I(y_0,x_1) + (1-t_x)\,t_y\,I(y_1,x_0) + t_x t_y\,I(y_1,x_1).$$

Все координаты и веса строятся как матрицы NumPy; поэлементного Python-цикла нет.

### 5.2. Grayscale

Для изображения BGR используется линейная комбинация каналов:

$$Y = 0.114\,B + 0.587\,G + 0.299\,R.$$

Получается одноканальная матрица интенсивностей размером $H\times W$.

### 5.3. Antique 

Применяется матрица коэффициентов сепии:

$$R' = 0.393\,R + 0.769\,G + 0.189\,B,$$

$$G' = 0.349\,R + 0.686\,G + 0.168\,B,$$

$$B' = 0.272\,R + 0.534\,G + 0.131\,B.$$

Для параметра силы $\alpha$ (0..1) результат смешивается с исходным изображением:

$$I' = (1-\alpha)\,I + \alpha\,I_{\text{sepia}}.$$

### 5.4. Fade Color

Пусть $C$ — заданный RGB-цвет выцветания, а $\alpha$ — сила эффекта. Тогда:

$$I' = (1-\alpha)\,I + \alpha\,C.$$

Это линейная интерполяция между исходным изображением и заданным цветом.

### 5.5. Film

Пусть $s$ — параметр `film-strength` (0..1). Сначала выполняется линейное смешивание каналов B и R и лёгкое подавление G:

$$B_f = (1-s)\,B + s\,R,$$

$$G_f = (1 - 0.15\,s)\,G,$$

$$R_f = (1-s)\,R + s\,B.$$

Затем каналы B и R дополнительно масштабируются:

$$B_f' = \mathrm{clip}(1.05\cdot B_f,\;0,\;255),$$

$$R_f' = \mathrm{clip}(0.95\cdot R_f,\;0,\;255).$$

Для имитации зерна добавляется гауссов шум:

$$I_f'' = I_f' + N(0,\sigma^2),$$

где $\sigma$ = `film-noise` (по умолчанию 8). Результат ограничивается диапазоном $[0,255]$.

### 5.6. Matte

Центральная область сохраняется, а края изображения постепенно смешиваются с белым цветом.

Введём нормированные координаты:

$$x,y\in[-1,1],\qquad r=\sqrt{x^2+y^2}.$$

Для порога $r_0$ (`matte-radius`) и мягкости $p$ (`matte-softness`):

$$t=\mathrm{clip}\!\left(\frac{r-r_0}{1-r_0},\;0,\;1\right),\qquad m = t^{\,p}\cdot s,$$

где $s$ — `matte-strength`. Итог:

$$I' = (1-m)\,I + m\cdot 255.$$

Таким образом, по краям получается мягкая белая рамка.

### 5.7. Царапины и шум

Основной шум задаётся гауссовой матрицей с дисперсией, зависящей от параметра `noise`:

$$\sigma = 255 \cdot \text{noise} \cdot 0.18,\qquad N_{ij}\sim N(0,\sigma^2).$$

Дополнительно генерируется поле царапин: для каждой царапины случайно выбираются координаты начала, длина (5–40% высоты) и малый угол отклонения от вертикали ($\pm5^\circ$). Толщина линии — 1 или 2 пикселя. Дополнительно добавляются мелкие точечные пятна с плотностью $0.04\cdot\text{scratch-density}$.

Итоговая маска царапин $S\in[0,1]^{H\times W\times 1}$ смешивается со случайным значением яркости $v\in[0.65,\,1.0]$:

$$I' = I + N + S\cdot(255\,v - I).$$

В завершение применяется `Antique` со `strength=0.6`, что придаёт изображению состаренный вид.

### 5.8. Neon

Изображение переводится в яркость:

$$Y = 0.114\,B + 0.587\,G + 0.299\,R.$$

Границы находятся простыми конечными разностями соседних пикселей (это вычислительно производиетельней оператора Собеля 
и даёт достаточное качество для эффекта свечения):

$$g_x(i,j) = Y(i,j+1) - Y(i,j),\qquad g_y(i,j) = Y(i+1,j) - Y(i,j).$$

Модуль градиента:

$$M = \sqrt{g_x^2 + g_y^2},\qquad E = \mathrm{clip}(M/255,\;0,\;1).$$

Для построения ореола свечения $E$ размывается усредняющим фильтром 3×3, который применяется несколько раз:

$$B_k(E) = \underbrace{\text{box3x3}\circ\dots\circ\text{box3x3}}_{k}(E).$$

Число итераций зависит от параметра `neon-blur`: для «мягкого» слоя $k_1 = \mathrm{round}(4\cdot\text{blur})$, для «широкого» — $k_2 = \mathrm{round}(10\cdot\text{blur})$.

Итоговое свечение:

$$G = \text{strength}\cdot\bigl(70\,E + 130\,B_{k_1}(E) + 180\,B_{k_2}(E)\bigr).$$

Свечение добавляется к синему и красному каналам (что даёт фиолетовый оттенок):

$$B' = B + G,\qquad R' = R + G,$$

после чего значения ограничиваются диапазоном $[0,255]$.
