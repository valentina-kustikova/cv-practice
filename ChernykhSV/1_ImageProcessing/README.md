## Математическое описание алгоритмов 

### 1. Изменение разрешения изображения.
==Что делает фильтр?==
Фильтр меняет разрешение изображения в соответствии с установленным параметром `scale`>0.
==Принцип работы:==
- Каждый новый пиксель проецируется в точку `(x,y)` в старом изображении
- Эта точка попадает внутрь квадрата 2x2 из четырех старых пикселей.
- Для каждой новой точки считаются веса: `wx = вес правого соседа`; ` wy = вес верхнего соседа`
- Веса используются для подсчета цвета нового пикселя:
	цвет на **верхней** грани: `top = a * (1-wx) + b * wx`
	цвет на **нижней** грани: `bot = c * (1-wx) + d * wx`
	**полученный** цвет пикселя: `out = top * (1-wy) + bot * wy`
В итоге получаем изображение с измененным разрешением.
==Команда запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f resize --scale 0.5
```

### 2. Перевод изображения в оттенки серого.
==Что делает фильтр?==
Меняет цвет изображения с цветного на одноцветный. Серое изображение - замена трех чисел каждого пикселя одним числом.
==Принцип работы:==
Цвет каждого пикселя изображения переводится в серый цвет: `gray = 0.299 * r + 0.587 * g + 0.114 * b`
В итоге получаем изображение, каждый канал которого имеет значение цвета = `gray`.
==Команда запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f grayscale
```

### 3. Фотоэффект антиквариат.
==Что делает фильтр?==
Придает изображению теплый оттенок. Параметр `sepia` от 0 до 1. Увеличение параметра соответствует увеличению фотоэффекта.
==Принцип работы:==
К каждому цветовому каналу каждого пикселя применяется некоторое преобразование:
`sepia_r = 0.393 * r + 0.769 * g + 0.189 * b`
`sepia_g = 0.349 * r + 0.686 * g + 0.168 * b`
`sepia_b = 0.272 * r + 0.534 * g + 0.131 * b`
В итоге получаем `out = original * (1.0 - strength) + sepia_bgr * strength` изображение с эффектом антиквариата.
==Команда запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f antique --sepia 0.7
```

### 4. Выцветание изображения.
==Что делает фильтр?==
Делает изображение более блеклым, менее контрастным и менее насыщенным. Параметры: `alpha` от 0 до 1 - сколько остается от оригинала; `fade-level` от 0 до 255 - к какому цвету все сходится (255 - белый, 0 - черный).
==Принцип работы:==
`res = img * alpha + level * (1.0 - alpha)` - линейная интерполяция между изображением и цветом со значением level.
В итоге получаем изображение с эффектом выгоревшем на солнце.
==Команда запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f fade --fade_level 100 --alpha 0.6
```

### 5. Имитация инфракрасной пленки.
==Что делает фильтр?==
Делает зеленые участки изображения ярко-красными, синие участки более светлыми. Параметр `infared_strength` от 0 до 1. 0 - оригинал без изменений, 1 - максимально инфракрасный эффект.
==Принцип работы:==
Каждый цветовой канал преобразуется определенным образом:
`ir = 0.4 * r + 0.9 * g + 0.1 * b`
`new_g = 0.5 * b + 0.5 * ir`
`new_b = 0.5 * r + 0.5 * ir`
В итоге получаем более светлое изображение.
==Команды запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f infrared --infrared_strength 0.7
```

### 6. Эффект маски.
==Что делает фильтр?==
Этот эффект делает края фотографии белыми, создавая овальную рамку вокруг центральной ее части. Параметры: `matte_radius` от 0 до 1 (по умолчанию 0.8) размер овала; `matte_softness` ≥ 0 (по умолчанию 0.2) - ширина зоны растушёвки.
==Принцип работы:==
Для каждого пикселя вычисляется квадрат расстояния до центра изображения: ``d = ((x - x_c) / x_c)^2 + ((y - y_c) / y_c)^2`` где `(x_c, y_c)` — центр, `d = 0` в центре, `d = 1` на границе вписанного эллипса, `d > 1` — в углах.
По `d` строится вес белого:
- при `softness = 0`: `weight = 1, если d > radius, иначе 0` (жёсткая граница).
- иначе: `weight = clip((d - radius) / softness, 0, 1)` (плавный переход).
В итоге получаем фотографию с рамкой по центру.
==Команды запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f matte --matte_radius 0.8 --matte_softness 0.2
```

### 7. Эффект состаренной фотографии, добавление царапин и шума.
==Что делает фильтр?==
Добавляет к изображению шум и тонкие светлые царапины. Параметры: `noise` от 0 до 0.5 (по умолчанию 0.05) - сила зерна; `scratches` ≥ 0 (по умолчанию 7) - количество царапин.
==Принцип работы:==
К каждому пикселю добавляется случайная величина из нормального распределения `res += np.random.normal(0, noise * 255, (h, w, 1)).astype(np.float32)`.
`scratches` линий со случайными параметрами, пиксели вдоль линии смешиваются с белым: `p = 0.85·p + 0.15·255`.
В итоге получаем состаренную фотографию.
==Команды запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f aged --noise_amount 0.05 --scratches_count 15
```

### 8. Неоновый эффект.
==Что делает фильтр?==
Выделяет контуры объектов на изображении и подсвечивает их бирюзовым цветом поверх оригинала. Параметр `neon_gain` > 0 (по умолчанию 1) - усиление контуров: чем больше, тем ярче свечение.
==Принцип работы:==
- Каналы B, G, R переводятся в яркость по BT.601: `Y = 0.114B + 0.587G + 0.299R`.
- Свёртка с ядрами Собеля `Gx, Gy` даёт две производные: по горизонтали и вертикали. Магнитуда: `M = sqrt(Gx² + Gy²)`.
- `M' = clip(M · neon_gain, 0, 255)` параметр управляет контрастом контуров.
- `M'` прибавляется к B и G каналам оригинала, возникает бирюзовый оттенок.
В итоге получаем фото с бирюзовыми контурами.
==Команды запуска:==
``` powershell
python main.py -i "picture\pic2.jpg" -o "picture\pic1_out.jpg" -f neon --neon_gain 1
```
