# Image Filters

Консольная программа для применения фильтров к изображению. Все фильтры написаны на `numpy` в векторизованном виде без циклов по пикселям. `OpenCV` используется для чтения и записи изображений, а также для рисования царапин в фильтре `age`.

## Использование

```
python script.py --filter <имя> --filter_args "<key=value,key=value>" --image <файл>
```

- `--filter`: один из `rescale`, `grayscale`, `antique`, `fade`, `ir`, `matte`, `age`, `neon`.
- `--filter_args`: параметры фильтра через запятую, например `width=200,height=150`. Значения разбираются как `int`, затем `float`, иначе остаются строкой. Необязательный аргумент, у всех параметров есть значения по умолчанию.
- `--image`: путь к исходному изображению.

Результат сохраняется в файл `<фильтр>_<имя изображения>` в текущей папке проекта.


## Примеры команд запуска
```
python script.py --filter rescale --filter_args width=320,height=240 --image cat.PNG
python script.py --filter antique --filter_args vignette=0.7,vignette_scale=0.85,feather=0.25 --image cat.PNG
python script.py --filter matte   --filter_args scale=0.7,feather=0.2 --image cat.PNG
python script.py --filter age     --filter_args sigma=15,seed=42      --image cat.PNG
python script.py --filter neon    --filter_args color=cyan,intensity=2 --image cat.PNG
python script.py --filter grayscale --image cat.PNG
```

### Rescale

Изменение разрешения методом ближайшего соседа без интерполяции. Размеры выходного изображения: `W' = width`, `H' = height`.

Коэффициенты масштаба:

```
sx = W / W'
sy = H / H'
```

Для каждого выходного индекса `x' ∈ [0, W')` и `y' ∈ [0, H')` ищется координата во входном изображении. Берутся центры пикселей (отсюда `+0.5` и `-0.5`):

```
x_in = (x' + 0.5) * sx - 0.5
y_in = (y' + 0.5) * sy - 0.5
```

Ближайший пиксель, с защитой от выхода за границы:

```
x_idx = clip(round(x_in), 0, W - 1)
y_idx = clip(round(y_in), 0, H - 1)

out[y', x'] = I[y_idx[y'], x_idx[x']]
```

Индексы строятся сразу для всех пикселей:

```
x_out = arange(W') -> (W',)
y_out = arange(H') -> (H',)

x_in  = (x_out[None, :] + 0.5) * sx - 0.5      # (1, W')
y_in  = (y_out[:, None] + 0.5) * sy - 0.5      # (H', 1)
```

Массивы индексов `y_idx` формы `(H', 1)` и `x_idx` формы `(1, W')` транслируются в `(H', W')`, а последняя ось (каналы) сохраняется. Результат имеет форму `(H', W', 3)`, выбор всех пикселей делается одной операцией.

`np.round` округляет половинные значения к ближайшему чётному (`0.5 -> 0`, `1.5 -> 2`).

### Grayscale

Перевод в оттенки серого взвешенной суммой каналов:

```
Y = 0.114 * B + 0.587 * G + 0.299 * R
```

Формула применяется сразу ко всему изображению через срезы каналов:

```
Y = I[..., 0] * 0.114 + I[..., 1] * 0.587 + I[..., 2] * 0.299
```

Каждый срез имеет форму `(H, W)`, поэтому результат одноканальный.

### Antique

Сепия с затемнением краёв (виньетка). Параметры: `vignette ∈ [0, 1]` — сила затемнения краёв (`0` — без виньетки, `1` — края полностью чёрные), `vignette_scale ∈ (0, 2]` — размер эллипса относительно изображения, `feather > 0` — ширина плавного перехода.

Сначала считается яркость `Y` (как в `grayscale`), затем каждый канал получается умножением `Y` на свой коэффициент:

```
B' = 0.43 * Y
G' = 0.74 * Y
R' = 1.07 * Y
```

`Y` умножается на скаляры целиком, затем три массива `(H, W)` собираются в `(H, W, 3)` через `np.stack(..., axis=-1)`.

Эллипс и нормированное расстояние считаются так же, как в `matte`:

```
cx = W / 2          a = W / 2 * vignette_scale
cy = H / 2          b = H / 2 * vignette_scale

dx = (x - cx) / a
dy = (y - cy) / b
d  = sqrt(dx² + dy²)
```

При `d <= 1 - feather` маска равна 1 (центр), при `d >= 1 + feather` равна 0 (край), при `d = 1` равна 0.5.

Сепия умножается на коэффициент яркости, который в центре равен 1, а на краях `1 - vignette`:

```
out = clip(sepia * (1 - vignette + vignette * mask), 0, 255)
```

Расстояние для всех пикселей считается так же как в `matte`:

```
dx = (x - cx)[None, :] / a        # (1, W)
dy = (y - cy)[:, None] / b        # (H, 1)
d  = sqrt(dx**2 + dy**2)          # (H, W)
```

Маска `mask` формы `(H, W)` расширяется до `(H, W, 1)` через `mask[..., None]` и умножается на сепию `(H, W, 3)` сразу по всем каналам.

### Fade

Выцветание: снижение насыщенности до 60% и сжатие контраста к среднему серому.

Для каждого канала `c ∈ {B, G, R}`:

```
1) насыщенность 0.6:
   S_c = Y + 0.6 * (I_c - Y)

2) сжатие контраста:
   out_c = 0.8 * S_c + 128 * 0.2
```

Формула считается над массивами `(H, W)` для каждого канала, затем каналы собираются через `np.stack(..., axis=-1)`.

---

### IR

Эффект инфракрасной плёнки: линейное преобразование каналов (`a * x + b`) со сменой красного и синего каналов местами.

```
B' = 0.9 * R
G' = 1.2 * G + 15
R' = 1.1 * B + 10
```

где справа стоят каналы исходного изображения. Затем:

```
out = clip(stack([B', G', R'], axis=-1), 0, 255)
```

Каждый выходной канал считается как операция над срезом `(H, W)`. Перестановка каналов получается за счёт того, что выходной `B'` строится из `I[..., 2]`, а `R'` из `I[..., 0]`.

---

### Matte

Эффект белой маски (виньетка): в центре изображение остаётся нетронутым, к краям плавно переходит в белый цвет. Область сохранения задаётся эллипсом.

Параметры: `scale ∈ (0, 1]` — размер эллипса относительно изображения, `feather > 0` — ширина плавного перехода.

Центр и полуоси эллипса:

```
cx = W / 2          a = W * scale / 2
cy = H / 2          b = H * scale / 2
```

Нормированное расстояние от центра (`d = 1` на границе эллипса):

```
dx = (x - cx) / a
dy = (y - cy) / b
d  = sqrt(dx² + dy²)
```

Маска (доля исходного изображения в пикселе):

```
m = clip((1 + feather - d) / (2 * feather), 0, 1)
```

Поведение маски:

```
d <= 1 - feather ->  m = 1      (исходный пиксель)
1 - feather < d < 1 + feather ->  m линейно падает от 1 до 0 (m = 0.5 при d = 1)
d >= 1 + feather ->  m = 0      (пиксель становится белым)
```

Смешивание с белым цветом:

```
out = clip(I * m + 255 * (1 - m), 0, 255)
```

Расстояние для всех пикселей считается без циклов:

```
x  = arange(W)
y  = arange(H)

dx = (x - cx)[None, :] / a        # (1, W)
dy = (y - cy)[:, None] / b        # (H, 1)
d  = sqrt(dx**2 + dy**2)          # (H, W)
```

Маска `m` формы `(H, W)` расширяется до `(H, W, 1)` через `m[..., None]` и применяется ко всем трём каналам разом.

### Age

Эффект состаривания: плёночное зерно и царапины. Параметры: `sigma >= 0` — сила шума, `seed` — зерно генератора случайных чисел (при заданном `seed` результат воспроизводим).

**1. Шум.** Если `sigma > 0`, к каждому пикселю добавляется гауссов шум:

```
n(y, x) ~ N(0, sigma²)
```

Шум один на пиксель и общий для всех трёх каналов (выглядит как яркостное зерно и не искажает цвет).

**2. Царапины.** Количество царапин выбирается случайно:

```
k ~ U{5, ..., 25}
```

Для каждой царапины случайно выбираются:

```
x0 ~ U{0, ..., W-1}          y0 ~ U{0, ..., H-1}          (начало)
D  = int( sqrt(H² + W²) )                                  (диагональ)
L  ~ U{ D // 20, ..., D // 3 }                             (длина: 5%–33% диагонали)
θ  ~ U[0, 2π)                                              (угол)

яркость a:  с вероятностью 0.7 : a ~ U[10, 20]             (светлая)
            с вероятностью 0.3 : a ~ U[-25, -10]           (тёмная)
```

Конец отрезка вычисляется как:

```
x1 = int(x0 + L * cos θ)
y1 = int(y0 + L * sin θ)
```

Отрезок шириной 1 пиксель со значением `a` рисуется в одноканальную маску `M` формы `(H, W)` (`cv.line`), которая изначально нулевая.

**3. Итог.**

```
out = clip(I + n + M, 0, 255)
```

Шум генерируется одним вызовом `rng.normal(0, sigma, (H, W, 1))`; ось размера 1 транслируется на три канала. Маска царапин `M` формы `(H, W)` приводится к `(H, W, 1)` через `M[..., None]` и также добавляется ко всем каналам сразу. Рисование царапин выполняется циклом `k` (5–25 штук).

### Neon

Неоновая подсветка контуров. Параметры: `color ∈ {"pink", "cyan", "green"}` и `intensity >= 0`. Цвета заданы в порядке BGR, как принято в OpenCV:

```
pink  = (149,  71, 255)
cyan  = (238, 255,  71)
green = ( 17, 255,   0)
```

**1. Яркость.** `Y` из фильтра `grayscale`, приведённая к `float32`.

**2. Градиент.** Центральные разности по горизонтали и вертикали; на границах изображения градиент равен нулю:

```
Gx(y, x) = Y(y, x+1) - Y(y, x-1)       при 1 <= x <= W-2,   иначе 0
Gy(y, x) = Y(y+1, x) - Y(y-1, x)       при 1 <= y <= H-2,   иначе 0
```
- Градиент считается срезами со сдвигом:

  ```
  Gx[:, 1:-1] = Y[:, 2:] - Y[:, :-2]
  Gy[1:-1, :] = Y[2:, :] - Y[:-2, :]
  
**3. Сила края.** Модуль градиента, нормировка на максимум и гамма-коррекция:

```
G = sqrt(Gx² + Gy²)
G = G / max(G)                (если max(G) > 0)
G = G ^ 0.9
```

Показатель степени меньше 1 слегка усиливает слабые края.

**4. Свечение.** Три гауссовых размытия `G` разной ширины (размер ядра `k` и `sigma`): даёт яркое свечение у самой линии, широкое мягкое гало вокруг неё.

```
glow_5  :  k = 5,   sigma = 2.5
glow_15 :  k = 15,  sigma = 4.0
glow_41 :  k = 41,  sigma = 11.0
```

Одномерное ядро (`r = k // 2`) нормируется так, чтобы сумма весов была равна 1:

```
w(i) = exp(-i² / (2 * sigma²)) / Σ exp(-j² / (2 * sigma²)),     i, j ∈ {-r, ..., r}
```

Двумерное гауссово размытие раскладывается на два одномерных прохода: сначала по строкам, затем по столбцам. Края изображения достраиваются повторением крайних значений:

```
tmp(y, x)  = Σ w(i) * G(y, x+i)
glow(y, x) = Σ w(i) * tmp(y+i, x)
```

Каждый проход реализован как сумма сдвинутых срезов массива с весами ядра:

```
padded_h = pad(G, ((0, 0), (r, r)), mode='edge')       # (H, W + 2r)
tmp     += padded_h[:, j : j+W] * w[j]                 # j = 0, ..., k-1

padded_v = pad(tmp, ((r, r), (0, 0)), mode='edge')     # (H + 2r, W)
glow    += padded_v[j : j+H, :] * w[j]                 # j = 0, ..., k-1
```

Срез с номером `j` соответствует сдвигу на `j - r`. Цикл идёт по элементам ядра (5, 15 или 41 раз), на каждом шаге обрабатывается сразу весь массив.

**5. Цветной неон.** Белая сердцевина линии берётся из `G`, а цвет из трёх свечений с разными весами:

```
neon = G * (255, 255, 255) + color * (0.8 * glow_5 + 0.4 * glow_15 + 0.35 * glow_41)
```

Умножение выполняется через broadcasting: `(H, W, 1) * (3,) -> (H, W, 3)`.

**6. Итог.** Неон умножается на интенсивность и накладывается на исходное изображение, которое остаётся без изменений:

```
out = clip(I + intensity * neon, 0, 255)
```
