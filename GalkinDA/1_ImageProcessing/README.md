# Практическая работа № 1. Фильтры изображений

## Файлы

- `main.py` — разбор аргументов, чтение файла, запуск фильтра и сохранение результата;
- `filters.py` — базовый класс `ImageFilter`, вспомогательные функции и фильтры;
- `images/` — исходные изображения и текстура;
- `requirements.txt` — зависимости проекта.

## Установка

```bash
cd GalkinDA/1_ImageProcessing
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Общий вид команды:

```bash
python3 main.py ВХОДНОЙ_ФАЙЛ ВЫХОДНОЙ_ФАЙЛ --filter ИМЯ_ФИЛЬТРА [параметры]
```

### Фильтры и параметры

| Имя фильтра | Назначение | Параметры |
| --- | --- | --- |
| `resize` | Изменение размера | `--new-h`, `--new-w` — новая высота и ширина, целые числа больше нуля, обязательны |
| `gray` | Перевод в оттенки серого | нет |
| `antique` | Сепия с тёмной виньеткой | нет |
| `fade` | Смешивание с блеклым цветом | `--alpha` от 0 до 1, по умолчанию `0.5`; `--fade-color R G B` — целые значения от 0 до 255, по умолчанию `200 200 200` |
| `film` | Имитация инфракрасной плёнки с зерном | `--grain-sigma` не меньше нуля, по умолчанию `10`; `--seed` |
| `matte` | Белая овальная виньетка | `--radius` — нормализованный радиус белой рамки, по умолчанию `1.25`; `--feather` — ширина плавного перехода, по умолчанию `0.4` |
| `scratches_texture` | Сепия, зерно и потёртости из текстуры | `--noise-sigma` (по умолчанию `15`); `--texture-alpha` от 0 до 1 (по умолчанию `0.65`); `--seed` |
| `neon` | Контуры с голубым свечением | `--sob-threshold` не меньше нуля, по умолчанию `50` |

Для `film` и `scratches_texture` параметр `--seed` задаёт неотрицательное целое число.
При одинаковых изображении, параметрах и `seed` результат повторяется.
Если `seed` не указан, шум генерируется заново при каждом запуске.

Примеры всех команд (результаты сохраняются в `results/`):

```bash
mkdir -p results
python main.py images/mediabasket.jpg results/resize.png --filter resize --new-h 1200 --new-w 1800
python main.py images/mediabasket.jpg results/gray.png --filter gray
python main.py images/mediabasket.jpg results/antique.png --filter antique
python main.py images/mediabasket.jpg results/fade.png --filter fade --alpha 0.4 --fade-color 200 200 200
python main.py images/bor_bridge_orig.jpg results/film.png --filter film --grain-sigma 10 --seed 10
python main.py images/mediabasket.jpg results/matte.png --filter matte
python main.py images/mediabasket.jpg results/scratches_texture.png --filter scratches_texture --noise-sigma 8 --texture-alpha 0.65 --seed 10
python main.py images/mediabasket.jpg results/neon.png --filter neon --sob-threshold 50
```

## Описание алгоритмов

Изображение представлено массивом `uint8` формы `(H, W, 3)` с каналами RGB,
где `H` — высота, `W` — ширина; `x` обозначает столбец, `y` — строку.
CLI принимает RGB-изображения. Результат `gray` имеет форму `(H, W)`.
Обработка выполняется операциями NumPy, Pillow используется для чтения, сохранения и коррекции EXIF-ориентации входных фотографий. В `scratches_texture` Pillow только читает файл текстуры; её размер и яркость обрабатываются собственными функциями.

Вычисления с яркостью выполняются в вещественных числах. Перед возвратом результата
значения ограничиваются диапазоном `0..255` и переводятся в `uint8`;
Resize сразу копирует исходные значения. `clip(a, low, high)` ограничивает `a`
указанным диапазоном. В записи шума `N(0, sigma^2)` ноль — среднее,
`sigma` — стандартное отклонение, `sigma^2` — дисперсия.

### 1. Resize

Размер изображения изменяется методом ближайшего соседа. Для каждого пикселя
результата с координатами `(y, x)` выбирается пиксель исходного изображения:

```text
old_y = floor(y * H / new_h)
old_x = floor(x * W / new_w)
result[y, x] = img[old_y, old_x]
```

`floor` округляет координаты вниз, индексы ограничиваются границами изображения.
Новые значения цвета не вычисляются: при увеличении пиксели повторяются,
при уменьшении часть исходных пикселей пропускается.

### 2. RGB2GrayScale

Для RGB-пикселя вычисляется компонента яркости Y из цветового пространства YUV:

```text
Y = 0.299R + 0.587G + 0.114B
```

Три цветовых канала заменяются одним значением яркости. Наибольший вес имеет
зелёный канал, наименьший — синий.

### 3. Antique

Эффект сепии задаётся матрицей преобразования цвета. Для каждого пикселя:

```text
|R'|   |0.393 0.769 0.189| |R|
|G'| = |0.349 0.686 0.168| |G|
|B'|   |0.272 0.534 0.131| |B|
```

Матрица применяется ко всем пикселям и придаёт изображению тёплый коричневый оттенок.
В коде RGB-векторы записаны строками, поэтому используется транспонированная матрица.

Затем применяется тёмная виньетка. Координаты нормируются относительно центра
и размеров изображения:

```text
cx = (W - 1) / 2, cy = (H - 1) / 2
nx = (x - cx) / max(cx, 0.5)
ny = (y - cy) / max(cy, 0.5)
d2 = (nx^2 + ny^2) / 2
vignette = 1 - 0.75 * d2
result = sepia * vignette
```

Маска одинаково умножается на все три канала: в центре яркость сохраняется,
к краям плавно уменьшается, в углах при ширине и высоте больше одного пикселя
остаётся 25% яркости сепии до ограничения значений диапазоном `0..255`.
Минимальный знаменатель `0.5` исключает деление на ноль для размеров в один пиксель.

### 4. Fade Color

Изображение смешивается с выбранным RGB-цветом `fade_color`:

```text
result = (1 - alpha) * img + alpha * fade_color
```

При `alpha = 0` сохраняется исходное изображение, при `alpha = 1` получается
сплошная заливка выбранным цветом. Промежуточные значения дают плавное выцветание.

### 5. Film

Эффект инфракрасной плёнки создаётся линейным преобразованием RGB-каналов:

```text
R' = -0.5R + 4.5G - 2.3B
G' = R - 2G + 2B
B' = -0.6G + 1.6B
```

Такое преобразование меняет цветовые соотношения: зелёные участки получают
красный оттенок. К преобразованному изображению добавляется зерно:

```text
epsilon ~ N(0, grain_sigma^2)
result = clip([R', G', B'], 0, 255) + epsilon
```

Шум независим для каждого пикселя и канала. Это стилизация под инфракрасную плёнку,
а не точная модель.

### 6. Matte

Строится эллипс с центром изображения и полуосями `rx`, `ry`.
Для каждого пикселя вычисляется нормированное расстояние `d` до центра:

```text
cx = (W - 1) / 2, cy = (H - 1) / 2
rx = max(cx, 0.5), ry = max(cy, 0.5)
d = sqrt(((x - cx) / rx)^2 + ((y - cy) / ry)^2)
w = clip((radius - d) / feather, 0, 1)
```

Минимальная полуось `0.5` исключает деление на ноль для изображения шириной
или высотой в один пиксель. Маска смешивает изображение с белым фоном:

Параметр `radius` определяет нормализованное расстояние от центра, начиная с которого изображение становится полностью белым. Параметр `feather` определяет ширину плавного перехода. При `d <= radius - feather` исходные пиксели сохраняются, при `d >= radius` заменяются белыми. Между этими значениями выполняется линейное смешивание.

```text
result = w * img + (1 - w) * 255
```

При стандартных параметрах `radius=1.25`, `feather=0.4` исходное изображение сохраняется при `d <= 0.85`.
При `0.85 < d < 1.25` оно плавно осветляется, а при `d >= 1.25` заменяется белым цветом.

### 7. ScratchesTexture

Состаривание состоит из трёх этапов: сепия, зерно и потёртости.
Сначала применяется матрица сепии из Antique, без виньетки.
Затем добавляется гауссовский шум:

```text
epsilon ~ N(0, noise_sigma^2)
photo = clip(sepia + epsilon, 0, 255)
```

После применения сепии значения также ограничиваются диапазоном `0..255`.
Шум имеет форму `(H, W, 1)`: одно значение добавляется ко всем трём каналам пикселя.

Потёртости берутся из `images/tekstyra_small.jpg`. Текстура подгоняется под размер
фотографии методом ближайшего соседа и переводится в яркость.
Затем она накладывается на фотографию:

```text
mask = texture / 255
screen = 255 - (255 - photo) * (1 - mask)
result = (1 - texture_alpha) * photo + texture_alpha * screen
```

Чёрные участки текстуры не меняют фотографию, светлые создают потёртости.
Параметр `texture_alpha` задаёт силу эффекта: при `0` текстура не влияет
на результат, при `1` накладывается полностью. Параметр `noise_sigma` задаёт
силу зерна; при `0` зерно отсутствует.

### 8. Neon

Сначала вычисляется серое изображение по формуле из раздела 2. Далее применяется
линейная фильтрация с дублированием крайних пикселей:

```text
I'(x, y) = sum_i sum_j F(i, j) * I(x + i, y + j)
```

Ядро применяется без отражения. Смещение `i` идёт по
столбцам, `j` — по строкам. Контуры определяются двумя ядрами Собеля:

```text
Kx = [-1  0  1]     Ky = [-1 -2 -1]
     [-2  0  2]          [ 0  0  0]
     [-1  0  1]          [ 1  2  1]
```

`Kx` выделяет изменения яркости по горизонтали, `Ky` — по вертикали.
Из результатов фильтрации `Gx` и `Gy` вычисляется величина градиента:

```text
G = sqrt(Gx^2 + Gy^2)
edges = 1, если G > sob_threshold, иначе 0
```

Для свечения маска контуров усредняется ядром `ones(5, 5) / 25`:

```text
glow = convolve(edges, ones(5, 5) / 25)
strength = clip(edges + 2 * glow, 0, 1)
result = strength * [0, 255, 255]
```

Затем создаётся широкий ореол. Копия `strength` усредняется 45 раз
ядром `ones(7, 7) / 49`:

```text
halo = strength
halo = convolve(halo, ones(7, 7) / 49)  # повторяется 45 раз
strength = maximum(strength, 1.2 * halo)
neon = strength * [0, 255, 255]
```

`maximum` выбирает большее значение для каждого пикселя.
Результат — голубые контуры с мягким широким свечением на чёрном фоне.

В итоге применяем `neon` к исходному изображению с `neon_alpha = 0.5`
```
neon_aplha = 0.5
result = base + neon_aplha * neon
```
