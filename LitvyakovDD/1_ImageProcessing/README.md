# Обработка изображений

## Запуск

```text
python main.py --image ИМЯ_ФАЙЛА --filter ФИЛЬТР [параметры]
```

Если аргументы не переданы, программа выводит краткую справку:

```text
python main.py
```

`--image` и `--filter` обязательны. В `--image` передаётся имя файла из папки `img`.

## Параметры

| Аргумент | Описание |
| --- | --- |
| `--image ИМЯ_ФАЙЛА` | Имя изображения в папке `img`. |
| `--filter ФИЛЬТР` | Фильтр: `resize`, `grayscale`, `antique`, `fade`, `film`, `matte`, `scratches` или `neon`. |
| `--width ЧИСЛО` | Новая ширина для `resize`. |
| `--height ЧИСЛО` | Новая высота для `resize`. |
| `--strength ЧИСЛО` | Сила эффекта для `antique`, `fade`, `film` или `scratches`; диапазон `[0, 1]`. |
| `--matte-radius-x ЧИСЛО` | Радиус рамки `matte` по X; должен быть больше нуля (по умолчанию `0.8`). |
| `--matte-radius-y ЧИСЛО` | Радиус рамки `matte` по Y; должен быть больше нуля (по умолчанию `0.8`). |
| `--matte-softness ЧИСЛО` | Мягкость перехода `matte`; неотрицательное число. При нуле переход резкий. |
| `--neon-gain ЧИСЛО` | Усиление свечения для `neon`; должно быть больше нуля. |
| `--neon-brightness ЧИСЛО` | Яркость исходного изображения под неоном; диапазон `[0, 1]`, по умолчанию `0.4`; меньшее значение сильнее затемняет. |

## 1. resize

Изображение масштабируется до размеров `(W', H')`, и каждый пиксель выходного изображения берётся из соответствующего положения на исходном изображении.

Пусть исходное изображение имеет размеры `(W, H)`, а целевое — `(W', H')`. Для координат пикселя на выходе:

```text
x_out = i,  i = 0..W'-1
y_out = j,  j = 0..H'-1

x_in = floor(i * W / W')
y_in = floor(j * H / H')
```

Тогда:

```text
I'(j, i) = I(y_in, x_in)
```

То есть координаты отображаются в исходное изображение с сохранением RGB-компонент.

## 2. grayscale

Яркость вычисляется по формуле:

```text
Y = 0.299R + 0.587G + 0.114B
```

После этого каждый канал заменяется на это значение:

```text
I'(x, y, c) = Y(x, y),  c ∈ {R, G, B}
```

Затем значения ограничиваются диапазоном `[0, 255]`.

## 3. antique

Сепия получается линейным преобразованием RGB-каналов:

```text
[ R_sep  ]   [0.272  0.534  0.131] [R]
[ G_sep  ] = [0.349  0.686  0.168] [G]
[ B_sep  ]   [0.393  0.769  0.189] [B]
```

После этого выполняется смешение с исходным изображением:

```text
I' = (1 - s)I + sI_sep
```

где `s ∈ [0,1]` — параметр `strength`.

## 4. fade

Фильтр ослабляет насыщенность и добавляет светлый оттенок. Сначала вычисляется яркость `Y`:

```text
Y = 0.299R + 0.587G + 0.114B
```

Далее:

```text
I1 = I * (1 - 0.55s) + Y * (0.55s)
I' = I1 * (1 - 0.18s) + 245 * (0.18s)
```

где `s` — параметр `strength`.

Так изображение становится светлее и менее контрастным, но сохраняет общий тон.

## 5. film

Эффект плёнки задаётся преобразованием каналов:

```text
B' = 0.65B + 0.35R
G' = 0.75R + 0.25G
R' = 1.35G - 0.25B + 20
```

После этого новое изображение смешивается с исходным:

```text
I' = (1 - s)I + sI_film
```

где `s` — параметр `strength`.

## 6. matte

Фильтр осветляет края изображения белым цветом, создавая мягкую овальную рамку.
Для точки `(x, y)` вычисляется нормированное расстояние:

```text
d(x, y) = (x - cx)^2 / (cx * matte_radius_x)^2
        + (y - cy)^2 / (cy * matte_radius_y)^2
```

## 7. scratches

Фильтр накладывает текстуру `inner/Scratches.jpg` поверх исходного изображения.
Если текстура больше изображения, лишняя область обрезается по центру; если
текстура меньше, она растягивается до размера кадра. Параметр `strength`
задаёт силу текстуры в результате:

```text
I' = (1 - s)I + sT
```

## 8. neon

Сначала изображение переводится в серое `G`. Для каждого пикселя
вычисляются горизонтальный и вертикальный градиенты с помощью оператора Собеля.

Исходное изображение затемняется перед добавлением свечения, интенсивность свечения и границы для Собеля задаются параметрами `neon_brightness=0.8` и `neon_gain=40` 



## Примеры запуска

```text
python main.py --image unn.jpg --filter resize --width 800 --height 800
python main.py --image unn.jpg --filter grayscale
python main.py --image unn.jpg --filter antique --strength 0.8
python main.py --image unn.jpg --filter fade --strength 0.8
python main.py --image unn.jpg --filter film --strength 0.8
python main.py --image unn.jpg --filter matte --matte-radius-x 0.6 --matte-radius-y 0.6 --matte-softness 0.2
python main.py --image unn.jpg --filter scratches --strength 0.4
python main.py --image unn.jpg --filter neon --neon-gain 1 --neon-brightness 0.9

python main.py --image line.jpg --filter neon --neon-gain 2 --neon-brightness 0.9
```

Результат сохраняется в папке `result` в формате `<имя>_<номер фильтра>.<расширение>`, например `result/img_3.jpg`.
