# Обработка изображений

## Запуск

```text
python main.py --image ИМЯ_ФАЙЛА --filter ФИЛЬТР [параметры]
```

Без аргументов программа выводит краткую справку по аргументам:

```text
python main.py
```

`--image` и `--filter` обязательны при обработке. В `--image` указывается имя файла, например `img.jpg`.

## Параметры

| Аргумент | Описание |
| --- | --- |
| `--image ИМЯ_ФАЙЛА` | Имя изображения в папке `img`. |
| `--filter ФИЛЬТР` | Фильтр: `resize`, `grayscale`, `antique`, `fade`, `film`, `matte`, `scratches` или `neon`. |
| `--width ЧИСЛО` | Новая ширина для `resize`; целое число больше 0. |
| `--height ЧИСЛО` | Новая высота для `resize`; целое число больше 0. |
| `--count ЧИСЛО` | Количество царапин для `scratches`; целое число от 0 и выше. |
| `--strength ЧИСЛО` | Сила эффекта для `antique`, `fade`, `film`, `matte` или `neon`; от 0 до 1. По умолчанию: `1.0` для первых `antique`, `fade`, `film`, `0.8` для `matte`, `0.7` для `neon`. |
| `--threshold ЧИСЛО` | Порог поиска контуров для `neon`; от 0 и выше. По умолчанию: `70`. |
| `--brightness ЧИСЛО` | Яркость фона для `neon`; от 0 до 1. По умолчанию: `0.4`. |

Для `resize` обязательно указать `--width` и `--height`. Для `scratches` обязательно указать `--count`.

## Фильтры

- `resize` — увеличивает или уменьшает изображение до заданных ширины и высоты, копируя цвета пикселей исходного изображения.
- `grayscale` — заменяет цвет каждого пикселя яркостью, рассчитанной из синего, зелёного и красного каналов.
- `antique` — пересчитывает цветовые каналы по формулам сепии и смешивает результат с исходным изображением.
- `fade` — частично обесцвечивает изображение и добавляет светлый оттенок.
- `film` — пересчитывает синий, зелёный и красный каналы, создавая эффект инфракрасной плёнки.
- `matte` — смешивает пиксели с белым в зависимости от расстояния до центра, создавая овальную рамку.
- `scratches` — рисует заданное число случайных вертикальных чёрных или белых царапин.
- `neon` — затемняет изображение и окрашивает в неоновый цвет пиксели с резким изменением яркости относительно соседей.

## Примеры

```text
python main.py --image img.jpg --filter grayscale
python main.py --image img.jpg --filter resize --width 800 --height 600
python main.py --image img.jpg --filter antique --strength 0.5
python main.py --image img.jpg --filter scratches --count 5
python main.py --image img.jpg --filter neon --threshold 70 --brightness 0.4 --strength 0.7
```

Результат сохраняется `<имя>_<номер фильтра>.<расширение>`, например `result/img_3.jpg`.
