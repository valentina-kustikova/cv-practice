# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

## Общие замечания

Все фильтры реализованы **только на NumPy**, без вызовов высокоуровневых функций OpenCV. OpenCV используется исключительно для чтения/записи файлов (`cv2.imread`, `cv2.imwrite`).

## 1. Изменение разрешения (Resize)

**Назначение:** масштабирование изображения с билинейной интерполяцией.

**Математика.** Для каждого выходного пикселя `(x', y')` находится позиция в исходном изображении:

```
x = (W / W') · x'
y = (H / H') · y'
```

Берутся четыре соседа: `(⌊x⌋, ⌊y⌋)`, `(⌊x⌋+1, ⌊y⌋)`, `(⌊x⌋, ⌊y⌋+1)`, `(⌊x⌋+1, ⌊y⌋+1)`. Дробные части `fx = x − ⌊x⌋`, `fy = y − ⌊y⌋` служат весами:

```
I(x', y') = (1−fx)(1−fy)·I₀₀ + fx(1−fy)·I₁₀ + (1−fx)fy·I₀₁ + fx·fy·I₁₁
```

**Реализация.** Всё векторизовано: `y_l`, `x_l`, `y_h`, `x_h` — массивы индексов, `y_weight`, `x_weight` — массивы весов формы `(new_h, 1, 1)` и `(1, new_w, 1)`. Четыре среза `image[y_l[:, None], x_l]` дают массивы `(new_h, new_w, 3)`, дальше — взвешенная сумма. Никаких циклов по пикселям.

**Параметры:**

- `scale` — коэффициент (`0.5` = уменьшить вдвое);
- `width`, `height` — целевой размер (используются, если `scale` не задан).

**Ограничения:**

- При **уменьшении** нет антиалиасинга: билинейная интерполяция берёт только 4 соседа, поэтому мелкие детали могут «рябить». Качественный downscale требует предварительного гауссова размытия (как в `cv2.INTER_AREA`).
- Требует 3-канальный вход: `h, w, c = image.shape`. Grayscale `(H, W)` упадёт.
- При `scale = 1.0` или если не задан ни один параметр — возвращает вход без изменений.

## 2. Оттенки серого (GrayScale)

**Назначение:** перевод в монохром с сохранением воспринимаемой яркости.

**Математика:**

```
I_gray = 0.114·B + 0.587·G + 0.299·R
```

Почему не `(B+G+R)/3`: глаз наиболее чувствителен к зелёному и слабо — к синему. Простое среднее сделало бы зелёную траву и синее небо одинаково яркими, что не соответствует восприятию.

**Реализация.** Один векторный проход по каналам, `clip(0, 255)`, `astype(uint8)`, затем `np.stack([g, g, g], axis=-1)` — чтобы выход остался трёхканальным (совместимость с `cv2.imwrite` и остальным пайплайном).

**Ограничения:** работает только с BGR; для RGB-входа веса нужно переставить (`0.299·R + 0.587·G + 0.114·B`).

## 3. Эффект «Антиквариат» (Antique / Sepia)

**Назначение:** стилизация под старую выцветшую фотографию.

**Математика (стандартная матрица сепии):**

```
R' = 0.393·R + 0.769·G + 0.189·B
G' = 0.349·R + 0.686·G + 0.168·B
B' = 0.272·R + 0.534·G + 0.131·B
```

Сумма коэффициентов в каждой строке > 1, поэтому светлые участки «подгорают» к тёплому — это и даёт характерный коричневатый тон.

**Реализация.** Линейная комбинация каналов, `clip`, `uint8`. **Дополнительно** результат пропускается через `MatteFilter(1.2, 0.9, 0.0)` — то есть накладывается сильная белая виньетка с жёстким порогом (`softness=0.9` при `radius=1.2`). Именно это делает края почти белыми, а центр — чистым.

**Параметров нет**.

## 4. Выцветание цвета (Fade Color)

**Назначение:** приглушение насыщенности, «плёночный» вид.

**Математика.** Линейная интерполяция между оригиналом и его grayscale-версией:

```
C' = C·(1−α) + I_gray·α
```

где `α ∈ [0, 1]` — коэффициент выцветания. При `α=0` — оригинал, при `α=1` — чистый grayscale.

**Реализация.** `I_gray` считается по BT.601 и растягивается до трёх каналов (`np.stack`), затем поэлементное смешивание в `float`. Никаких циклов.

**Параметры:**

- `factor` (`α`) — по умолчанию `0.4`.

**Ограничения:**.

## 5. Имитация инфракрасной плёнки (Film Simulation)

**Назначение:** стилизация под красный монохром — как если бы снимали на плёнку с ИК-фильтром, пропускающим преимущественно красный канал.

**Математика и реализация.**

1. Изображение переводится в `float [0, 255]` (без нормализации).
2. Считается «ИК-сигнал» как смесь каналов **с упором на зелёный**:

   ```
   I_ir = 0.3·R + 0.7·G
   ```

3. Поднимается контраст вокруг среднего уровня:

   ```
   I_ir ← (I_ir − 128)·1.5 + 128
   I_ir ← clip(I_ir, 0, 255)
   ```

4. **Подъём чёрного:** к красному каналу прибавляется константа `+20` (`shadow_r = full_like(ir_light, 20)`). Это не «подложка только в тенях», а **равномерный сдвиг всего канала** — чёрный становится тёмно-красным, контраст чуть снижается.
5. Синий и зелёный каналы **зануляются**: `blue = green = 0`.
6. Результат: `stack([0, 0, R'])` — красный монохром с поднятыми тенями.

**Параметров нет*.

## 6. Эффект маски (Matte / Vignette)

**Назначение:** плавное «растворение» краёв изображения в заданный цвет (по умолчанию — белый).

**Математика.** Вводится **нормализованная эллиптическая дистанция** от центра:

```
d(x, y) = ((x − x_c) / x_c)² + ((y − y_c) / y_c)²
```

- в центре `d = 0`;
- на серединах сторон `d = 1`;
- в углах `d = 2`.

Далее вес заливки:

```
если softness == 0:   w = 1, если d > radius, иначе 0
иначе:                w = clip((d − radius) / softness, 0, 1)
```

Смешивание:

```
I' = I·(1 − w) + color·w
```

**Реализация.** `np.ogrid` даёт координатную сетку, `d` считается векторно. `weight[:, :, None]` для broadcast по каналам. Никаких циклов.

**Параметры:**

- `matte_radius` — где начинается заливка (`0.7` — ближе к центру, `1.2` — уже почти у углов);
- `matte_softness` — ширина перехода (`0` — жёсткая граница, `0.9` — очень мягкая);
- `color` — цвет заливки (по умолчанию `255` = белый). Может быть задан числом (серый) — в текущем коде не вектор.

## 7. Эффект состаренной фотографии (Scratch and Noise)

**Назначение:** добавить зерно и имитацию физических царапин на плёнке, затем тонировать под сепию.

**Реализация по шагам.**

1. **Шум.** К изображению прибавляется гауссов шум:

   ```
   I_noisy = I + N(0, (noise · 255)²)
   ```

   Шум генерируется массивом `(h, w, 1)` и **broadcast-ится на все три канала** — то есть шум **монохромный**, одинаковый во всех каналах. Это дешевле, но выглядит не так естественно, как независимый шум на канал.

2. **Царапины.** Рисуется `scratches` линий:
   - начало — случайная точка **в верхней половине** кадра (`y₀ ∈ [0, 0.5H)`);
   - длина — `10–40%` высоты;
   - угол — почти вертикальный, `±0.08` рад;
   - по пути добавляется шум `±0.4 px` — линия «дрожит», как настоящая;
   - в точках царапины маске присваивается `max(текущее, U(0.3, 0.6))`.

3. **Сглаживание маски.** Маска размывается box-фильтром `3×3` с паддингом `edge`:

   ```
   mask = Σ(9 сдвинутых копий) / 9
   ```

   Это делает царапины толщиной в 1–2 пикселя с мягкими краями, а не однопиксельными.

4. **Наложение царапин.** Линейная интерполяция к «цвету царапины»:

   ```
   I' = I·(1 − mask) + C·mask
   ```

   где `C = U(210, 240)` — **одно скалярное число на всю картинку**, а не на каждый пиксель. То есть все царапины в кадре имеют одинаковую яркость.

5. **Тонирование.** Результат смешивается с сепией (через `AntiqueFilter`, у которого ещё и виньетка):

   ```
   out = 0.4 · I' + 0.6 · Sepia(I')
   ```

   Доминирует сепия — финальная картинка заметно коричневая.

**Параметры:**

- `noise` — `σ` шума в долях от 255 (по умолчанию `0.04`);
- `scratches` — число царапин.

## 8. Неоновый эффект (Neon)

**Назначение:** выделить контуры и подсветить их цветным свечением в стиле Photoshop `Outer Glow`, но без OpenCV.

**Пайплайн (по шагам).**

1. **Подготовка.** BGR → `float [0, 1]`, отбрасывание альфы при наличии.
2. **Яркость.** `L = 0.114·B + 0.587·G + 0.299·R` — одна карта `(H, W)`.
3. **Пре-блюр.** `L_smooth = blur(L, σ = max(0.6, neon_blur))`. Гасит шум и мелкую текстуру, чтобы Sobel не ловил ложные контуры.
4. **Sobel.** Ручная свёртка ядрами 3×3:

   ```
   Gx = [-1 0 1; -2 0 2; -1 0 1]
   Gy = [-1 -2 -1; 0 0 0; 1 2 1]
   |G| = √(Gx² + Gy²)
   ```

5. **Нормализация.** `|G| ← |G| / max(|G|)` — в `[0, 1]`.
6. **Мягкий порог:**

   ```
   edge = clip((|G| − low) / (high − low), 0, 1)
   ```

   Ниже `low` — 0, выше `high` — 1, между — линейно. Отсекает слабые градиенты.
7. **Ядро (линия):** `core = edge^γ`. При `γ < 1` линия толще (гамма «поднимает» средние значения), при `γ > 1` — тоньше.

   > **`γ` должен быть > 0.** При `γ = 0` получается `x⁰ = 1` — всё изображение превращается в сплошную заливку. В исходном README пример с `--core_gamma 0.0` некорректен.

8. **Аура:** `aura = blur(core, σ = max(1.5, neon_blur · aura_scale))`. Гауссово размытие сохраняет суммарную энергию, поэтому с ростом `σ` яркость у самой линии падает, но пятно становится шире.
9. **База (фон).** Если `darken > 0`:

   ```
   ambient  = (0.12 + 0.35·L) · tint · tint_strength
   base     = img·(1 − darken) + ambient·darken
   ```

   То есть оригинал ослаблен, плюс цветная подложка, яркость которой зависит от `L` (в тенях слабее, в светах сильнее). Если `darken = 0` — `base = img` (оригинал без изменений).

10. **Неоновый слой.**

    ```
    neon_layer = neon_color · (core · core_brightness + aura · aura_brightness)
    neon_layer = clip(neon_layer, 0, 1)
    ```

    `neon_color` — BGR-вектор в `[0, 1]`, по умолчанию маджента `(255, 0, 255)`.

11. **Смешивание:**
    - по умолчанию **Screen**: `out = 1 − (1 − base)(1 − neon_layer)` — неон осветляет, но не затемняет;
    - опционально **Add**: `out = clip(base + neon_layer, 0, 1)` — неон «добавляется» к оригиналу, ярче, но на светлом фоне пересвет.

12. **Выход.** `out ← clip(out · master_strength, 0, 1)`, затем `× 255` и `astype(uint8)`.

**Параметры NeonFilter:**

| Параметр | Что делает | Дефолт | Диапазон |
|---|---|---:|---|
| `neon_blur` | Базовая σ; от неё масштабируются все размытия | `0.8` | `0.5 – 2.0` |
| `core_gamma` | Толщина линии: `<1` толще, `>1` тоньше | `0.65` | `0.4 – 1.0` |
| `core_threshold_low` | Нижний порог Sobel — отсекает слабые границы | `0.03` | `0.0 – 0.15` |
| `core_threshold_high` | Верхний порог — делает линию резче | `0.28` | `0.1 – 0.5` |
| `core_brightness` | Яркость самой линии | `1.8` | `0.0 – 3.0` |
| `aura_brightness` | Яркость свечения | `1.2` | `0.0 – 2.5` |
| `aura_scale` | Ширина свечения: `σ = neon_blur · aura_scale` | `8.0` | `3.0 – 20.0` |
| `neon_color` | Цвет неона (BGR) | `(255, 0, 255)` | — |
| `tint` | Цвет подложки (BGR) | `(120, 0, 80)` | — |
| `tint_strength` | Сила подложки | `1.0` | `0.0 – 2.0` |
| `darken` | Затемнение оригинала | `0.22` | `0.0 – 1.0` |
| `add_glow` | `True` = Add вместо Screen | `False` | — |
| `master_strength` | Общая экспозиция | `1.0` | `0.5 – 2.0` |

**Гауссово размытие внутри фильтра.** Реализовано вручную:

- ядро — 1D-гаусс `exp(−0.5·(x/σ)²)`, `x ∈ [−r, r]`, `r = ceil(3σ)` (правило трёх сигм: за `3σ` меньше 0.3% веса);
- ядро нормируется на сумму → сохранение яркости;
- свёртка **сепарабельная**: два прохода `_conv_axis` (по строкам, затем по столбцам) — `O(2N)` вместо `O(N²)`;
- паддинг — `mode="edge"`.

**Рекомендуемые пресеты:**

| Хочу | `core_brightness` | `aura_brightness` | `aura_scale` | `core_gamma` |
|---|---:|---:|---:|---:|
| Тонкая яркая линия | `2.2` | `0.6` | `6` | `0.85` |
| Классический неон | `1.8` | `1.2` | `8` | `0.65` |
| Мощное свечение | `1.2` | `2.0` | `14` | `0.55` |
| Только линия, без свечения | `2.0` | `0.0` | `1` | `0.9` |
| Мягкий «дышащий» | `1.5` | `1.6` | `10` | `0.55` |

## Инструкция по запуску

### 1. Подготовка окружения

```bash
pip install numpy opencv-python
```

### 2. Примеры использования CLI

```bash
# Изменение разрешения (0.5×)
python main.py -i images/apple1.jpg -o output_resize.jpg -f resize --scale 0.5

# Оттенки серого
python main.py -i images/apple1.jpg -o output_gray.jpg -f gray

# Антиквариат (сепия + виньетка)
python main.py -i images/apple1.jpg -o output_antique.jpg -f antique

# Выцветание
python main.py -i images/apple1.jpg -o output_fade.jpg -f fade --factor 0.6

# Инфракрасная плёнка (красный монохром)
python main.py -i images/apple1.jpg -o output_film.jpg -f film

# Овальная маска
python main.py -i images/apple1.jpg -o output_matte.jpg -f matte \
    --matte_radius 0.65 --matte_softness 0.25

# Шум и царапины
python main.py -i images/apple1.jpg -o output_scratch.jpg -f scratch \
    --noise 0.05 --scratches 6

# Неон — корректный запуск
python main.py -i images/apple1.jpg -o output_neon.jpg -f neon \
    --core_brightness 2.0 --aura_brightness 1.2 \
    --aura_scale 8.0 --core_gamma 0.65
```

## Структура проекта

```
project/
├── main.py            # CLI: парсинг аргументов, чтение/запись, вызов фильтра
├── filters.py         # ImageFilter и все классы фильтров
├── images/
│   └── apple1.jpg     # тестовое изображение
└── README.md          # этот файл
```

`main.py` не содержит логики фильтров — только:

1. разбор аргументов (`argparse`);
2. чтение (`cv2.imread`) с проверкой на `None`;
3. вызов `ImageFilter.get_filter(...)` с нужным `kwargs`;
4. `apply_filter`;
5. создание выходной директории при необходимости;
6. запись (`cv2.imwrite`).

Все параметры фильтров передаются через `**kwargs` в конструктор соответствующего класса. Это позволяет добавлять новые фильтры без правки `main.py` — достаточно зарегистрировать класс в словаре `filters` внутри `ImageFilter.get_filter`.
