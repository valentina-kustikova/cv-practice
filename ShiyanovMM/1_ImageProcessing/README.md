ImageFilter.py - скрипт для наложения фильтров на изображения и их изменения.

Вызывается через командную строку.  
Синтаксис: python ImageFilter.py {путь ко входному изображению} {имя выходного изображения} -f {название фильтра} {набор аргументов}  
Аргументы вводятся через пробел без знаков препинания.  
Синтаксис аргумента фильтра: {обозначение с дефисом или двумя дефисами} {значение}

СПИСОК ДОСТУПНЫХ ФИЛЬТРОВ:
1. resolution - изменяет масштаб. Принимает аргументы:
	* -s/--scale - множитель масштаба (по умолчанию 2.0). Не может быть отрицательным. Тип данных float
2. grayscale - обесцвечивает изображение. Не принимает аргументов
3. antique - "состаривает" изображение, накладывает на него сепию и виньетку. Принимает аргументы: 
	* -i/--intensity - интенсивность/сила наложения фильтра (по умолчанию 1.0). Принимает значение от 0 до 1. Тип данных float
	* -v/--vignette_color - цвет виньетки (по умолчанию black). Доступны вариант black и white. Тип данных str
4. fade - накладывает выцветание на изображение. Принимает аргументы: 
	* -i/--intensity - интенсивность/сила наложения фильтра (по умолчанию 0.5). Принимает значение от 0 до 1. Тип данных float
5. infrared - применяет эффект псевдо-ИК излучения. Не принимает аргументов.
6. matte - накладывает овальную рамку. Не принимает аргументов. Для работы фильтра matte в папке должен находиться файл mask.png.
7. noise - накладывает шуп и оставляет царапины на изображении. Принимает аргументы: 
	* -i/--intensity - интенсивность/сила наложения фильтра (по умолчанию 1.0). Принимает значение от 0 до 1. Тип данных float
8. neon - создает неоновый эффект, затемняя изображение. Принимает аргументы: 
	* -b/--brightness - яркость фонового изображения (по умолчанию 0.1). Принимает значение от 0 до 1. Тип данных float

Обработанное изображение сохраняется в путь, который указан, или же в текущую директорию, если указано только имя файла

В папке есть тестовые изображения: example1.png, example2.jpg, example3.png  
В папке есть по одному примеру обработки изображения example3.png для каждого фильтра:  
* out_antique.png создан командой: python ImageFilter.py ./example3.png out_antique.png -f antique -i 0.8 -v black
* out_gray.png создан командой: python ImageFilter.py ./example3.png out_gray.png -f grayscale
* out_infrared.png создан командой: python ImageFilter.py ./example3.png out_infrared.png -f infrared
* out_fade.png создан командой: python ImageFilter.py ./example3.png out_fade.png -f fade -i 0.5
* out_scaled.png создан командой: python ImageFilter.py ./example3.png out_scaled.png -f resolution -s 2.0
* out_neon.png создан командой: python ImageFilter.py ./example3.png out_neon.png -f neon -b 0.2
* out_noise.png создан командой: python ImageFilter.py ./example3.png out_noise.png -f noise -i 0.3
* out_matte.png создан командой: python ImageFilter.py ./example3.png out_matte.png -f matte
