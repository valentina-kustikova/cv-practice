
# Практическая работа №1: Обработка изображений (OpenCV + NumPy)

Данный проект представляет собой консольную утилиту для применения фильтров к изображениям. Реализация выполнена **без использования высокоуровневых функций OpenCV** — все преобразования осуществляются посредством базовых матричных операций с использованием библиотеки NumPy.

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install opencv-python numpy
   ```
2. Запустите скрипт через терминал, передав нужные аргументы:
   ```bash
   python main.py -i <input_image> -o <output_image> -f <filter_name> [options]
   ```

### Примеры использования

* **Изменение разрешения:** 
  `python main.py -i images/test.jpg -o images/res.jpg -f resize --width 1024 --height 768`
* **Эффект старого фото (Антиквариат):** 
  `python main.py -i images/test.jpg -o images/res.jpg -f antique`
* **Неоновый контур:** 
  `python main.py -i images/test.jpg -o images/res.jpg -f neon`
* **Применение всех фильтров к изображению**
  ``bash run.sh images/input/cat.jpg``

## Математическое описание алгоритмов

Все операции производятся над тензорами формы `(H, W, C)`, где `H` — высота, `W` — ширина, `C` — каналы цвета (OpenCV использует порядок **BGR**).

### 1. Изменение разрешения (Resize)
Реализован метод ближайшего соседа (Nearest Neighbor). Для каждого пикселя нового изображения с координатами $(x_{new}, y_{new})$ берется пиксель из исходного по формуле:
$$x_{old} = \lfloor x_{new} \cdot \frac{W_{old}}{W_{new}} \rfloor, \quad y_{old} = \lfloor y_{new} \cdot \frac{H_{old}}{H_{new}} \rfloor$$

### 2. Оттенки серого (Grayscale)
Преобразование RGB в интенсивность свечения (Luma) осуществляется скалярным произведением каналов на весовые коэффициенты:
$$Y = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$

### 3. Антиквариат / Сепия (Antique)
Эффект сепии достигается умножением вектора цвета каждого пикселя на специальную матрицу трансформации:
$$R_{new} = (R \cdot 0.393) + (G \cdot 0.769) + (B \cdot 0.189)$$
$$G_{new} = (R \cdot 0.349) + (G \cdot 0.686) + (B \cdot 0.168)$$
$$B_{new} = (R \cdot 0.272) + (G \cdot 0.534) + (B \cdot 0.131)$$

### 4. Выцветание (Fade Color)
Линейная интерполяция между оригинальным цветом пикселя $P_{orig}$ и его серой версией $P_{gray}$ с коэффициентом выцветания $\alpha \in [0, 1]$:
$$P_{new} = P_{orig} \cdot (1 - \alpha) + P_{gray} \cdot \alpha$$

### 5. Имитация пленки (Infrared)
Для создания инфракрасного эффекта красный канал инвертируется, а синий и зеленый затемняются:
$$R_{new} = 255 - R \cdot 0.8, \quad G_{new} = G \cdot 0.3, \quad B_{new} = B \cdot 0.3$$

### 6. Эффект маски (Matte / Vignette)
Создается матрица расстояний на основе уравнения эллипса:
$$D(x, y) = \frac{(x - X_c)^2}{a^2} + \frac{(y - Y_c)^2}{b^2}$$
Где $X_c, Y_c$ — центр изображения, $a, b$ — полуоси. Значения $D$ ограничиваются диапазоном $[0, 1]$ и служат альфа-каналом для смешивания изображения с белым цветом по краям.

### 7. Царапины и шум (Noise)
- **Зернистость:** к каждому пикселю добавляется значение из нормального (Гауссовского) распределения $N(0, \sigma^2)$, где $\sigma = 15$.
- **Царапины:** случайная генерация координат и закрашивание столбцов матрицы (срез массива Numpy) белым цветом с легкой вариацией яркости.

### 8. Неоновый эффект (Neon)
Поиск контуров реализован через вычисление градиента яркости (аналог оператора Собеля). Вычисляется модуль разности соседних пикселей по осям X и Y путем сдвига матриц:
$$\nabla I = |I(x+1, y) - I(x, y)| + |I(x, y+1) - I(x, y)|$$
Найденные контуры $\nabla I$ выступают в качестве маски интенсивности для окрашивания в заданный цвет (например, циан: R=10%, G=80%, B=100%).
