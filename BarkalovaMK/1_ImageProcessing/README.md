# Обработка изображений с использованием OpenCV


## Структура проекта

Корневая папка — 1_ImageProcessing. Внутри неё: пакет filters/ 
(с файлами __init__.py, base.py, resize.py, grayscale.py, antique.py, fade.py,
film.py, matte.py, scratches.py, neon.py), папка images/ с тестовым 
изображением test.jpg, скрипт main.py — точка входа, файл зависимостей 
requirements.txt и описание README.md.
```
1_ImageProcessing/
    filters/
        __init__.py        — делает папку пакетом
        base.py            — абстрактный класс ImageFilter
        resize.py          — изменение разрешения
        grayscale.py       — перевод в оттенки серого
        antique.py         — эффект «антиквариат»
        fade.py            — выцветание
        film.py            — имитация плёнки
        matte.py           — овальная рамка
        scratches.py       — царапины и шум
        neon.py            — неоновый эффект
    images/
        test.jpg           — изображение
    main.py 
    requirements.txt
    README.md
```


## Запуск

python main.py -i <input> -o <output> -f <filter> [параметры]

| Аргумент       | Описание                                             |
|----------------|------------------------------------------------------|
| `-i, --input`  | путь к входному изображению                          |
| `-o, --output` | путь для сохранения результата                       |
| `-f, --filter` | тип фильтра                                          |
| `--scale`      | коэффициент масштаба для `resize` (по умолчанию 0.5) |
| `--alpha`, `--brightness` | параметры `fade`                          |
| `--strength`   | параметр `film`                                      |
| `--vignette`   | параметр `antique`                                   |
| `--border`     | толщина рамки для `matte`                            |
| `--n_scratches`, `--noise_std` | параметры `scratches`                |
| `--threshold`  | порог для `neon`                                     |

## Математическое описание фильтров

### Изменение разрешения (Resize)
Реализована билинейная интерполяция.

Для каждой точки `(x, y)` нового изображения находятся 4 ближайших пикселя
исходного: `(x0, y0)`, `(x1, y0)`, `(x0, y1)`, `(x1, y1)`, где
`x0 = ⌊x⌋`, `x1 = x0 + 1`, аналогично по `y`.

Значение вычисляется как взвешенная сумма:
```
I(x, y) = (1 − w_y) · [ (1 − w_x) * I(x0, y0) + w_x * I(x1, y0) ] + w_y · [ (1 − w_x) * I(x0, y1) + w_x * I(x1, y1) ]
```
где `w_x = x − x0`, `w_y = y − y0`.

Координаты новых пикселей задаются через `np.linspace(0, h-1, new_h)` и
`np.linspace(0, w-1, new_w)` — равномерное распределение по исходному изображению.


### Оттенки серого (Grayscale)
Используется стандарт ITU-R BT.601:
```
Y = 0.299 * R + 0.587 * G + 0.114 * B
```
Коэффициенты отражают спектральную чувствительность человеческого глаза:
зелёный воспринимается ярче, синий — темнее.Сумма коэффициентов равна 1,
что сохраняет динамический диапазон яркости.

Результат - одноканальное изображение `Y` размером `H * W`.


### FadeColor — выцветание
#### Шаг 1. Интерполяция к белому
```
I_1 = alpha * I + (1 − alpha) * 255, (alpha по умолчанию 0.7)
```
При `alpha = 1` изображение не меняется; при `alpha = 0` — становится 
полностью белым. Промежуточные значения имитируют утрату контраста.

#### Шаг 2. Осветление
```
I_2 = I_1 + b
```
где `b = brightness` — сдвиг яркости вверх. (по умолчанию 25)

#### Шаг 3. Снижение насыщенности
Вычисляем «серое» значение как среднее по трём каналам:
```
Y = (R + G + B) / 3
```
Смешиваем с исходным цветным изображением:
```
I_out = 0.6 · I_2 + 0.4 · Y
```
Это уменьшает насыщенность на 40%: цвета становятся ближе к серому.


### Film — имитация плёнки
#### Перестановка каналов
Основной эффект — частичная замена R и B. 
Параметр `s = strength` задаёт степень смешения

Формулы перестановки:
```
R' = (1 − s) * R + s * B
B' = (1 − s) * B + s * R
G' = (1 − 0.15 * s) * G
```
При `s = 0` — исходное изображение, при `s = 1` — полная перестановка R и B.
Зелёный канал приглушается незначительно.

#### Тонирование (сдвиг цветового баланса)
После перестановки каналы дополнительно масштабируются:
```
B' <- 1.05 * B'      (синий +5%)
R' <- 0.95 * R'      (красный −5%)
```
(чтобы картинка оставалась не слишком "теплой")

#### Зерно (аддитивный шум)
К каждому пикселю добавляется независимая гауссова случайная величина
с нулевым средним и стандартным отклонением `sigma = noise`:
```
I_film(x, y, c) = I'(x, y, c) + eps(x, y, c),   eps = N(0, sigma^2)
```
где `I'(x, y, c)` — изображение после шагов 1–2.

(т.к на пленке часто бывает физический шум)

Итоговая формула фильтра:
```
I_final = clip( I_tinted + eps, 0, 255 )
```
где

- `I_tinted` — результат шагов 1 и 2;
- `eps = N(0, sigma^2)` — шум с sigma = `noise` (по умолчанию 8.0).


### Antique — эффект «антиквариат»
#### Этап 1. Сепия
Линейное преобразование каналов через матрицу `M_sepia`:
```
| R' |   | 0.393  0.769  0.189 |   | R |
| G' | = | 0.349  0.686  0.168 | * | G |
| B' |   | 0.272  0.534  0.131 |   | B |
```
(даёт тёплый коричневато-жёлтый оттенок)

#### Этап 2. Виньетка
Затемнение по краям. 
Нормированное расстояние от центра:
```
d(x, y) = sqrt( ((x − c_x) / c_x)^2 + ((y − c_y) / c_y)^2 )
```
где `c_x = W/2`, `c_y = H/2`. В центре `d = 0`, на границе `d = 1`, в углах
`d = sqrt(2)`.

Маска затемнения:
```
m(x, y) = clip( 1 − k · d(x, y), 0, 1 )
```
где `k = vignette` (по умолчанию 0.6)

Применение:
```
I_sepia(x, y) <- m(x, y) * I_sepia(x, y)
```

#### Этап 3. Зерно
К каждому пикселю добавляется независимая гауссова величина:
```
I_final = I_sepia + eps,   eps = N(0, sigma^2)
```
где `sigma = noise` (по умолчанию 6.0).


### Matte — овальная рамка
Накладываем эллиптическую маску: вне её-белый фон, внутри-исходное изображение.
Формулы:
Уравнение эллипса с полуосями `a_x`, `a_y`:
```
d(x, y) = sqrt( ((x − c_x) / a_x)^2 + ((y − c_y) / a_y)^2 )
```
где
- `c_x = W/2`, `c_y = H/2` — центр;
- `a_x = max(c_x − border, 1)`, `a_y = max(cy − border, 1)` — полуоси,
  уменьшенные на `border` пикселей.

Маска с плавным переходом:
```
m(x, y) = clip( (1 − d(x, y)) / softness, 0, 1 )
```
`softness` (по умолчанию 0.20) задаёт ширину зоны перехода.

Итог:
```
I_out = m * I + (1 − m) * 255
```


### ScratchesNoise — царапины и шум
Фильтр «состаривание»: добавляет зерно, царапины и пятна, затем тонирует сепией.
Параметры:
- `noise` — сила зерна (по умолчанию 0.10);
- `scratch_density` — плотность царапин (по умолчанию 0.03);
- `seed` — seed генератора случайных чисел (по умолчанию 40).

#### Зерно
К каждому пикселю добавляется независимая гауссова величина

#### Царапины
Рисуется `n = ⌊W * scratch_density * 0.5⌋` почти вертикальных линий. Каждая имеет:
- `x1 - [0, W)` — старт по горизонтали;
- `y1 - [0, H)` — старт по вертикали;
- `length - [0.05H, 0.40H)` — длина;
- `angle - [-5, 5]` — наклон;
- `thickness - {1, 2}` — толщина (75% случаев — 1 пиксель);
- `intensity - [0.20, 0.45]` — яркость в слое царапин.

Линия рисуется через линейную интерполяцию (`np.linspace` между `(x1, y1)` и
`(x2, y2)`, округление до пикселей, `np.maximum` при пересечении).

#### Размытие царапин
Слой размывается усреднением 3×3

#### Пятна
Каждый пиксель с вероятностью `scratch_density * 0.04` становится
точкой. Значения ослабляются коэффициентом 0.4.

#### Объединение и наложение
```
scratch = clip(stripe_field + specks, 0, 1)
I_result = I + grain + scratch * (255 * scratch_value − I)
```
где `scratch_value = U(0.60, 0.85)` — светлый цвет царапины.

#### Сепия
Классическая матрица сепии, смешивание с оригиналом при `strength = 0.6`


### Neon — неоновый эффект
Параметры:
- `threshold` — порог для определения контуров (по умолчанию 40);
- `glow` — множитель яркости градиента (по умолчанию 1.2).

#### Шаг 1. Grayscale
По формуле BT.601

#### Шаг 2. Градиенты Собеля
Ядра:
```
     | -1  0  1 |                | -1  -2  -1 |
Gx = | -2  0  2 | ,      Gy =    |  0   0   0 |
     | -1  0  1 |                |  1   2   1 |
```
Так как ядра фиксированы, свёртка переписана через разности сдвинутых
срезов (без циклов). Краевая рамка 1 пиксель остаётся нулевой.

#### Шаг 3. Модуль градиента
```
M(i, j) = sqrt( gx(i, j)^2 + gy(i, j)^2 )
M' = clip( glow * M, 0, 255 )
```
Большая `M'` — резкий перепад яркости — граница объекта.

#### Шаг 4. Порог
```
E(i, j) = 1, если M'(i, j) > threshold, иначе 0
```

#### Шаг 5. Свечение
Оригинал затемняется в 4 раза, поверх накладываются контуры:
```
I_out = 0.25 * I + E * (0.2 * B, 0.9 * G, 1.0 * R) * M'
```
Множители `(0.2, 0.9, 1.0)` для каналов BGR дают тёплый красно-оранжевый неон.
