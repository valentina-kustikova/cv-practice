## Установка и запуск

Python 3.10 или новее. Команды выполняются из `PikhotskyRV/1_ImageProcessing`.

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py --input images/colors.png --output result.png --filter antique
```

В Linux и macOS путь к интерпретатору окружения: `.venv/bin/python`.
В следующих примерах `python` обозначает интерпретатор с установленными зависимостями.

```text
python main.py -i images/colors.png -o results/resize.png -f resize --width 640 --height 480
python main.py -i images/colors.png -o results/grayscale.png -f grayscale
python main.py -i images/colors.png -o results/antique.png -f antique --strength 0.8
python main.py -i images/colors.png -o results/fade.png -f fade --strength 0.6
python main.py -i images/colors.png -o results/film.png -f film --gamma 1.2
python main.py -i images/shapes.png -o results/matte.png -f matte --softness 0.3
python main.py -i images/shapes.png -o results/scratches.png -f scratches --count 15 --noise 12 --seed 42
python main.py -i images/shapes.png -o results/neon.png -f neon --threshold 25 --radius 4 --glow 2
```

`--input`, `--output`, `--filter` обязательны. Параметры доступны только для выбранного
фильтра; для `resize` обязательны оба размера. Справка: `python main.py --help`,
подробности для фильтра: `python main.py --filter neon --help`.

| Фильтр | Параметры, диапазоны и значения по умолчанию |
| --- | --- |
| `resize` | `--width`, `--height`: целые числа > 0 |
| `grayscale` | Нет параметров |
| `antique` | `--strength`: [0, 1], по умолчанию 1 |
| `fade` | `--strength`: [0, 1], по умолчанию 0.5 |
| `film` | `--gamma`: [0.1, 5], по умолчанию 1 |
| `matte` | `--softness`: [0.01, 1], по умолчанию 0.3 |
| `scratches` | `--count`: целое ≥ 0, по умолчанию 12; `--noise`: [0, 255], по умолчанию 10; `--seed`: целое ≥ 0, по умолчанию случайное зерно |
| `neon` | `--threshold`: [0, 255], по умолчанию 25; `--radius`: целое [0, 50], по умолчанию 4; `--glow`: [0, 10], по умолчанию 2 |

Вход читается как восьмибитное цветное изображение BGR. Серое изображение преобразуется
в три канала, прозрачность отбрасывается. Формат результата определяется расширением
выходного файла; для сохранения точных значений пикселей следует использовать PNG.
Папка результата создаётся автоматически, существующий выходной файл перезаписывается.
Поддерживаются пути с кириллицей. При успехе код завершения равен 0, при ошибке
чтения, обработки или записи — 1, при ошибке аргументов командной строки — 2.

## Реализация

`filters.py` содержит восемь функций фильтрации, принимающих массив NumPy формы
`(H, W, 3)` типа `uint8` в порядке BGR. Они возвращают новый массив того же типа,
не изменяя исходный; `resize` меняет также размеры. `check_image` проверяет формат
и переводит данные в `float32`, `check_range` проверяет числовые параметры,
`to_uint8` ограничивает результат диапазоном [0, 255] и округляет до целого.
`brightness` вычисляет яркость, `blur` выполняет размытие для свечения.

`main.py` содержит `cli_argument_parser` для разбора аргументов, `read_image`
для чтения и декодирования, `save_image` для кодирования и записи и `main`
для последовательного запуска этих шагов с обработкой ошибок. Словарь `FILTERS`
связывает название фильтра с функцией. OpenCV используется только для ввода
и вывода; преобразования реализованы базовыми операциями над массивами.

## Математическое описание

Ниже `I` — исходное изображение, `J` — результат до округления,
`clip(a, l, u)` ограничивает значение `a` интервалом `[l, u]`.
Все операции с цветами выполняются отдельно для каждого пикселя.

### Изменение разрешения

Используется метод ближайшего соседа. Для исходных размеров `W, H` и новых `w, h`:

```text
xs = floor(x * W / w), ys = floor(y * H / h)
J[y, x] = I[ys, xs], 0 ≤ x < w, 0 ≤ y < h.
```

Увеличение повторяет пиксели, уменьшение выбирает отдельные пиксели без сглаживания.

### Оттенки серого

```text
Y = 0.114B + 0.587G + 0.299R
J_B = J_G = J_R = Y.
```

### Антиквариат

Сначала рассчитывается сепия, затем она смешивается с оригиналом с силой `s`:

```text
S_B = 0.131B + 0.534G + 0.272R
S_G = 0.168B + 0.686G + 0.349R
S_R = 0.189B + 0.769G + 0.393R
J = (1 - s)I + s * clip(S, 0, 255).
```

### Выцветание

Снижаются насыщенность и контраст, тени становятся светлее:

```text
C = (1 - s)I + sY
L = 64s
J = L + C * (255 - L) / 255.
```

При `s = 0` изображение не меняется, при `s = 1` получается светлый серый вариант.

### Имитация плёнки

Моделируется цветной негатив с гамма-коррекцией:

```text
J = 255 * (1 - I / 255)^gamma.
```

При `gamma = 1` яркости инвертируются, цвета заменяются дополнительными.
Гамма регулирует распределение промежуточных тонов. Это стилизация под негатив,
а не физическая модель фотохимического процесса.

### Белая овальная маска

Координаты нормируются относительно центра и полуосей изображения:

```text
u = (2x - (W - 1)) / max(W - 1, 1)
v = (2y - (H - 1)) / max(H - 1, 1)
d = sqrt(u² + v²)
a = clip((d - (1 - softness)) / softness, 0, 1)
J = (1 - a)I + 255a.
```

Внутри овала сохраняется оригинал; в переходной области он плавно смешивается
с белым. При `d ≥ 1` получается белая рамка. Делители допускают ширину или высоту 1;
единственный пиксель изображения 1×1 остаётся центральным и не меняется.

### Царапины и шум

В каждом пикселе генерируется независимый шум `n ~ N(0, noise²)`, одинаковый
для трёх каналов: `J = I + n`. Затем `count` раз выбираются равновероятно столбец
`x ∈ [0, W)`, начало `y0 ∈ [0, H)` и конец `y1 ∈ [y0 + 1, H]`. Пиксели
`J[y0:y1, x]` заменяются на 0 или 255 с равными вероятностями. Царапины могут
пересекаться. `seed` позволяет повторить результат в одном окружении;
при `count = 0` и `noise = 0` изображение не меняется.

### Неон

По яркости `Y` вычисляются градиенты оператора Собеля. Границы массива
дополняются повторением ближайшего пикселя. Ядра применяются вручную суммированием
сдвинутых срезов:

```text
Kx = [-1  0  1]       Ky = [-1 -2 -1]
     [-2  0  2]            [ 0  0  0]
     [-1  0  1]            [ 1  2  1]
M = sqrt(Gx² + Gy²) / 4
E = clip(M / 255, 0, 1), если M > threshold, иначе 0.
```

Для ореола `E` последовательно размывается по горизонтали и вертикали.
Для радиуса `r > 0` веса имеют вид `w(k) = exp(-k² / (2sigma²))`,
где `k = -r, ..., r`, `sigma = max(r / 2, 0.5)`; веса делятся на их сумму.
При `r = 0` размытие возвращает исходную маску. Итог в порядке BGR:

```text
A = E + glow * blur(E, r)
J = 0.1I + A * (255, 180, 40).
```

Контуры окрашиваются в голубой цвет, вокруг них появляется свечение на тёмном фоне.
