# Лабораторная работа № 1. Библиотека обработки изображений

## 1. Цель работы

Цель работы — разработать библиотеку обработки изображений на языке Python, реализующую восемь фильтров с использованием базовых матричных операций NumPy.

В рамках работы необходимо реализовать геометрические и цветовые преобразования, а также художественные эффекты: изменение размера изображения, перевод в оттенки серого, сепию, выцветание, плёночный эффект, белую матовую рамку, состаривание фотографии и неоновое свечение контуров.

Основные алгоритмы обработки реализованы самостоятельно с использованием NumPy. Библиотека OpenCV применяется для чтения и сохранения изображений.

## 2. Используемые технологии

- **Python** — язык программирования.
- **NumPy** — работа с массивами изображений и выполнение математических операций над пикселями.
- **OpenCV** — чтение и сохранение изображений.
- **argparse** — обработка аргументов командной строки.
- **pathlib** — работа с путями к файлам.

Цветное изображение представляется трёхмерным массивом размера \(H \times W \times 3\), где \(H\) — высота, \(W\) — ширина, а три компонента соответствуют цветовым каналам.

OpenCV хранит цветные изображения в порядке **BGR**: синий, зелёный, красный. Значения каналов обычно находятся в диапазоне от 0 до 255.

В формулах ниже \(I\) обозначает исходное изображение или пиксель, а \(I'\) — результат обработки. Для выполнения вычислений значения пикселей преобразуются в тип `float32`. После обработки результат ограничивается диапазоном от 0 до 255 и преобразуется в `uint8`.

## 4. Математическое обоснование фильтров

### 4.1. Resize — изменение размера изображения

Для изменения разрешения используется метод ближайшего соседа (*Nearest Neighbor*).

Пусть исходное изображение имеет размеры \(H \times W\), а новое — \(H' \times W'\).

Для каждого пикселя нового изображения вычисляются координаты соответствующего пикселя исходного изображения:

\[
x_s=\left\lfloor x\frac{W}{W'}\right\rfloor
\]

\[
y_s=\left\lfloor y\frac{H}{H'}\right\rfloor
\]

Тогда значение пикселя результата определяется выражением:

\[
I'(y,x)=I(y_s,x_s)
\]

Здесь \(x,y\) — координаты пикселя нового изображения, а \(x_s,y_s\) — координаты пикселя исходного изображения.

В реализации для вычисления индексов используются `np.arange`, масштабирование координат, преобразование к целочисленному типу и ограничение индексов допустимым диапазоном. Затем пиксели выбираются посредством индексирования NumPy-массива.

**Обоснование выбора алгоритма:** метод ближайшего соседа прост и позволяет реализовать изменение размера без использования готового `cv2.resize`. Он не вычисляет промежуточные значения цветов, поэтому при увеличении изображения могут появляться ступенчатые границы.

### 4.2. Grayscale — преобразование в оттенки серого

Для перевода цветного изображения в оттенки серого вычисляется яркость каждого пикселя.

Используется взвешенная сумма цветовых каналов:

\[
Y=0.114B+0.587G+0.299R
\]

Здесь \(B\), \(G\) и \(R\) — значения синего, зелёного и красного каналов соответственно, а \(Y\) — рассчитанная яркость.

Коэффициенты различаются, поскольку цветовые каналы вносят неодинаковый вклад в воспринимаемую яркость изображения.

В программе каждый канал извлекается из массива и преобразуется в `float32`. Затем вычисляется яркость по приведённой формуле.

**Обоснование:** взвешенное преобразование сохраняет различия в яркости объектов лучше, чем простое арифметическое среднее трёх каналов. В результате каждый пиксель представлен одним значением яркости вместо трёх цветовых компонентов.

### 4.3. Antique — эффект сепии

Эффект сепии создаётся посредством линейного преобразования цветовых каналов.

Для каждого пикселя рассчитываются новые значения:

\[
R'=0.393R+0.769G+0.189B
\]

\[
G'=0.349R+0.686G+0.168B
\]

\[
B'=0.272R+0.534G+0.131B
\]

Эти формулы можно представить в виде матричного умножения:

\[
\begin{bmatrix}
R'\\
G'\\
B'
\end{bmatrix}
=
\begin{bmatrix}
0.393&0.769&0.189\\
0.349&0.686&0.168\\
0.272&0.534&0.131
\end{bmatrix}
\begin{bmatrix}
R\\
G\\
B
\end{bmatrix}
\]

Матрица изменяет соотношение исходных цветовых компонентов, придавая изображению тёплый коричневатый оттенок.

В коде результат записывается в массив с учётом порядка каналов BGR, используемого OpenCV.

**Обоснование:** матричное преобразование позволяет изменять цвет каждого пикселя с помощью линейных комбинаций исходных каналов. Такой подход прост, эффективен и не требует применения готовых цветовых фильтров OpenCV.

### 4.4. Fade Color — эффект выцветания

Фильтр смешивает исходный пиксель с заданным цветом.

Математически операция определяется выражением:

\[
I'=(1-\alpha)I+\alpha C
\]

где:

- \(I\) — исходный пиксель;
- \(C\) — заданный цвет;
- \(\alpha\) — интенсивность эффекта, от 0 до 1;
- \(I'\) — результат смешивания.

При \(\alpha=0\) изображение остаётся неизменным. При \(\alpha=1\) все пиксели заменяются заданным цветом. Промежуточные значения создают плавное смешивание исходного изображения с цветом выцветания.

В программе вычисления выполняются сразу над массивами NumPy, без отдельного цикла по каждому пикселю.

**Обоснование:** линейное смешивание позволяет управлять интенсивностью эффекта одним параметром и создавать равномерное цветовое выцветание изображения.

### 4.5. Film — плёночный эффект

Фильтр имитирует стилизованную цветопередачу плёнки и добавляет случайное зерно.

Сначала изменяется интенсивность цветовых каналов:

\[
B'=B(1-0.25s)
\]

\[
G'=G(1-0.05s)
\]

\[
R'=R(1+0.15s)
\]

где \(s\) — сила эффекта, принимающая значения от 0 до 1.

Затем к каждому каналу добавляется случайный шум:

\[
I''=I'+\varepsilon
\]

Случайная величина \(\varepsilon\) генерируется из нормального распределения:

\[
\varepsilon\sim\mathcal{N}(0,\sigma^2)
\]

Здесь \(\sigma\) задаёт интенсивность шума и соответствует параметру `noise`.

В реализации используется генератор случайных чисел NumPy. После изменения цветовых каналов и добавления шума значения ограничиваются диапазоном от 0 до 255.

**Обоснование:** изменение соотношения каналов создаёт тёплую цветовую стилизацию, а случайные отклонения яркости формируют эффект плёночного зерна. Из-за случайной составляющей результаты разных запусков могут немного различаться.

### 4.6. Matte — белая матовая рамка

Фильтр создаёт мягкую белую овальную рамку по краям изображения.

Сначала для каждого пикселя рассчитывается расстояние до центра изображения. Координаты нормируются, чтобы маска могла быть рассчитана независимо от абсолютного разрешения.

Расстояние определяется формулой:

\[
d(x,y)=\sqrt{x^2+y^2}
\]

На основе расстояния и параметра радиуса строится маска:

\[
t=\operatorname{clip}\left(
\frac{d-r}{1-r},0,1
\right)
\]

\[
M=s\,t^p
\]

где:

- \(r\) — радиус центральной области;
- \(s\) — сила эффекта;
- \(p\) — параметр мягкости перехода;
- \(M\) — маска, определяющая интенсивность белой рамки.

Затем исходное изображение смешивается с белым цветом:

\[
I'=(1-M)I+255M
\]

Если \(M=0\), пиксель сохраняет исходный цвет. Если \(M=1\), пиксель становится белым.

По мере удаления от центральной области маска увеличивается, и изображение плавно смешивается с белым цветом.

**Обоснование:** маска позволяет управлять эффектом в зависимости от положения каждого пикселя. Использование расстояния до центра формирует овальную рамку, а степень маскирования задаёт плавность перехода.

### 4.7. Noise — эффект старой фотографии

Фильтр имитирует визуальные дефекты старой фотографии с помощью затемнения, случайного зерна, царапин, пыли и цветовой засветки.

#### Затемнение

Сначала яркость исходного изображения немного уменьшается:

\[
I_1=0.88I
\]

Это создаёт более тёмную основу для последующих эффектов.

#### Добавление зерна

К изображению добавляется случайный шум:

\[
I_2=I_1+\varepsilon
\]

где шум генерируется из нормального распределения:

\[
\varepsilon\sim\mathcal{N}(0,(24a)^2)
\]

Здесь \(a\) — параметр количества шума.

#### Формирование царапин

В программе создаются две двумерные маски: для светлых и тёмных царапин. Координаты линий постепенно изменяются с небольшими случайными отклонениями, поэтому царапины выглядят неровными.

Для сглаживания используется собственная функция `box_blur`, вычисляющая среднее значение в окрестности \(3\times3\):

\[
B(x,y)=\frac{1}{9}
\sum_{i=-1}^{1}\sum_{j=-1}^{1}
M(x+i,y+j)
\]

Здесь \(M\) — маска царапин, а \(B\) — сглаженная маска.

Светлые царапины добавляются к яркости изображения, а тёмные вычитаются из неё. Это создаёт неоднородные следы износа.

#### Добавление пыли

В случайных координатах создаются небольшие светлые пятна. Их яркость уменьшается по мере удаления от центра пятна, формируя мягкие пылевые точки.

#### Цветовая засветка

Для каждого пикселя вычисляется маска \(L(x,y)\), интенсивность которой зависит от расстояния до нижнего левого угла. Маска усиливается дополнительной экспоненциальной составляющей и несколько раз сглаживается.

Затем к цветовым каналам добавляются разные значения:

\[
B'=B+45L
\]

\[
G'=G+110L
\]

\[
R'=R+190L
\]

Увеличение красного и зелёного каналов создаёт оранжево-красный световой блик.

**Обоснование:** комбинация зерна, царапин, пыли и локальной цветовой засветки формирует несколько видов визуальных дефектов, характерных для стилизации под старую фотографию. Случайные элементы создаются заново при каждом запуске.

### 4.8. Neon — неоновое свечение контуров

Фильтр выделяет выраженные контуры изображения и добавляет к ним цветное свечение.

#### Шаг 1. Расчёт яркости

Цветное изображение преобразуется в карту яркости:

\[
Y=0.114B+0.587G+0.299R
\]

Это позволяет анализировать изменения интенсивности изображения независимо от отдельных цветовых компонентов.

#### Шаг 2. Сглаживание

К карте яркости дважды применяется собственная функция `box_blur`, усредняющая соседние значения в окрестности \(3\times3\).

Сглаживание уменьшает влияние мелких деталей перед вычислением градиента.

#### Шаг 3. Вычисление изменений яркости

Приближённые изменения яркости по горизонтали и вертикали рассчитываются методом центральных разностей:

\[
G_x(x,y)=\frac{Y(x+1,y)-Y(x-1,y)}{2}
\]

\[
G_y(x,y)=\frac{Y(x,y+1)-Y(x,y-1)}{2}
\]

Затем определяется величина градиента:

\[
E(x,y)=\sqrt{G_x(x,y)^2+G_y(x,y)^2}
\]

Большие значения \(E\) соответствуют резким изменениям яркости, которые часто возникают на границах объектов.

#### Шаг 4. Выделение сильных контуров

В качестве порога используется 78-й процентиль значений градиента, а для верхней границы нормализации — 99-й процентиль.

Значения между порогом и верхней границей нормализуются в диапазон от 0 до 1. Слабые изменения яркости подавляются, а более выраженные контуры сохраняются.

#### Шаг 5. Создание свечения

На основе маски контуров создаётся цветной слой свечения. Он многократно сглаживается функцией `box_blur`, после чего добавляется к исходному изображению.

Дополнительно формируется более тонкая яркая линия, усиливающая визуальную выраженность контуров.

**Обоснование:** приближённый градиент позволяет выделять границы объектов с помощью базовых математических операций над массивами. Размытие отдельного цветного слоя создаёт эффект свечения без использования готового фильтра выделения контуров OpenCV.

## 7. Чтение, сохранение и обработка ошибок

Функция `read_image` проверяет существование входного файла и загружает изображение с помощью `cv2.imread`. Если файл отсутствует, возникает `FileNotFoundError`. Если изображение не удалось прочитать, возникает `ValueError`.

Функция `save_image` создаёт родительскую папку для выходного файла и сохраняет результат с помощью `cv2.imwrite`. Если сохранить изображение не удалось, программа сообщает об ошибке.

В `main.py` выбранный фильтр создаётся через `ImageFilter.get_filter`. Затем к изображению применяется метод `apply` с параметрами, соответствующими выбранному фильтру. Ошибки чтения, некорректных значений и операций ввода-вывода перехватываются и выводятся пользователю.

## 8. Обоснование использования NumPy

Изображение является массивом чисел, поэтому многие преобразования можно выразить через операции над массивами:

- взвешенное сложение цветовых каналов;
- линейное смешивание изображения с цветом;
- умножение каналов на коэффициенты;
- применение двумерных масок;
- генерацию и добавление случайного шума;
- вычисление градиентов яркости;
- усреднение значений соседних пикселей.

NumPy позволяет выполнять арифметические операции сразу над массивами, что уменьшает необходимость использовать циклы Python для обработки каждого пикселя.

OpenCV используется для чтения и записи изображений. Основные алгоритмы преобразования реализованы самостоятельно с использованием NumPy; готовые высокоуровневые фильтры OpenCV для этих преобразований не применяются.

## 9. Ограничения реализации

1. Метод ближайшего соседа может создавать ступенчатые границы при увеличении изображения.
2. Случайный шум, царапины и пыль могут отличаться между запусками.
3. Функция `box_blur` использует циклы по пикселям, поэтому многократное сглаживание больших изображений может занимать заметное время.
4. Параметры художественных эффектов предназначены для визуальной стилизации и не являются точной физической моделью фотоплёнки.
5. После вычислений значения цветовых каналов ограничиваются диапазоном от 0 до 255.

## 10. Вывод

В ходе работы разработана библиотека обработки изображений, включающая восемь фильтров. Для изменения размера используется индексирование массива по методу ближайшего соседа, для цветовых преобразований — линейные комбинации каналов и смешивание пикселей, а для художественных эффектов — маски, случайные величины, локальное усреднение и приближённый градиент яркости.

Реализация демонстрирует, как базовые операции над матрицами изображений позволяют создавать геометрические, цветовые и художественные эффекты без использования готовых высокоуровневых фильтров OpenCV.
