# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

## Цель работы

Цель работы - реализовать библиотеку простых фильтров для обработки изображений на Python с использованием OpenCV и NumPy. Фильтры выполняются через базовые матричные операции над массивами изображения.

## Установка и запуск

1. Открыть PowerShell или командную строку.
2. Перейти в папку практической работы:

```bash
cd GusevDA/1_ImageProcessing
```

3. Установить библиотеки:

```bash
pip install -r requirements.txt
```

Если команда `pip` не работает, можно использовать:

```bash
python -m pip install -r requirements.txt
```

4. Запустить обработку всех фильтров:

```bash
python main.py --filter all --input input/02_woman_face.png --output output
```

Файл `input/02_woman_face.png` должен лежать в папке `input`.

## Примеры запуска отдельных фильтров

```bash
python main.py --filter gray --input input/02_woman_face.png --output output/gray.png
python main.py --filter antique --input input/02_woman_face.png --output output/antique.png
python main.py --filter resize --input input/02_woman_face.png --output output/resize.png
```

## Описание реализованных фильтров

### 1. Resize

Фильтр изменяет размер изображения без использования `cv2.resize()`. Для каждого пикселя нового изображения вычисляется соответствующая координата в старом изображении:

```text
x_old = x_new * old_width / new_width
y_old = y_new * old_height / new_height
```

После этого берется ближайший пиксель исходного изображения.

### 2. GrayScale

Фильтр переводит цветное изображение в оттенки серого по формуле яркости:

```text
Gray = 0.114 * B + 0.587 * G + 0.299 * R
```

Полученная яркость записывается во все три канала B, G и R.

### 3. Antique

Фильтр создает эффект старой фотографии. Для этого применяется сепия-преобразование:

```text
R' = 0.393R + 0.769G + 0.189B
G' = 0.349R + 0.686G + 0.168B
B' = 0.272R + 0.534G + 0.131B
```

После вычисления значения ограничиваются диапазоном от 0 до 255.

### 4. Fade Color

Фильтр выцветания уменьшает насыщенность изображения. Сначала изображение смешивается с серой версией, затем немного осветляется:

```text
Result = Image * (1 - a) + Gray * a
```

где `a` - коэффициент выцветания.

### 5. Film

Фильтр имитирует необычную пленку. Каналы изображения смешиваются между собой, часть красного канала ослабляется, зеленый усиливается, а синий получает инвертированный оттенок. Это дает эффект пленочного цветового сдвига.

### 6. Matte

Фильтр создает белую овальную рамку по краям фотографии. Для каждого пикселя вычисляется расстояние от центра:

```text
d = ((x - cx) / rx)^2 + ((y - cy) / ry)^2
```

Чем дальше пиксель от центра, тем сильнее он смешивается с белым цветом.

### 7. Scratches and Noise

Фильтр добавляет шум и царапины для эффекта состаренной фотографии. Шум создается случайной матрицей с нормальным распределением, которая прибавляется к яркости пикселей. Царапины рисуются тонкими светлыми линиями поверх изображения.

### 8. Neon

Фильтр выделяет контуры объектов и подсвечивает их. Сначала изображение переводится в серый цвет. Затем вычисляются простые градиенты по горизонтали и вертикали:

```text
Gx = I(x + 1, y) - I(x - 1, y)
Gy = I(x, y + 1) - I(x, y - 1)
```

Если величина градиента больше порога, пиксель считается контуром. Контуры дополнительно размываются простой матричной операцией и подсвечиваются неоновым цветом.

## Файлы программы

- `filters.py` - библиотека фильтров.
- `main.py` - скрипт запуска с аргументами командной строки.
- `input/` - папка с исходным изображением.
- `output/` - папка с результатами обработки.

## Простая структура кода

В файле `filters.py` каждый фильтр реализован отдельной функцией. В файле `main.py` выполняются четыре действия: разбираются аргументы командной строки, читается изображение, применяется выбранный фильтр и сохраняется результат.
