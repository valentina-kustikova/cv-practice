# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

Консольная python-утилита для применения фильтров (представлено 8 вариантов) к цветным изображениям

## Требования

- Python 3.8+
- NumPy (матричные операции в фильтрах)
- OpenCV (чтение и запись изображений)

### Установка

```bash
pip install numpy opencv-python
```

### Запуск

```bash
python main.py -i <input-filepath> -o <output-filepath> -f <filter-name> [params]
```

### Файловая структура

```text
1_ImageProcessing/
├── main.py          # точка входа: парсинг аргументов, чтение, применение фильтра, сохранение
├── filters.py       # базовый класс ImageFilter и реализации фильтров-наследников
├── img/             # тестовые изображения
└── README.md
```

## Описание фильтров
### Resize - изменение размера изображения

```bash
python main.py -i <input-filepath> -o <output-filepath> -f resize --width 1920 --height 1080
```
Принимает обязательные параметры ширины и высоты изображения.

**Алгоритм**:\
Строит карту индексов желаемого разрешения, после чего формирует новое изображение с помощью метода ближайшего соседа (*interpolation=nearest*)

### RGB2GrayScale - перевод в оттенки серого

```bash
python main.py -i <input-filepath> -o <output-filepath> -f grayscale
```
Используется без параметров.

**Алгоритм**:\
Переводит цвет каждого пикселя в интенсивность по формуле ([ITU-R Rec. 709](https://en.wikipedia.org/wiki/Rec._709)):

```text
Y = 0.2126 * R + 0.7152 * G + 0.0722 * B
```

### Antique - эффект "антиквариат"

```bash
python main.py -i <input-filepath> -o <output-filepath> -f antique --intensity 0.8
```
Принимает параметр интенсивности (от 0 до 1) применения фильтра. Значение по умолчанию: `0.8`.

**Алгоритм**:\
К изображению применяется стандартная матрица сепии:

```text
R' = 0.393 * R + 0.769 * G + 0.189 * B
G' = 0.349 * R + 0.686 * G + 0.168 * B
B' = 0.272 * R + 0.534 * G + 0.131 * B
```

Модифицированное изображение смешивается с оригинальным с заданным параметром интенсивности сепии (линейная интерполяция).

### FadeColor - выцветание

```bash
python main.py -i <input-filepath> -o <output-filepath> -f fadecolor --strength 0.5
```
Принимает параметр интенсивности (от 0 до 1) применения фильтра. Значение по умолчанию: `0.5`.

**Алгоритм:**\
Изображение смешивается (линейная интерполяция) с полутоновой версией (обесцвечивание), после чего аналогичным образом подмешивается белый цвет с весовым коэффициентом `0.3` (имитация выгорания).

### Tape - имитация ИК-пленки

```bash
python main.py -i <input-filepath> -o <output-filepath> -f tape --grain 0.1
```
Принимает параметр зернистости (от 0 до 1). Значение по умолчанию: `0.1`.

**Алгоритм:**\
Попиксельно применяет матричное преобразование, имитирующее ИК-пленку для цифровых фотографий:

```text
R' = 0.2 * R + 1.3 * G - 0.5 * B
G' = 0.0 * R + 0.4 * G + 0.4 * B
B' = 0.0 * R + 0.0 * G + 1.0 * B
```

Поверх изображения с фильтром добавляется пленочное зерно с помощью добавления нормального цветового шума со стандартным отклонением `grain * 255`.

### Matte - наложение овальной маски

```bash
python main.py -i <input-filepath> -o <output-filepath> -f matte --border 0.05 --feather 0.05 --color 255 255 255
```
Принимает величину отступа (от 0 до 1) маски от границы изображения `--border`, толщину переходной границы ("плавность", от 0 до 1) `--feather` и цвет маски `--color` (BRG). Значения по умолчанию: `border = 0.05`, `feather = 0.05`, `color = [255 255 255]`.

**Алгоритм:**\
Размечает эллипс, внутренность которого заполняется пикселями изображения, внешность - заливается цветом рамки. Во внутренней окрестности границы изображение и маска смешиваются (линейная интерполяция).

### Noise - добавление царапин и шума

```bash
python main.py -i <input-filepath> -o <output-filepath> -f noise --scratch_count 7 --noise_level 0.05
```
Принимает параметры числа царапин и уровня шума. Значения по умолчанию: `scratch_count = 7`, `noise_level = 0.05`.

**Алгоритм:**\
Царапины добавляются в случайные столбцы изображения как вертикальные полосы случайной длины. Цвет полосы - черный или белый - выбирается равновероятно. С вероятностью `noise_level` каждый пиксель заменяется на чисто белый или чисто черный (с равной вероятностью), что имитирует добавление шума.

### Neon - неоновый эффект

```bash
python main.py -i <input-filepath> -o <output-filepath> -f neon --threshold 50 --glow 0.8 --color 255 0 135
```
Принимает параметры порога выделения границ для оператора Собеля, интенсивности свечения (от 0 до 1) и цвета неона (BRG). Значения по умолчанию: `threshold = 50`, `glow = 0.8`, `color = [255 255 255]`

**Алгоритм:**\
Изображение переводится в оттенки серого по рассмотренному выше алгоритму. К полутоновому изображению применяется упрощенный оператор Собеля (центральная разность), выделяются границы, которые окрашиваются в выбранный цвет. Эффект размытия контуров добавляется через 6-кратное усреднение по окрестности 3x3, реализованной с помощью `np.roll`.
