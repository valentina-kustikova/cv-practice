## Описание математических алгоритмов и фильтров

Изображение в OpenCV хранится в порядке каналов **BGR** (Blue, Green, Red). Значения пикселей находятся в диапазоне `[0, 255]`. Архитектура использует абстрактный класс `ImageFilter` с фабричным методом `get_filter`.

### Изменение разрешения (Resize)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/resize.jpg -f resize --width 300 --height 200
```
Принимает обязательные параметры `--width` и `--height`.

2. **Алгоритм**:
Используется метод **билинейной интерполяции**. Для каждого пикселя нового изображения вычисляются координаты в исходном изображении с помощью `np.linspace`. Затем берутся 4 ближайших соседа (сверху-слева, сверху-справа, снизу-слева, снизу-справа). Итоговое значение вычисляется как взвешенная сумма:
`I(x, y) = (1 - dy) * [(1 - dx) * I(x0, y0) + dx * I(x1, y0)] + dy * [(1 - dx) * I(x0, y1) + dx * I(x1, y1)]`
где `dx` и `dy` — дробные части координат.

### Перевод в оттенки серого (RGB2GrayScale)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/gray.jpg -f gray
```
Не принимает параметров.

2. **Алгоритм**:
Перевод в одноканальное изображение по стандарту **ITU-R BT.601**. В коде используется матричное умножение изображения на вектор весов:
`Y = 0.114 * B + 0.587 * G + 0.299 * R`
Коэффициенты отражают различную чувствительность человеческого глаза к разным цветам (зеленый глаз воспринимает ярче всего).

### Эффект "Антиквариат" (Antique)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/antique.jpg -f antique --intensity 0.9
```
Принимает опциональный параметр `--intensity` (от 0 до 1) — сила эффекта (по умолчанию 0.85).

2. **Алгоритм**:
1. **Сепия:** Применяется линейное преобразование с использованием матрицы сепии (умножение `img @ sepia_mat.T`), которое придает изображению коричневато-желтый оттенок.
2. **Виньетка:** Вычисляется расстояние от центра до каждого пикселя. Создается маска затемнения краев по формуле `mask = 1.0 - 0.5 * dist`.
3. Результат смешивается с оригиналом с заданной интенсивностью.

### Выцветание (Fade Color)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/fade.jpg -f fade --strength 0.5
```
Принимает опциональный параметр `--strength` (от 0 до 1) — степень выцветания (по умолчанию 0.35).

2. **Алгоритм**:
Снижает контраст и насыщенность:
1. Цвета смещаются к белому: `I' = I * (1 - fade) + 255 * fade`.
2. Вычисляется среднее значение по трем каналам (градация серого). Цветность уменьшается за счет смешивания текущего значения со средним:
`I'' = mean + (I' - mean) * (1.0 - fade * 0.5)`

### Имитация пленки (Film)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/film.jpg -f film --grain 20.0 --tint 0.6
```
Принимает опциональные параметры `--grain` (уровень шума, по умолчанию 15.0) и `--tint` (сила эффекта, по умолчанию 0.4).

2. **Алгоритм**:
Имитирует инфракрасную пленку. Используется матричное умножение на специальную цветовую матрицу, которая переназначает каналы (например, красный становится более чувствительным к зеленому, а синий уходит в тени). Дополнительно накладывается гауссов шум для имитации зернистости пленки.

### Наложение овальной маски (Matte)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/matte.jpg -f matte --radius 0.8 --softness 0.1
```
Принимает опциональные параметры `--radius` (радиус от 0.1 до 1.0, по умолчанию 0.75) и `--softness` (плавность перехода, по умолчанию 0.2).

2. **Алгоритм**:
Создает белые края. Строится нормированное эллиптическое расстояние от центра:
`d = sqrt(((x - cx) / (cx * radius))^2 + ((y - cy) / (cy * radius))^2)`
Маска создается с помощью полинома плавного перехода (Smoothstep):
`t = clip((d - 1.0 + softness) / softness, 0, 1)`
`mask = t^2 * (3 - 2*t)`
Это позволяет сделать границу овала максимально плавной, без резких переходов.

### Состаривание фотографии (ScratchesNoise)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/scratches.jpg -f scratches --n-scratches 30 --noise-level 25.0
```
Принимает опциональные параметры `--n-scratches` (количество царапин, по умолчанию 20) и `--noise-level` (уровень шума, по умолчанию 15.0).

2. **Алгоритм**:
1. **Шум:** К изображению прибавляется нормально распределенный шум.
2. **Царапины:** Генерируются случайные линии. Для каждой царапины генерируется начальная точка, длина и случайное отклонение по X. Точки линии вычисляются через `np.linspace`, а их яркость устанавливается с помощью fancy-индексации в одномерную маску, которая затем накладывается на изображение. Весь процесс векторизован.

### Неоновое свечение (Neon)
1. **Использование**:
```bash
python main.py -i input/test.jpg -o output/neon.jpg -f neon --threshold 30.0 --glow-intensity 2.0
```
Принимает опциональные параметры `--threshold` (порог градиента, по умолчанию 40.0) и `--glow-intensity` (яркость свечения, по умолчанию 1.5).

2. **Алгоритм**:
1. Изображение переводится в оттенки серого.
2. Вычисляется градиент яркости с помощью **оператора Собеля** вручную через срезы матрицы `np.pad` и вычитания соседних элементов.
3. Вычисляется модуль градиента: `mag = sqrt(gx^2 + gy^2)`.
4. Слабые градиенты отсекаются порогом.
5. Оригинал приглушается (умножается на 0.25), а поверх накладываются контуры с неоновым свечением.
