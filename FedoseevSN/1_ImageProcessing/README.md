## Установка и запуск

Для работы программы необходимы Python, NumPy и OpenCV.

Установка зависимостей:

```bash
pip install opencv-python numpy
```

Общий формат запуска:

```bash
python main.py -i input/test.jpg -o output/result.jpg -f <filter> [параметры]
```

Параметры `-i` и `-o` задают входной и выходной файлы, а `-f` определяет применяемый фильтр.

Изображения OpenCV хранит в формате BGR. Значения цветовых каналов находятся в диапазоне от 0 до 255.

## Описание фильтров и алгоритмов

### 1. Изменение размера (Resize)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/resize.jpg -f resize --width 300 --height 200
```

Принимает обязательные параметры `--width` и `--height`, задающие размеры итогового изображения.

**Алгоритм:**

Используется билинейная интерполяция. Для каждого пикселя нового изображения определяются соответствующие координаты в исходном изображении. Затем выбираются четыре соседних пикселя и вычисляется их взвешенная сумма.

Сначала выполняется интерполяция по горизонтали, затем по вертикали. Дробные части координат `dx` и `dy` определяют веса соседних пикселей.

### 2. Перевод в оттенки серого (Gray)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/gray.jpg -f gray
```

Дополнительные параметры не требуются.

**Алгоритм:**

Каждый цветной пиксель преобразуется в одно значение яркости. Для этого используется взвешенная сумма трёх цветовых каналов:

`Y = 0.114 * B + 0.587 * G + 0.299 * R`

Коэффициенты учитывают различную воспринимаемую яркость синего, зелёного и красного цветов. Вычисления выполняются сразу для всего изображения с помощью матричного умножения NumPy.

### 3. Эффект антиквариата (Antique)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/antique.jpg -f antique --intensity 0.85 --vignette 0.55
```

Параметры:
- `--intensity` — интенсивность эффекта сепии от 0 до 1 (по умолчанию 0.85).
- `--vignette` — интенсивность затемнения краёв (по умолчанию 0.55).

**Алгоритм:**

Сначала к изображению применяется матрица сепии, изменяющая соотношение цветовых каналов и придающая фотографии коричневатый оттенок.

Затем результат смешивается с исходным изображением в соответствии с параметром `intensity`.

Для создания виньетки вычисляется расстояние каждого пикселя от центра изображения. На его основе формируется маска затемнения:

`mask = clip(1 - vignette * dist^2, 0, 1)`

В результате центральная часть изображения сохраняет яркость, а края затемняются.

### 4. Эффект выцветания (Fade)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/fade.jpg -f fade --strength 0.35
```

Параметр `--strength` задаёт интенсивность эффекта от 0 до 1. По умолчанию равен 0.35.

**Алгоритм:**

Сначала цветовые значения смешиваются с белым цветом:

`I' = I * (1 - strength) + 255 * strength`

Затем вычисляется среднее значение цветовых каналов. Цветность уменьшается путём смешивания исходных значений с этим средним. В результате изображение становится светлее и менее насыщенным.

### 5. Имитация плёнки (Film)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/film.jpg -f film --grain 15 --tint 0.4
```

Параметры:
- `--grain` — уровень плёночного зерна (по умолчанию 15.0).
- `--tint` — интенсивность цветового преобразования от 0 до 1 (по умолчанию 0.4).

**Алгоритм:**

Для изменения цветового оттенка используется специальная матрица преобразования. Исходное изображение смешивается с результатом матричного умножения, что позволяет получить эффект необычной цветопередачи.

Дополнительно генерируется случайный гауссов шум с нулевым средним и заданным параметром разброса `grain`. Он добавляется к изображению для имитации плёночного зерна.

### 6. Овальная маска (Matte)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/matte.jpg -f matte --radius 0.75 --softness 0.2
```

Параметры:
- `--radius` — размер овальной области от 0.1 до 1.0 (по умолчанию 0.75).
- `--softness` — плавность перехода к белой области (по умолчанию 0.2).

**Алгоритм:**

В центре изображения строится эллипс. Для каждого пикселя вычисляется нормированное расстояние до центра с учётом радиуса эллипса.

На основе расстояния формируется маска. Внутри овальной области изображение сохраняется, а снаружи постепенно заменяется белым цветом.

Для сглаживания границы используется функция Smoothstep:

`t = clip((d - 1 + softness) / softness, 0, 1)`

`weight = t^2 * (3 - 2 * t)`

Это позволяет избежать резкой границы между изображением и заливкой.

### 7. Состаривание изображения (Scratches)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/scratches.jpg -f scratches --noise-level 15
```

Параметр `--noise-level` задаёт уровень шума (по умолчанию 15.0).

**Алгоритм:**

Для имитации старой фотографии к исходному изображению добавляется гауссов шум с нулевым средним и заданным уровнем разброса.

Дополнительно создаётся случайная маска пыли. Небольшая часть пикселей случайным образом становится светлее или темнее. Это создаёт эффект пылинок и дефектов старой плёнки.

### 8. Неоновое свечение (Neon)

Пример использования:

```bash
python main.py -i input/test.jpg -o output/neon.jpg -f neon --threshold 40 --glow-intensity 1.5 --sigma 4
```

Параметры:
- `--threshold` — порог выделения границ (по умолчанию 40.0).
- `--glow-intensity` — интенсивность свечения (по умолчанию 1.5).
- `--sigma` — параметр гауссова размытия (по умолчанию 4.0).

**Алгоритм:**

Сначала изображение переводится в оттенки серого. Затем вручную вычисляются горизонтальная и вертикальная составляющие градиента с помощью оператора Собеля.

Величина градиента определяется по формуле:

`G = sqrt(Gx^2 + Gy^2)`

Пиксели, значение градиента которых превышает заданный порог, становятся контурами.

Для создания свечения контуры окрашиваются в заданные цвета и размываются с помощью гауссова фильтра. Размытие реализовано вручную с использованием одномерного гауссова ядра: сначала по горизонтали, затем по вертикали.

Итоговое изображение складывается из затемнённого оригинала, размытого свечения и чётких контуров.

## Архитектура программы

Все фильтры наследуются от абстрактного класса `ImageFilter` и реализуют метод `apply_filter(image)`.

Для создания нужного фильтра используется статический метод `get_filter()`, который выбирает класс по переданному названию и создаёт его экземпляр с необходимыми параметрами.

Файл `main.py` отвечает за:
1. Разбор аргументов командной строки с помощью `argparse`.
2. Чтение входного изображения через `cv2.imread`.
3. Создание и применение выбранного фильтра.
4. Создание выходной директории при необходимости.
5. Сохранение результата через `cv2.imwrite`.

Ошибки чтения, обработки и сохранения изображения перехватываются и выводятся в консоль.
