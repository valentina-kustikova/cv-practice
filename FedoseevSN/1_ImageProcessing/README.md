## Архитектура

Все фильтры наследуются от абстрактного класса `ImageFilter`, который предоставляет:

- **статический фабричный метод** `get_filter(filter_name, **params)` — возвращает экземпляр нужного фильтра по его имени;
- **абстрактный метод** `apply_filter(image)` — применяет преобразование к изображению (массив NumPy, формат BGR, `uint8`).

Такая архитектура позволяет добавлять новые фильтры, не меняя код в `main.py`: достаточно унаследоваться от `ImageFilter` и зарегистрировать класс в словаре `registry` фабрики.

## Фильтры

### 1. `resize` — изменение разрешения

Реализован методом **ближайшего соседа** (nearest neighbour). Пусть исходное изображение имеет размеры `H * W`, целевое — `H' * W'`. Координаты нового пикселя `(i, j)` берутся из исходного по формулам:

```
y = floor(i * H / H')
x = floor(j * W / W')
```

Реализация — целочисленное индексирование массива NumPy:

```python
y_idx = np.clip((np.arange(H') * H / H').astype(int), 0, H - 1)
x_idx = np.clip((np.arange(W') * W / W').astype(int), 0, W - 1)
result = image[y_idx][:, x_idx]
```

Метод быстрый, но при сильном увеличении даёт «ступенчатые» края (эффект пикселизации).

**Параметры:**
- `--width` (int) — целевая ширина;
- `--height` (int) — целевая высота.

**Пример:**
```bash
python main.py -i input/test.jpg -o output/resize.jpg -f resize --width 300 --height 200
```

### 2. `gray` — оттенки серого

Линейная комбинация каналов по стандарту **ITU-R BT.601**:

```
Y = 0.299*R + 0.587*G + 0.114*B
```

Коэффициенты отражают разную чувствительность человеческого глаза к красному, зелёному и синему: зелёный даёт наибольший вклад в воспринимаемую яркость, синий — наименьший.

На выходе — одноканальное изображение `uint8`.

**Пример:**
```bash
python main.py -i input/test.jpg -o output/gray.jpg -f gray
```

### 3. `antique` — эффект «антиквариат»

Состоит из трёх последовательных шагов.

**Шаг 1. Тонирование в сепию.** Линейное преобразование каналов:

```
R' = 0.393*R + 0.769*G + 0.189*B
G' = 0.349*R + 0.686*G + 0.168*B
B' = 0.272*R + 0.534*G + 0.131*B
```

Матрица подобрана так, чтобы все цвета приобрели тёплый коричневато-жёлтый оттенок, характерный для старых фотографий.

**Шаг 2. Гамма-коррекция.** Степенное преобразование яркости:

```
I_out = 255 * (I / 255)^γ,   γ = 1.2
```

При `γ > 1` значения яркости уменьшаются — изображение темнеет, контраст в тенях растёт.

**Шаг 3. Виньетка.** Затемнение к краям по закону:

```
v(x, y) = 1 − 0.5 * d(x, y) / d_max
d(x, y) = √((x − c_x)^2 + (y − c_y)^2)
```

где `(c_x, c_y)` — центр изображения, `d_max` — расстояние до угла. В центре `v = 1`, к краям снижается до `0.5`.

Результат смешивается с оригиналом по параметру `intensity`:
```
I_final = (1 − t)*I + t*I_antique
```

**Параметры:**
- `--intensity` (float, 0…1, по умолчанию 1.0) — сила эффекта.

### 4. `fade` — выцветание

Два действия.

**Шаг 1. Поднятие теней.** Смешивание с белым:
```
I' = I + (255 − I)*s
```

При `s = 0` — оригинал, при `s = 1` — белое изображение.

**Шаг 2. Снижение насыщенности.** Для каждого пикселя считается среднее по каналам, и отклонение от среднего сжимается:
```
m = mean(I')
I'' = m + (I' − m)*(1 − s/2)
```

Коэффициент `(1 − s/2)` меньше единицы, поэтому цветность уменьшается.

**Параметры:**
- `--strength` (float, 0…1, по умолчанию 0.3) — сила выцветания.

### 5. `film` — имитация инфракрасной плёнки

Инфракрасная плёнка регистрирует ближний ИК-диапазон, в котором растительность отражает сильно, а небо — слабо. Это даёт характерные «марсианские» оттенки. В грубом приближении эффект достигается перестановкой и масштабированием каналов:

```
R' = 1.3*G
G' = 0.8*R
B' = 0.5*B
```

Дополнительно накладывается гауссов шум `N(0, σ^2)` с σ = `grain`, имитирующий зернистость плёнки:

```
I_out = (1 − t)*I + t*I_infrared + N(0, σ^2)
```

**Параметры:**
- `--grain` (float, по умолчанию 15.0) — σ шума;
- `--tint` (float, 0…1, по умолчанию 0.6) — сила инфракрасного оттенка.

### 6. `matte` — овальная рамка

Вокруг центральной части изображения строится эллиптическая маска. Расстояние до центра нормируется на полуоси:

```
r(x, y) = √( ((x − c_x) / r_x)^2 + ((y − c_y) / r_y)^2 )
r_x = c_x*(1 − b),   r_y = c_y*(1 − b)
```

- `r < 1` — внутри эллипса;
- `r = 1` — на границе;
- `r > 1` — снаружи.

Маска получается плавной:

```
m = clip( (1 − r) / s + 0.5, 0, 1 )
```

где `s` — параметр `softness`. Внутри маски `m ≈ 1`, снаружи `≈ 0`. Итог:

```
I' = m*I + (1 − m)*255
```

Область вне эллипса заменяется белым.

**Параметры:**
- `--border` (float, 0…0.49, по умолчанию 0.1) — доля, на которую эллипс меньше половины изображения;
- `--softness` (float, по умолчанию 0.05) — ширина плавного перехода.

### 7. `scratches` — царапины и шум

Имитация состаренной фотографии.

**Шум.** Аддитивный гауссов шум `N(0, σ^2)` с σ = `noise_level`:
```
I' = I + N(0, σ^2)
```

**Царапины.** Рисуются `n` тонких ярких линий. Для каждой:
- случайная начальная точка `(x_0, y_0)`;
- длина `L ∈ [H/4, H]`;
- угол `α = π/2 + U(−0.3, 0.3)` — почти вертикально, с небольшим наклоном;
- яркость `B ∈ [180, 255]`.

Точки линии — параметрическое уравнение:
```
x(t) = x_0 + t*cos α
y(t) = y_0 + t*sin α,   t = 0..L−1
```

Пиксели вне изображения игнорируются.

**Параметры:**
- `--n-scratches` (int, по умолчанию 15) — число царапин;
- `--noise-level` (float, по умолчанию 20.0) — σ шума.

### 8. `neon` — неоновое свечение

Выделение контуров объектов и их подсветка цветным ореолом.

**Шаг 1. Яркость.** По BT.601:
```
Y = 0.299*R + 0.587*G + 0.114*B
```

**Шаг 2. Градиент.** Численно через центральные разности (`np.gradient`):
```
g_x(x, y) ≈ (Y(x+1, y) − Y(x−1, y)) / 2
g_y(x, y) ≈ (Y(x, y+1) − Y(x, y−1)) / 2
```

Модуль градиента:
```
M = √(g_x^2 + g_y^2)
```

**Шаг 3. Порог.** Слабые перепады отсекаются:
```
E = max(M − T, 0)
```
где `T` — параметр `threshold`. Значения нормируются в `[0, 255]`.

**Шаг 4. Свечение.** К каждому пикселю применяется операция, аналогичная морфологической дилатации: берётся максимум из окрестности радиуса 3. Реализовано через сдвиги массива (`np.roll`) и `np.maximum`:
```
G(x, y) = max( E(x+dx, y+dy) )  для  dx, dy ∈ [−3, 3]
```

**Шаг 5. Цветной слой.** Неоновый оттенок — розово-голубой:
```
R_neon = G
G_neon = 0.3*G
B_neon = 0.9*G
```

**Шаг 6. Смешивание** с оригиналом по параметру `glow_intensity`:
```
I_out = (1 − k)*I + k*I_neon
```

**Параметры:**
- `--threshold` (float, по умолчанию 50.0) — порог отсечения слабых градиентов;
- `--glow-intensity` (float, 0…1, по умолчанию 0.8) — сила неонового слоя.

## Обработка ошибок

- Если файл не найден или не читается — `FileNotFoundError` с сообщением.
- Если для `resize` не указаны `--width` и `--height` — `ValueError`.
- Если фильтр неизвестен — `argparse` отказывается работать и выводит список допустимых значений.
- Если не удалось сохранить результат — `IOError`.

Все ошибки печатаются в `stderr`, процесс завершается с кодом 1.
