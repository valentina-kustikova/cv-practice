# Практическая работа №2 — классификация изображений с Bag of Visual Words

## 1. Цель работы

Разработать приложение для классификации фотографий архитектурных достопримечательностей на основе подхода **Bag of Visual Words (BoW, мешок визуальных слов)**. Приложение поддерживает классические локальные дескрипторы OpenCV, признаки сверточных нейронных сетей PyTorch с произвольного заданного слоя и методы машинного обучения из `scikit-learn`.

Реализованы следующие способы извлечения признаков:

| Тип | Метод (флаг CLI) | Размерность дескриптора | Источник признаков |
|---|---|---:|---|
| Классический | SIFT (`sift`) | 128 | Локальные ключевые точки OpenCV (`cv2.SIFT_create`) |
| Классический | ORB (`kaze`) | 256 | Распакованные бинарные дескрипторы ORB (`cv2.ORB_create`, используется для совместимости с OpenCV 5.0.0) |
| CNN | ResNet18 (`resnet18`) | 512 / 256 | Пространственная карта признаков выбранного слоя (`layer4` / `layer3`) через `register_forward_hook` |
| CNN | ConvNeXt-Tiny (`convnext_tiny`) | 768 / 384 | Пространственная карта признаков выбранного слоя (`features.7` / `features.5`) через `register_forward_hook` |

Для классификации BoW-гистограмм поддерживаются **SVM** (`LinearSVC`, по умолчанию) и **Random Forest** (`RandomForestClassifier`).

## 5. Общий принцип Bag of Visual Words

Пусть для изображения извлечено множество локальных дескрипторов:

$$
D = \{d_1,d_2,\ldots,d_N\}, \qquad d_i\in\mathbb{R}^{p}.
$$

### 5.1. Построение визуального словаря

Дескрипторы тренировочных изображений объединяются в общую матрицу (с ограничением выборки до `max_samples = 200 000` для контроля потребления оперативной памяти). Алгоритм `MiniBatchKMeans` разбивает их на $K$ кластеров (`--clusters`). Центр каждого кластера интерпретируется как визуальное слово:

$$
V=\{\mu_1,\mu_2,\ldots,\mu_K\}.
$$

На каждой итерации выполняются два шага:

1. **Назначение кластеров:** каждый дескриптор относится к ближайшему центру по евклидову расстоянию:

$$
q(d_i)=\arg\min_{j\in\{1,\ldots,K\}}\|d_i-\mu_j\|_2^2.
$$

2. **Обновление центров:** центр кластера пересчитывается как среднее отнесённых к нему дескрипторов:

$$
\mu_j=\frac{1}{|C_j|}\sum_{d_i\in C_j}d_i.
$$

### 5.2. Построение и нормализация BoW-гистограммы

После построения словаря все дескрипторы изображения назначаются ближайшим визуальным словам. Подсчитывается частота попадания в каждый кластер:

$$
h_j=\sum_{i=1}^{N}\mathbb{1}[q(d_i)=j],\qquad j=1,\ldots,K.
$$

Для повышения устойчивости к доминирующим фоновым визуальным словам (небо, листва, асфальт) применяется **L1-нормировка с последующей степенной (Root) и L2-нормализацией**:

$$
p_j=\frac{h_j}{\sum_{r=1}^{K}h_r}, \qquad \tilde h_j=\sqrt{p_j}, \qquad \hat h_j=\frac{\tilde h_j}{\|\tilde h\|_2}.
$$

Евклидова (L2) норма ненулевой гистограммы равна единице. Если дескрипторы не найдены, возвращается нулевая гистограмма.

### 5.3. Обучение классификатора

Для каждого тренировочного изображения строится вектор $\hat h$. Матрица гистограмм подаётся на вход классификатора (`LinearSVC(C=1.0)` или `RandomForestClassifier`). Словарь K-Means, кодировщик меток (`LabelEncoder`), обученный классификатор и конфигурация экстрактора сохраняются в едином файле `.joblib`.

## 6. Реализация извлечения признаков

### 6.1. Классические методы OpenCV

- **SIFT (`SIFTExtractor`):** изображение переводится в оттенки серого, после чего `cv2.SIFT_create(nfeatures=max_features)` обнаруживает ключевые точки и вычисляет 128-мерные вещественные дескрипторы, инвариантные к масштабу и повороту.
- **ORB (`KAZEExtractor`):** в среде используется сборка **OpenCV 5.0.0**, из которой классический детектор `KAZE` исключён. Для сохранения совместимости с интерфейсом реализован детектор `cv2.ORB_create(nfeatures=max_features)`, чьи 32-байтовые бинарные дескрипторы распаковываются через `np.unpackbits` в 256-мерные векторы `float32`.

### 6.2. CNN-модели PyTorch

Для сверточных сетей реализована явная предобработка средствами OpenCV и NumPy, согласованная со статистикой ImageNet:

1. Чтение изображения в формате BGR и перевод цветовых каналов `BGR -> RGB`.
2. Масштабирование до фиксированного размера `224×224` (`cv2.INTER_AREA`) без центрального кропа (`CenterCrop`), чтобы сохранить верхние и боковые архитектурные детали зданий.
3. Приведение значений пикселей в диапазон `[0, 1]` (`float32`).
4. Поканальная нормализация параметрами ImageNet:

$$
\mu=(0.485,0.456,0.406),\qquad
\sigma=(0.229,0.224,0.225),
$$

$$
x'_c=\frac{x_c-\mu_c}{\sigma_c}.
$$

Извлечение выполняется в режиме `eval()` и `torch.inference_mode()` с любого заданного пользователем слоя (`--layer`) при помощи `register_forward_hook`. Сверточная карта признаков размера `[1, C, H, W]` разворачивается в матрицу локальных дескрипторов `[H*W, C]` без принудительного пространственного пулинга, после чего каждый вектор нормируется по L2-норме.

## 8. Запуск приложения

Все команды выполняются из директории `MoskaevVA/2_ImageClassification/`.

### 8.1. Обучение (`train`)

```powershell
# ConvNeXt-Tiny (слой features.5) + Linear SVM (лучшая конфигурация)
python main.py train --data "DATASET" --extractor convnext_tiny --layer features.5 --clusters 512 --classifier svm --device cuda --model outputs/convnext_f5.joblib

# ConvNeXt-Tiny (слой features.7) + Linear SVM
python main.py train --data "DATASET" --extractor convnext_tiny --layer features.7 --clusters 256 --classifier svm --device cuda --model outputs/convnext_tiny.joblib

# ResNet18 (слой layer4) + Linear SVM
python main.py train --data "DATASET" --extractor resnet18 --layer layer4 --clusters 256 --classifier svm --device cuda --model outputs/resnet18.joblib

# SIFT + Linear SVM
python main.py train --data "DATASET" --extractor sift --clusters 128 --classifier svm --model outputs/sift.joblib

# ORB (режим kaze для OpenCV 5.0) + Linear SVM
python main.py train --data "DATASET" --extractor kaze --clusters 128 --classifier svm --model outputs/kaze.joblib
```

### 8.2. Тестирование (`test`)

```powershell
python main.py test --data "DATASET" --model outputs/convnext_f5.joblib --device cuda --output outputs/convnext_f5
```

В консоль выводятся общая точность (`Accuracy`) и таблица метрик по всем 29 классам (`precision`, `recall`, `f1-score`), а в директорию `--output` сохраняются файлы `test_predictions.csv` и `classification_report.txt`.

### 8.3. Классификация одного изображения (`predict`)

```powershell
python main.py predict --image "DATASET\test\NNSUDataset\01_NizhnyNovgorodKremlin\example.jpg" --model outputs/convnext_f5.joblib --device cuda --show
```

В консоль выводится предсказанный класс, а в `outputs/prediction.png` сохраняется совместная визуализация изображения и его BoW-гистограммы (при указании флага `--show` график дополнительно открывается в интерактивном окне).

## 9. Экспериментальные результаты и выводы

Эксперименты проведены на полном тестовом наборе данных из **29 классов** (1 333 изображения в `trainval`, 2 354 изображения в `test`):

| Экстрактор | Слой CNN | Классификатор | Размер словаря | Accuracy на test | Macro F1 | Weighted F1 |
|---|---|---|---:|---:|---:|---:|
| **ConvNeXt-Tiny** | `features.5` | Linear SVM | 512 | **0.7821 (78.21%)** | **0.78** | **0.81** |
| **ConvNeXt-Tiny** | `features.7` | Linear SVM | 256 | **0.7120 (71.20%)** | **0.70** | **0.73** |
| **ResNet18** | `layer4` | Linear SVM | 256 | **0.6538 (65.38%)** | **0.65** | **0.67** |
| **ResNet18** | `layer3` | Linear SVM | 512 | **0.5748 (57.48%)** | **0.55** | **0.59** |
| **SIFT** | — | Linear SVM | 128 | **0.2073 (20.73%)** | **0.19** | **0.19** |
| **ORB (вместо KAZE)** | — | Linear SVM | 128 | **0.1181 (11.81%)** | **0.10** | **0.10** |

### Анализ результатов:

1. **Преимущество CNN-признаков над классическими дескрипторами:** нейросетевые экстракторы (`ConvNeXt-Tiny` — 78.21%, `ResNet18` — 65.38%) многократно превосходят классический `SIFT` (20.73%). Локальные градиентные дескрипторы чувствительны к ракурсу съёмки, погодным условиям и перекрытиям, тогда как сверточные фильтры ImageNet кодируют устойчивые семантические части архитектурных объектов (купола, арки, колонны, фасады).
2. **Влияние архитектуры CNN и пространственного разрешения карты признаков:** переход от `ResNet18` к современной архитектуре `ConvNeXt-Tiny` увеличил точность на `layer4`/`features.7` с 65.38% до 71.20%. Использование предпоследнего блока `features.5` с пространственной сеткой `14×14` (196 дескрипторов на изображение) вместо грубой сетки `7×7` (49 дескрипторов) позволило сохранить мелкие архитектурные детали и поднять качество до **78.21%** (Weighted F1 = **0.81**).
3. **Эффективность степенной L2-нормализации гистограмм:** применение преобразования $\sqrt{p_j}$ с последующей L2-нормировкой подавило влияние частых фоновых визуальных слов и усилило информативность редких характерных элементов фасадов, обеспечив прирост точности и устойчивости линейного классификатора `LinearSVC`.
4. **Несовместимость бинарных дескрипторов с евклидовым K-Means:** `ORB` показал минимальную точность (11.81%), поскольку его дескрипторы являются бинарными строками и требуют расстояния Хэмминга. При кластеризации стандартным K-Means с евклидовой метрикой центроиды усредняются в дробные значения, что снижает разделимость визуальных слов. Вещественные дескрипторы `SIFT` и L2-нормированные карты CNN корректно работают в евклидовом пространстве.
