# Практическая работа №1. Обработка изображений с использованием OpenCV

Библиотека фильтров на Python. OpenCV используется **только для чтения и записи**
изображений (`cv2.imdecode`, `cv2.imencode`) и, опционально, для показа окна
(`--show`). Все преобразования реализованы базовыми матричными операциями NumPy:
поэлементная арифметика, индексация, матричное умножение, свёртка через сумму
сдвинутых копий. Функции `cv2.resize`, `cv2.cvtColor`, `cv2.GaussianBlur`,
`cv2.Sobel`, `cv2.line` и т.п. не применяются.

## Запуск

```
python main.py -i <входное изображение> [-o <выходной файл>] [--show] <фильтр> [параметры фильтра]
```

| Аргумент | Описание |
|---|---|
| `-i, --image` | путь к входному изображению (обязательный) |
| `-o, --output` | путь для результата; по умолчанию `<имя>_<фильтр>.png` |
| `--show` | показать исходное и результирующее изображения в окне |
| `<фильтр>` | `resize`, `grayscale`, `antique`, `fade`, `film`, `matte`, `old`, `neon` |

### Примеры

```bash
python main.py -i images/image.png -o results/small.png resize --scale 0.25 --interpolation nearest
python main.py -i images/image.png resize --width 800      
python main.py -i images/image.png grayscale
```

По умолчанию результат сохраняется рядом с исходным изображением:
например, `images/image.png` → `images/image_neon.png`.
Параметр `-o` задаёт другой путь; недостающая папка создаётся автоматически.

### Последовательность работы скрипта

1. **Разбор аргументов** — `cli_argument_parser()` (argparse, у каждого фильтра
   своя подкоманда со своими типизированными параметрами).
2. **Чтение изображения** — `read_image(path)`: проверка существования файла,
   декодирование, проверка результата; при ошибке выводится сообщение и
   возвращается код 1. Работает и с путями, содержащими кириллицу.
3. **Применение фильтра** — `ImageFilter.get_filter(name, **params).apply_filter(image)`;
   некорректные параметры → сообщение и код 2.
4. **Сохранение** — `write_image(path, image)`; ошибка записи → код 3.

### Архитектура

`ImageFilter` — абстрактный класс с абстрактным методом `apply_filter(image)` и
статическим фабричным методом `get_filter(name, **params)`. Наследники
регистрируются декоратором `@ImageFilter.register` в словаре «имя → класс»,
поэтому добавление нового фильтра не требует правки фабрики.

## Математическое описание алгоритмов

Обозначения: $I(y, x) = (R, G, B)$ — исходное изображение размера $H \times W$,
интенсивности нормированы в $[0, 1]$ ($I = I_{uint8}/255$). Результат
приводится обратно к $[0, 255]$ с насыщением: $\mathrm{clip}(255\,I' + 0.5,\ 0,\ 255)$.
Линейная интерполяция: $\mathrm{lerp}(a, b, t) = (1 - t)\,a + t\,b$.

В формулах каналы записаны в порядке RGB, а массивы OpenCV хранятся в BGR.
`ensure_bgr` повторяет канал серого изображения трижды или отбрасывает
четвёртый канал прозрачности; порядок RGB/BGR эта функция не меняет.
`resize` работает непосредственно со значениями исходного массива.

### Вспомогательные операции

**Яркость** (ITU-R BT.601):
$$Y = 0.299\,R + 0.587\,G + 0.114\,B.$$

**Двумерная свёртка** с ядром $K$ размера $(2a+1)\times(2b+1)$:
$$(I * K)(y, x) = \sum_{i=-a}^{a}\sum_{j=-b}^{b} K(i, j)\; I(y+i,\ x+j).$$
Реализована как сумма $\sum K(i,j)\cdot \text{shift}_{i,j}(I)$ сдвинутых копий
изображения; за границей изображение продолжается крайними пикселями.
Ядро не переворачивается: строго говоря, это корреляция. Для симметричного
гауссова ядра она совпадает со свёрткой.

**Размытие Гаусса.** При $\sigma > 0$ используется одномерное ядро радиуса
$r = \max(1, \lceil 3\sigma\rceil)$:
$$g(t) = \frac{e^{-t^2 / 2\sigma^2}}{\sum_{s=-r}^{r} e^{-s^2/2\sigma^2}},\quad t = -r..r.$$
Двумерное ядро разделимо, $G(i,j) = g(i)\,g(j)$, поэтому свёртка выполняется
последовательно по строкам и по столбцам: $O(r)$ операций на пиксель вместо $O(r^2)$.
При $\sigma \le 0$ функция возвращает исходный массив без размытия.

### 1. Изменение разрешения (`resize`)

Пиксель $(y', x')$ результата размера $H' \times W'$ отображается в точку исходного
изображения с выравниванием по центрам пикселей:
$$x = \left(x' + \tfrac12\right)\frac{W}{W'} - \tfrac12,\qquad
  y = \left(y' + \tfrac12\right)\frac{H}{H'} - \tfrac12.$$

**Ближайший сосед:** $I'(y', x') = I(\mathrm{round}(y),\ \mathrm{round}(x))$.

**Билинейная интерполяция:** пусть $x_0 = \lfloor x\rfloor,\ y_0 = \lfloor y\rfloor$,
$\Delta x = x - x_0,\ \Delta y = y - y_0$. Тогда
$$I'(y',x') = (1-\Delta y)\big[(1-\Delta x)I_{y_0x_0} + \Delta x\, I_{y_0x_1}\big]
             + \Delta y\big[(1-\Delta x)I_{y_1x_0} + \Delta x\, I_{y_1x_1}\big].$$

Координаты за границами ограничиваются диапазоном $[0, W-1]$, $[0, H-1]$. Если задана
одна сторона, вторая вычисляется из соотношения сторон: $H' = \mathrm{round}(H\cdot W'/W)$.
Вычисление векторизовано: индексы строк и столбцов формируются один раз, затем
используется расширенная индексация NumPy. `scale` имеет приоритет над
`width` и `height`; при задании обеих сторон пропорции могут измениться.
По умолчанию применяется `bilinear`. Метод `nearest` использует `np.round`
(точные половины округляются к ближайшему чётному числу).

### 2. Оттенки серого (`grayscale`)

$$I'(y, x) = 0.299\,R + 0.587\,G + 0.114\,B.$$
Веса соответствуют чувствительности глаза к основным цветам (максимальная — к зелёному).
Результат — одноканальная матрица $H \times W$.

### 3. Антиквариат (`antique`)

Сепия — линейное преобразование цветового вектора:
$$\begin{pmatrix} R_s \\ G_s \\ B_s \end{pmatrix} =
\begin{pmatrix} 0.393 & 0.769 & 0.189\\ 0.349 & 0.686 & 0.168\\ 0.272 & 0.534 & 0.131 \end{pmatrix}
\begin{pmatrix} R \\ G \\ B \end{pmatrix}.$$
Строки матрицы имеют близкие пропорции; для неотрицательных входных значений
коэффициенты дают $R_s \ge G_s \ge B_s$, создавая тёплый коричневый тон.
После преобразования значения сепии ограничиваются диапазоном $[0,1]$.

Затем — смешивание с оригиналом и снижение контраста относительно середины диапазона:
$$I' = \mathrm{lerp}(I,\ I_s,\ k),\qquad I'' = (I' - 0.5)\,c + 0.5,$$
где $k \in [0,1]$ — `intensity`, $c$ — `contrast` ($c < 1$ — «блёклый» снимок).

После тонирования применяется лёгкая тёмная виньетка: центр остаётся без
затемнения, к углам сила плавно увеличивается. Параметр `--vignette`
задаёт силу затемнения от 0 до 1 (по умолчанию 0.18; 0 отключает виньетку).

### 4. Выцветание (`fade`)

Параметр $k \in [0, 1]$ — сила эффекта.

1. Частичная десатурация — сдвиг каждого канала к яркости:
   $I_1 = I + 0.7k\,(Y - I)$.
2. Сжатие тонального диапазона (тени «приподнимаются», света приглушаются):
   $I_2 = l + (h - l)\,I_1,\quad l = 0.18k,\ h = 1 - 0.10k$.
   Чёрный становится тёмно-серым, белый — светло-серым, контраст падает в $h - l$ раз.
3. Тёплый оттенок, как у выгоревших отпечатков:
   $I_3 = I_2 + k\cdot(\Delta R, \Delta G, \Delta B) = I_2 + k\cdot(0.03,\ 0,\ -0.04)$.

### 5. Имитация инфракрасной плёнки (`film`)

Плёнка, чувствительная к ближнему ИК-диапазону, регистрирует сильное отражение
хлорофилла: листва выглядит почти белой, а голубое небо и вода — тёмными.
Фильтр художественно имитирует этот эффект по видимым каналам, а не измеряет
реальное ИК-излучение (зелёный вклад усиливается, синий вычитается):
$$\mathrm{IR} = \mathrm{clip}(0.2\,R + 1.4\,G - 0.6\,B,\ 0,\ 1).$$

* **`--mode bw`** (ч/б плёнка Kodak HIE): $I' = (\mathrm{IR}, \mathrm{IR}, \mathrm{IR})$.
* **`--mode color`** (цветная плёнка Aerochrome, «ложные цвета»): спектр смещается на
  одну позицию — ИК записывается в красный слой, красный — в зелёный, зелёный — в синий:
  $(R', G', B') = (\mathrm{IR},\ R,\ G)$. Цвета условные: например, чистый зелёный
  превращается в пурпурный до добавления ореола и зерна.

**Ореол (halation)** — рассеяние света в эмульсии вокруг светлых участков:
$$M = \mathrm{clip}\!\left(\frac{I' - 0.6}{0.4}, 0, 1\right),\quad
  L = M * G_\sigma,\quad \sigma = \frac{\max(H,W)}{150},$$
$$I'' = 1 - (1 - I')(1 - h\,L)\quad\text{(смешивание «экран», } h\text{ — `halation`)}.$$

**Зерно**: $I''' = I'' + n,\ n \sim \mathcal N(0, s^2)$, одно значение на пиксель
для всех каналов ($s$ — `grain`).
Ореол вычисляется отдельно по каналам и отключается при `halation <= 0`;
зерно отключается при `grain <= 0`. Режим `bw` возвращает три одинаковых канала.

### 6. Матовая рамка (`matte`)

Координаты нормируются к полуосям изображения:
$\hat x = \dfrac{x - (W-1)/2}{W/2},\ \hat y = \dfrac{y - (H-1)/2}{H/2}$.
Эллиптическое расстояние до центра:
$$d = \frac{\sqrt{\hat x^2 + \hat y^2}}{\rho},$$
где $\rho$ — `radius`. Множество $d \le 1$ — эллипс с полуосями $\rho W/2$ и $\rho H/2$.
Доля цвета рамки при $f > 0$ (`feather`) задаётся функцией smoothstep:
$$t = \mathrm{clip}\!\left(\frac{d - 1}{f},\ 0,\ 1\right),\qquad \alpha = 3t^2 - 2t^3,$$
$$I' = (1 - \alpha)\,I + \alpha\,C,$$
где $C$ — цвет рамки (по умолчанию белый). Внутри эллипса $\alpha = 0$ (изображение
не меняется), за пределами $d \ge 1 + f$ — $\alpha = 1$ (чистый цвет рамки).
Ширина перехода в нормированных координатах равна $\rho f$, а не $f$ пикселей.
При `feather=0` переход резкий: $\alpha=1$ только для $d>1$.

### 7. Состаренная фотография (`old`)

Эффекты применяются последовательно:

1. **Сепия** (п. 3) с силой `sepia` и контрастом 0.9.
2. **Виньетирование** — затемнение к краям:
   $I_2 = I_1\,(1 - v\,\tfrac12(\hat x^2 + \hat y^2))$, $v$ — `vignette`.
3. **Шум**: $I_3 = I_2 + n,\ n \sim \mathcal N(0, \sigma_n^2)$.
4. **Царапины.** Короткие тонкие нити со случайным начальным направлением
   и накопленными поворотами на каждом шаге. Длина составляет 2.5–7.5% меньшей
   стороны кадра (минимум 2 px). Субпиксельное покрытие сглаживает края,
   сила плавно уменьшается к концам; базовая сила — от 0.2 до 0.45.
   Царапины светлые: $I_4 = \mathrm{lerp}(I_3,\ 0.95,\ S)$.
5. **Пыль** — $N$ дисков $\{(y,x): (y-c_y)^2 + (x-c_x)^2 \le r^2\}$, $r \sim U(0.5, 2.5)$,
   формируют маску $D$; пыль тёмная: $I_5 = \mathrm{lerp}(I_4,\ 0.08,\ D)$.

Параметр `--seed` у `old` и `film` делает результат воспроизводимым при одинаковом
входе, настройках и новом объекте фильтра (в том числе при новом запуске CLI).
Повторные вызовы одного объекта продолжают последовательность генератора.

### 8. Неоновый эффект (`neon`)

Эффект тонкой неоновой трубки поверх фотографии: почти белое ядро
и насыщенный фиолетовый ореол. Контуры выбираются автоматически по яркости;
для точного повторения вручную обведённых объектов нужна отдельная маска.

1. **Подготовка:** гауссово сглаживание подавляет мелкие шумовые детали.
2. **Контуры:** градиент Собеля нормируется по 99-му процентилю.
   Подавление немаксимумов с билинейной интерполяцией сужает границы до тонких
   линий. Плавный порог `threshold` (по умолчанию 0.3) отсекает слабые детали.
3. **Свечение:** почти белое ядро дополняется тремя цветными ореолами
   со значениями sigma 2, 7 и 20, умноженными на масштаб изображения
   $s=\max(\min(H,W)/1080, 0.35)$; веса слоёв — 1.8, 1.2 и 0.65.
   Каждый слой дополнительно умножается на своё значение sigma и на $s$.
4. **Композиция:** экспоненциальное преобразование света и экранное смешивание
   сохраняют детали исходной фотографии и мягкие переходы свечения.

По умолчанию `color="#BF00FF"`, `glow=1.0`, `intensity=1.0`, `background=0.7`.
Параметр `--color` принимает цвет в формате `#RRGGBB`;
`--glow` управляет ореолом, `--intensity` — общей яркостью свечения,
`--background` — видимостью исходного фото. Все преобразования выполнены NumPy.

## Проверка корректности

Для сравнения можно использовать `cv2.resize` с `INTER_LINEAR` (для `bilinear`)
и `cv2.cvtColor` с `COLOR_BGR2GRAY` (для `grayscale`). Сравнивать следует
разность значений в знаковом или дробном типе, чтобы избежать переполнения `uint8`.
Такое сравнение проверяет выбранные изображения и размеры, а не гарантирует
погрешность для любых входных данных.
