# Лабораторная работа №1. Обработка изображений с использованием библиотеки OpenCV

## Цель работы
Разработать библиотеку фильтров на языке Python с использованием базовых матричных операций над изображениями в OpenCV.

## Реализованные фильтры

### 1. Изменение разрешения (Resize)
**Алгоритм:**  
Масштабирует изображение до заданных `width` и `height`.

- Вычисляет новые индексы строк и столбцов:
  `floor(arange(new_size) * (old_size / new_size))`.
- Выбирает пиксели по этим индексам.
- Фактически использует метод ближайшего соседа.


### 2. Перевод в оттенки серого (Grayscale)
**Алгоритм:** взвешенная сумма каналов BGR по формуле ITU-R BT.601:
\[
Y = 0.114 \cdot B + 0.587 \cdot G + 0.299 \cdot R
\]
Результат — одноканальное изображение.

### 3. Фотоэффект «Антиквариат» (Antique)
**Алгоритм:**
1. Преобразование в сепию с помощью матрицы.
2. Наложение виньетки: затемнение по краям по закону \(1 - 0.9 \cdot (d / d_{max})^2\), где \(d\) — расстояние от центра.
3. Добавление гауссова шума с \(\sigma = 0.02\).

### 4. Выцветание (Fade Color)
**Алгоритм:**
1. Понижение контраста: \(I' = (I - self.contrast) \cdot 0.7 + self.contrast\).
2. Смешивание с белым: \(I'' = self.alpha \cdot I' + (1 - self.alpha) \cdot 1.0\).
3. Ограничение значений в диапазоне \([0, 1]\).

### 5. Имитация плёнки (Film)
**Алгоритм:** имитация инфракрасной плёнки.
Меняются местами зеленый и синий канал.
Затем добавляется зернистость (гауссов шум \(\sigma = 0.05\)).

### 6. Эффект маски (Matte)
**Алгоритм:** создаётся овальная маска.  
Уравнение эллипса:
\[
\frac{(x - x_c)^2}{a^2} + \frac{(y - y_c)^2}{b^2} \leq 1
\]
где \(a = 0.4W\), \(b = 0.4H\).  
Пиксели вне эллипса закрашиваются белым.

### 7. Царапины и шум (Scratches)
**Алгоритм:**
1. Рисуются случайные линии (царапины) с помощью `cv2.line` (базовая операция).
2. Добавляется шум «соль и перец»: случайные пиксели становятся белыми или чёрными с заданной вероятностью.

### 8. Неоновый эффект (Neon)
**Алгоритм:**
Создаёт неоновый эффект на основе выделения краёв.

- Переводит изображение в grayscale.
- Считает градиенты оператором Собеля:
  - `Kx` — горизонтальные изменения;
  - `Ky` — вертикальные изменения.
- Использует `convolve2d` со скользящим окном и edge-паддингом.
- Вычисляет магнитуду градиента:
  `sqrt(gx^2 + gy^2)`.
- Нормирует магнитуду в `0..255`.
- Порогом `threshold` выделяет края.
- Формирует неоновое изображение:
  - фон чёрный;
  - края окрашены в `(255, 255, 0)`.
- Строит гауссово свечение `glow` через разделимую свёртку `blur_channel`.
- Складывает неон и свечение.

## Установка и запуск

### Требования
- Python 3.8+
- Установленные библиотеки: `opencv-python`, `numpy`

### Создание и активация окружения
```bash
python -m venv venv
venv\Scripts\activate 
```

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Пример
```bash
python main.py --input images/test.jpg --output ry.jpg --filter neon --threshold 40 --glow_ksize 7
```
