# Лабораторная работа №1. Обработка изображений с использованием библиотеки OpenCV

## Цель работы
Разработать библиотеку фильтров на языке Python с использованием базовых матричных операций над изображениями в OpenCV.

## Реализованные фильтры

### 1. Изменение разрешения (Resize)
**Алгоритм:**  
Масштабирует изображение до заданных `width` и `height`.

- Вычисляет новые индексы строк и столбцов:
  `floor(arange(new_size) * (old_size / new_size))`.
- Выбирает пиксели по этим индексам.
- Фактически использует метод ближайшего соседа.


### 2. Перевод в оттенки серого (Grayscale)
**Алгоритм:** взвешенная сумма каналов BGR по формуле ITU-R BT.601:

`Y = 0.114 B + 0.587  G + 0.299  R`

Результат — одноканальное изображение.

### 3. Фотоэффект «Антиквариат» (Antique)
**Алгоритм:**
1. Преобразование в сепию с помощью матрицы.
2. Наложение виньетки: затемнение по краям по закону `(1 - 0.9  (d / d_max)^2)`, где (d) — расстояние от центра.
3. Добавление гауссова шума с `(sigma = 0.02)`.

### 4. Выцветание (Fade Color)
**Алгоритм:**
1. Понижение контраста: `(I' = (I - self.contrast)   0.7 + self.contrast)`.
2. Смешивание с белым: `(I'' = self.alpha   I' + (1 - self.alpha)   1.0)`.
3. Ограничение значений в диапазоне (0, 1].

### 5. Имитация плёнки (Film)
**Алгоритм:** имитация инфракрасной плёнки.
Меняются местами зеленый и синий канал, затем добавляется зернистость.

### 6. Эффект маски (Matte)
**Алгоритм:** создаётся овальная маска с плавным выбеливанием по уравнению эллипса.
Нормированное расстояние от центра: `d = dist / (min(h, w)/2)`. 
Функция перехода с плавным выбеливанием:
```text
t = clip((d − radius) / softness, 0, 1)
t = t²·(3 − 2t)
```
Далее смешиваем с белым и добавляем шум.

### 7. Царапины и шум (Scratches)
**Алгоритм:**
1. Применяется эффект Antique.
2. Рисуются случайные линии (царапины) с помощью `cv2.line`.
3. Добавляется шум «соль и перец»: случайные пиксели становятся белыми или чёрными с заданной вероятностью.

### 8. Неоновый эффект (Neon)
**Алгоритм:**
Создаёт неоновый эффект на основе выделения краёв.

Основной алгоритм:

1. Изображение переводится в оттенки серого по рассмотренному выше алгоритму.
2. К полутоновому изображению применяется упрощенный оператор Собеля (центральная разность).
3. Выделенные границы окрашиваются в выбранный цвет.
4. Эффект размытия контуров добавляется с помощью многократной дилатации (число дилатаций определяется толщиной подсветки `glow_width`) с гауссовым затуханием.
5. Базовый и контурный слои смешиваются со слоем подсветки с заданным коэффициентом свечения `glow`.
6. Ширина неоновой линии регулируется параметром  `line_width` за счет многкратной дилатации.

## Установка и запуск

### Требования
- Python 3.8+
- Установленные библиотеки: `opencv-python`, `numpy`

### Создание и активация окружения
```bash
python -m venv venv
.venv\Scripts\activate 
```

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Пример
```bash
python main.py --input images/images.png --output test.jpg --filter neon

python main.py --input images/images.png --output test.jpg --filter neon --line_width 1 --glow_width 6 --glow 1

python main.py --input images/test.jpg --output test.jpg --filter resize --width 15 --height 50

python main.py --input images/test.jpg --output test.jpg --filter grayscale

python main.py --input images/test.jpg --output test.jpg --filter antique

python main.py --input images/test.jpg --output test.jpg --filter fade

python main.py --input images/test.jpg --output test.jpg --filter film

python main.py --input images/test.jpg --output test.jpg --filter matte

python main.py --input images/test.jpg --output test.jpg --filter scratches
```
