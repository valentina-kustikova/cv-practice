# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

## О работе

Реализована библиотека фильтров обработки изображений на Python. Каждый
фильтр — отдельный класс, принимающий массив NumPy и возвращающий новое
изображение с применённым эффектом.

## Формат запуска

```bash
python src/main.py -i <вход> -o <выход> -f <фильтр> [параметры]
```

- `-i`, `--input` — путь к исходному изображению (обязателен);
- `-o`, `--output` — путь для сохранения результата (обязателен),
  расширение файла определяет формат;
- `-f`, `--filter` — имя фильтра (обязателен);
- остальные параметры зависят от конкретного фильтра.

## 1. Resize — изменение разрешения

**Алгоритм:** метод ближайшего соседа (nearest neighbor). Для каждого
выходного пикселя `(x', y')` находится соответствующий пиксель исходного
изображения по формулам:

```
x_src = floor(x' · W / W')
y_src = floor(y' · H / H')
I_out(y', x') = I_in(y_src, x_src)
```

где `W, H` — размеры исходного изображения, `W', H'` — выходного.
Реализация векторная — через массивы индексов и fancy-индексацию NumPy.

**Параметры:** `-W` (ширина), `-H` (высота) — обязательные.

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_640x480.jpg -f resize -W 640 -H 480
```

## 2. RGB2GrayScale — оттенки серого

**Алгоритм:** яркость пикселя вычисляется по формуле:

```
Y = 0.114·B + 0.587·G + 0.299·R
```

Коэффициенты соответствуют BGR-порядку каналов OpenCV. Веса отражают
восприятие яркости человеческим глазом: зелёный даёт наибольший вклад,
синий — наименьший. Сумма весов равна 1, поэтому результат остаётся в
диапазоне 0..255. Операция применяется ко всему изображению как тензорное
произведение вектора весов на массив пикселей.

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_gray.jpg -f gray
```

## 3. Antique — эффект «антиквариат»

**Алгоритм:** сепия с виньеткой.

Сепия — линейное цветовое преобразование, задаваемое матрицей 3×3:

```
[B']   [0.131  0.534  0.272]   [B]
[G'] = [0.168  0.686  0.349] · [G]
[R']   [0.189  0.769  0.393]   [R]
```

Матрица умножается на вектор каналов каждого пикселя. Положительные
коэффициенты дают тёплую коричневатую гамму.

Виньетка — затемнение от центра к краям. Коэффициент затемнения:

```
v(x, y) = 1 − k · (r(x, y) / r_max)²
```

где `r` — расстояние от центра, `r_max` — расстояние до угла, `k` —
параметр `vignette`. В центре коэффициент равен 1, в углу — `1 − k`.

**Параметры:** `--vignette` (0..1, по умолчанию 0.3).

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_antique.jpg -f antique
```

## 4. FadeColor — выцветание

**Алгоритм:** смешивание изображения с его серой версией и понижение
контраста.

Шаг 1 — смешивание:

```
Y  = 0.114·B + 0.587·G + 0.299·R
C' = α·C + (1 − α)·Y       для C ∈ {B, G, R}
```

где `α` — коэффициент сохранения цвета (`α = 1` — оригинал, `α = 0` —
полностью серое).

Шаг 2 — понижение контраста с подмешиванием дымки:

```
C'' = C'·contrast + (1 − contrast)·255·haze
```

**Параметры:** `--alpha` (0.5), `--contrast` (0.85), `--haze` (0.15).

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_fade.jpg -f fade
```

## 5. Film — имитация инфракрасной плёнки

**Алгоритм:** линейные канальные сдвиги + тонирование + гауссов шум.

Шаг 1 — канальные сдвиги, имитирующие ИК-отклик:

```
[B']   [ 0.6  −0.3   0.1]   [B]
[G'] = [ 0.2   0.5   0.3] · [G]
[R']   [ 1.1   0.3  −0.2]   [R]
```

Отрицательные коэффициенты дают «вычитание» одних каналов из других:
зелёный входит в синий с минусом (растительность светлеет), синий входит
в красный с минусом (небо темнеет).

Шаг 2 — тонирование: умножение на вектор `[0.95, 1.0, 1.05]`.

Шаг 3 — гауссов шум:

```
result = result + N(0, σ²)
```

где `σ` — параметр `grain`.

**Параметры:** `--grain` (8.0), `--seed` (для воспроизводимости).

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_film.jpg \
    -f film --seed 42
```

## 6. Matte — овальная маска с белыми краями

**Алгоритм:** эллиптическая маска с плавной границей.

Нормированные координаты от центра:

```
u = (x − c_x) / a,   v = (y − c_y) / b
d = √(u² + v²)
```

где `a, b` — полуоси эллипса. При `d < 1` точка внутри эллипса,
при `d > 1` — снаружи. Маска с плавным переходом:

```
mask = clip( (1 + feather − d) / (2·feather), 0, 1 )
```

где `feather` — половина ширины переходной зоны. Композиция:

```
result = mask·image + (1 − mask)·255
```

Внутри эллипса — изображение, снаружи — белый, на границе — плавный
переход.

**Параметры:** `--a_ratio` (0.45), `--b_ratio` (0.45), `--feather` (0.05).

**Запуск:**

```bash
python src/main.py -i data/input/portrait.jpg -o data/output/portrait_matte.jpg -f matte
```

## 7. Scratches — царапины и шум

**Алгоритм:** рисование отрезков поверх изображения + гауссов шум.

Царапина — отрезок от `(x_0, y_0)` до `(x_1, y_1)`, задаваемый
параметрически:

```
x(t) = x_0 + t·(x_1 − x_0)
y(t) = y_0 + t·(y_1 − y_0),   t ∈ [0, 1]
```

В точках `(round(x(t)), round(y(t)))` значение пикселя изменяется на
`±intensity` (светлая или тёмная царапина). Знак выбирается случайно,
светлые встречаются чаще. Поверх всего изображения добавляется гауссов
шум `N(0, noise_level²)`.

**Параметры:** `--n_scratches` (5), `--scratch_intensity` (40.0),
`--noise_level` (12.0), `--seed`.

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_scratches.jpg \
    -f scratches --n_scratches 10 --seed 42
```

## 8. Neon — неоновое выделение контуров

**Алгоритм:** оператор Собеля + цветовая подсветка.

Шаг 1 — перевод в оттенки серого.

Шаг 2 — свёртка двумя ядрами Собеля 3×3:

```
Gx = [[-1  0  1]      Gy = [[-1 -2 -1]
      [-2  0  2]            [ 0  0  0]
      [-1  0  1]]           [ 1  2  1]]
```

`Gx` даёт отклик на горизонтальные перепады яркости, `Gy` — на
вертикальные.

Шаг 3 — величина градиента:

```
G = √(Gx² + Gy²)
```

Большое значение соответствует границе объекта, нулевое — однородной
области.

Шаг 4 — нормализация к диапазону 0..255: `G / G.max() · 255`.

Шаг 5 — композиция:

```
result = darkness·image + (G / 255)·neon_color·intensity
```

Оригинал притемняется, поверх него складывается цветной слой градиентов.

**Параметры:** `--darkness` (0.3), `--neon_color` (BGR, по умолчанию
`255 255 0` — циан), `--intensity` (1.0).

**Запуск:**

```bash
python src/main.py -i data/input/city.jpg -o data/output/city_neon.jpg -f neon
```
