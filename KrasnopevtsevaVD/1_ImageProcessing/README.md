# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

## Цель лабораторной работы

Набор фильтров для художественной и базовой обработки фотографий на Python. Ключевое требование работы — отказаться от высокоуровневых функций OpenCV (`cv2.resize`, `cv2.cvtColor`, `cv2.Sobel`, `cv2.filter2D` и т. п.). Всю вычислительную работу выполняет `numpy` через арифметику над матрицами. Из OpenCV используются только две функции — `cv2.imread` для чтения файла и `cv2.imwrite` для записи результата.

## Файловая структура

## Запуск

Базовый синтаксис:

python main.py -i <входной_файл> -f <фильтр> [-o <выходной_файл>] [параметры фильтра]

| Аргумент | Описание |
|---|---|
| -i, --input | путь к входному изображению (обязательный) |
| -f, --filter | имя фильтра (обязательный) |
| -o, --output | путь для сохранения результата (по умолчанию output.jpg) |

Доступные фильтры: resize, grayscale, antique, fade, infrared, matte, aged, neon.

Параметры фильтров (все необязательные):

| Параметр | Фильтр | По умолчанию | Описание |
|---|---|---|---|
| --scale | resize | 0.5 | коэффициент масштабирования, > 0 |
| --alpha | fade | 0.5 | сила выцветания, 0..1 |

Примеры запуска для каждого фильтра:

Ресайз (уменьшение вдвое):
python main.py -i images/input.png -f resize --scale 0.5 -o images/out_resize.png

Черно-белое:
python main.py -i images/input.png -f grayscale -o images/out_gray.png

Сепия:
python main.py -i images/input.png -f antique -o images/out_antique.png

Выцветание (сильное):
python main.py -i images/input.png -f fade --alpha 0.8 -o images/out_fade.png

Инфракрасный эффект:
python main.py -i images/input.png -f infrared -o images/out_ir.png

Маска:
python main.py -i images/input.png -f matte -o images/out_matte.png

Состаривание:
python main.py -i images/input.png -f aged -o images/out_aged.png

Неон:
python main.py -i images/input.png -f neon -o images/out_neon.png


## Архитектура фильтров

Абстрактный класс ImageFilter: у любого фильтра должен быть метод apply_filter(image), принимающий матрицу и возвращающий матрицу. Наследники реализуют этот метод.

Статический метод ImageFilter.get_filter(name, **kwargs): - по строковому имени он находит класс в словаре и создаёт экземпляр, передавая ему параметры из kwargs. Код вызова не знает, какой именно класс создаётся. 

| Класс | Имя (-f) |
|---|---|
| Resize | resize |
| Grayscale | grayscale |
| Antique | antique |
| FadeColor | fade |
| Infrared | infrared |
| Matte | matte |
| AgedPhoto | aged |
| Neon | neon |

Чтобы добавить новый фильтр, нужно написать класс-наследник и внести его в словарь внутри get_filter.

## Математическое описание алгоритмов

Обозначения: I — исходная матрица, I' — результат, (H, W) — размеры, clip(v) = min(max(v, 0), 255). Все каналы — в порядке BGR.

### Resize — изменение размера

Метод ближайшего соседа. Размеры результата:
H' = ⌊H · S⌋, W' = ⌊W · S⌋
где S — коэффициент масштабирования. Для каждого пикселя результата (y', x') берётся ближайший пиксель исходника:
I'(y', x') = I(⌊y'/S⌋, ⌊x'/S⌋)
Индексы считаются векторно через np.arange и fancy indexing, без циклов.

### Grayscale — оттенки серого

Стандарт ITU-R BT.601, учитывающий разную чувствительность глаза к цветам:
Y = 0.299 · R + 0.587 · G + 0.114 · B
Значение Y округляется и записывается в одноканальную матрицу.

### Antique — сепия

Сначала изображение переводится в оттенки серого (получаем Y). Затем яркость умножается на коэффициенты для каждого канала:
B' = 0.43 · Y, G' = 0.74 · Y, R' = 1.07 · Y
Красный усиливается, синий гасится — получается коричневато-жёлтый оттенок.

### FadeColor — выцветание

Линейная интерполяция между исходным пикселем и белым:
I' = I · (1 − α) + 255 · α, α ∈ [0, 1]
При α = 0 — оригинал, при α = 1 — полностью белое.

### Infrared — имитация ИК-плёнки

Красный и синий каналы меняются местами, зелёный усиливается:
B' = R, G' = clip(1.2 · G), R' = B
Дополнительно накладывается гауссов шум со средним 0 и стандартным отклонением noise_level — имитация зерна плёнки.

### Matte — овальная маска

Для каждого пикселя вычисляется нормированное расстояние до центра:
d = √(((x − cx)/rx)² + ((y − cy)/ry)²)
где rx, ry — радиусы эллипса. На границе эллипса d = 1. Маска с плавным переходом:
mask = clip((d − (1 − softness)) / (2·softness), 0, 1)
Внутри овала mask = 0 — пиксель не меняется. Снаружи mask = 1 — пиксель белый. Между ними — плавный градиент. Итоговое значение: I' = I · (1 − mask) + 255 · mask.

### AgedPhoto — состаривание

Изображение остаётся цветным, накладываются два эффекта.
1. Шум: к каждому пикселю прибавляется случайное число из нормального распределения N(0, (noise · 255)²).
2. Царапины: рисуется scratches вертикальных полос. Каждая полоса занимает весь столбец x_line и осветляется:
I'(·, x_line) = I(·, x_line) · 0.85 + 255 · 0.15
То есть столбец становится на 15% светлее.

### Neon — неоновые контуры

1. Перевод в оттенки серого.
2. Градиент оператором Собеля: свёртка с ядрами
   Gx = [[−1, 0, 1], [−2, 0, 2], [−1, 0, 1]]
   Gy = [[−1, −2, −1], [0, 0, 0], [1, 2, 1]]
   Магнитуда: |G| = √(Gx² + Gy²). Большое значение — резкий перепад яркости, то есть контур.
3. Нормировка |G| / max(|G|) в диапазон [0, 1].
4. Порог: пиксели с малой магнитудой обнуляются (шум).
5. Утолщение маски (дилатация) — чтобы контуры были видны.
6. Свечение: маска размывается несколько раз, к утолщённым контурам добавляется ореол.
7. Наложение поверх исходного: I' = I · (1 − mask) + neon_color · mask
   где neon_color = [255, 255, 50] в BGR — бирюзовый.

## Порядок работы скрипта

1. Разбор аргументов через argparse.
2. Чтение файла cv2.imread. Если файла нет — FileNotFoundError. Если не удалось декодировать — ValueError.
3. Создание объекта фильтра через ImageFilter.get_filter.
4. Вызов apply_filter — все вычисления внутри.
5. Сохранение результата через cv2.imwrite. Если папки нет — она создаётся.

Все исключения перехватываются в main(), печатается сообщение, скрипт завершается с кодом 1.
