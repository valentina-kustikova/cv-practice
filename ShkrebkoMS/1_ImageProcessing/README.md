# Практическая работа №1. Обработка изображений с использованием библиотеки OpenCV

## Описание

Библиотека фильтров для обработки изображений на языке Python.
Все фильтры реализованы вручную с помощью базовых матричных операций
библиотеки NumPy. OpenCV используется только для чтения (`cv2.imread`)
и сохранения (`cv2.imwrite`) изображений.

## Структура проекта

```
1_ImageProcessing/
├── main.py            # скрипт запуска: аргументы, чтение, применение фильтра, сохранение
├── filters.py         # абстрактный класс ImageFilter и классы фильтров
├── requirements.txt   # необходимые библиотеки
├── images/            # тестовые изображения
└── README.md
```

## Установка

```
conda create -n cv python=3.12
conda activate cv
pip install -r requirements.txt
```

## Запуск

Команды выполняются из папки `1_ImageProcessing`:

```
python main.py -i <входное изображение> -o <результат> -f <фильтр> [-p <параметр>]
```

| Аргумент         | Описание                                               | Обязательный |
|------------------|--------------------------------------------------------|--------------|
| `-i`, `--input`  | путь к входному изображению                            | да           |
| `-o`, `--output` | путь для сохранения результата                         | да           |
| `-f`, `--filter` | тип фильтра (см. список ниже)                           | да           |
| `-p`, `--param`  | параметр фильтра (смысл зависит от фильтра)            | нет          |

Если параметр не указан, используется значение по умолчанию.

Доступные фильтры: `resize`, `gray`, `antique`, `fade_color`, `film_effect`,
`matte`, `old_photo`, `neon`.

Скрипт выполняет действия в следующем порядке:

1. Разбор аргументов командной строки (`cli_argument_parser`).
2. Чтение изображения (`read_image`). Если файл не найден или не читается,
   выводится сообщение об ошибке и программа завершается.
3. Создание фильтра по имени (`ImageFilter.get_filter`) и его применение
   (`apply_filter`). При недопустимом значении параметра выводится сообщение об ошибке.
4. Сохранение результата.

## Устройство библиотеки фильтров

`ImageFilter` — абстрактный базовый класс. Он содержит:

- статический фабричный метод `get_filter(name, param)`, который по имени
  фильтра создаёт объект нужного класса;
- абстрактный метод `apply_filter(image)`, который обязан реализовать каждый фильтр.

Каждый фильтр — отдельный класс-наследник `ImageFilter`.

Изображение хранится как массив размером `H × W × 3` со значениями от 0 до 255.
OpenCV хранит каналы в порядке **B, G, R**. Вычисления выполняются в типе
`float32`, после чего результат ограничивается диапазоном [0, 255]
и переводится обратно в `uint8`.

Обозначения в формулах:

- `R`, `G`, `B` — значения красного, зелёного и синего каналов пикселя (0–255);
- `C` — любой из каналов, если формула одинакова для всех трёх;
- `p` — параметр фильтра, передаваемый через `-p`.

## Реализованные фильтры

### 1. Изменение разрешения (`resize`)

Изменяет размер изображения в `s` раз методом ближайшего соседа.

Новые размеры изображения (с округлением вниз до целого):

```
H_new = H · s
W_new = W · s
```

Каждый пиксель нового изображения берётся из исходного по правилу
(с округлением вниз):

```
i_old = i_new / s
j_old = j_new / s
```

где `i`, `j` — номер строки и столбца пикселя.
При `s < 1` часть строк и столбцов пропускается (уменьшение),
при `s > 1` строки и столбцы повторяются (увеличение).

**Параметр `-p`:** коэффициент масштаба `s > 0`, по умолчанию `0.5`.

**Пример:**

```
python main.py -i images/mountain.jpg -o small.jpg -f resize -p 0.5
```

### 2. Оттенки серого (`gray`)

Переводит изображение в оттенки серого. Яркость пикселя вычисляется
как взвешенная сумма каналов. Коэффициенты учитывают разную
чувствительность глаза к цветам:

```
Y = 0.299 · R + 0.587 · G + 0.114 · B
```

Результат — одноканальное изображение того же размера.

**Параметр `-p`:** не используется.

**Пример:**

```
python main.py -i images/mountain.jpg -o gray.jpg -f gray
```

### 3. Антиквариат (`antique`)

Придаёт изображению коричневый оттенок старой фотографии (сепия).
Каждый новый канал вычисляется как взвешенная сумма всех трёх исходных каналов:

```
R_sepia = 0.393 · R + 0.769 · G + 0.189 · B
G_sepia = 0.349 · R + 0.686 · G + 0.168 · B
B_sepia = 0.272 · R + 0.534 · G + 0.131 · B
```

Сумма коэффициентов для красного канала (≈1.35) больше, чем для зелёного (≈1.20)
и синего (≈0.94), поэтому изображение становится тёплым, коричнево-жёлтым.

Затем сепия смешивается с исходным изображением с силой `p`:

```
C_new = (1 − p) · C + p · C_sepia
```

**Параметр `-p`:** сила эффекта `p` от 0 до 1, по умолчанию `1`
(0 — исходное изображение, 1 — полная сепия).

**Пример:**

```
python main.py -i images/mountain.jpg -o antique.jpg -f antique -p 0.7
```

### 4. Выцветание (`fade_color`)

Имитирует фотографию, выгоревшую на солнце. Каждый канал каждого пикселя
смешивается с белым цветом (255):

```
C_new = C · (1 − p) + 255 · p
```

Тёмные области поднимаются сильнее светлых, поэтому уменьшаются контраст
и насыщенность цветов, изображение становится бледным.

**Параметр `-p`:** сила выцветания `p` от 0 до 1, по умолчанию `0.5`.
Рекомендуемые значения 0.2–0.6: при `p = 1` изображение становится полностью белым.

**Пример:**

```
python main.py -i images/mountain.jpg -o fade.jpg -f fade_color -p 0.3
```

### 5. Имитация инфракрасной плёнки (`film_effect`)

Имитирует инфракрасную плёнку (например, Kodak Aerochrome). Растения сильно
отражают инфракрасный свет, и на такой плёнке зелёная листва выглядит красной,
а небо — фиолетовым. На обычном фото растения зелёные, поэтому зелёный канал
используется вместо инфракрасного: красный и зелёный каналы меняются местами,
синий остаётся без изменений:

```
R_ir = G
G_ir = R
B_ir = B
```

Затем результат смешивается с исходным изображением с силой `p`:

```
C_new = (1 − p) · C + p · C_ir
```

Пиксели, у которых R ≈ G (серые камни, белые облака), почти не меняются.

**Параметр `-p`:** сила эффекта `p` от 0 до 1, по умолчанию `1`.

**Пример:**

```
python main.py -i images/mountain.jpg -o film.jpg -f film_effect
```

### 6. Маска (`matte`)

Делает края фотографии белыми, оставляя овальную область в центре.

Для каждого пикселя вычисляется «эллиптическое» расстояние до центра
изображения `(cx, cy) = (W/2, H/2)`:

```
d = √( ((x − cx) / (W/2))² + ((y − cy) / (H/2))² )
```

В центре `d = 0`, на эллипсе, вписанном в изображение, `d = 1`.
Деление на `W/2` и `H/2` делает область овальной, повторяющей пропорции снимка.

По расстоянию строится маска с плавным переходом
(результат ограничивается диапазоном [0, 1]):

```
mask = (1 − d) / (1 − p)
```

- `d ≤ p` — `mask = 1`, пиксель не меняется;
- `p < d < 1` — маска плавно убывает от 1 до 0;
- `d ≥ 1` — `mask = 0`, пиксель белый.

Изображение смешивается с белым цветом по маске:

```
C_new = C · mask + 255 · (1 − mask)
```

**Параметр `-p`:** размер чистой центральной области `p` от 0 до 1 (не включая 1),
по умолчанию `0.6`. Чем больше `p`, тем резче граница овала.

**Пример:**

```
python main.py -i images/mountain.jpg -o matte.jpg -f matte -p 0.6
```

### 7. Состаренная фотография (`old_photo`)

Имитирует старую фотографию. Эффект складывается из пяти шагов.

**1. Пожелтение.** К изображению применяется сепия (фильтр `antique`) с силой 0.8.

**2. Затемнение краёв (виньетка).** Используется то же расстояние `d`
до центра, что и в фильтре `matte`. Края старых снимков темнее центра:

```
C_new = C · (1 − 0.5 · d²)
```

**3. Зерно плёнки.** К каждому пикселю добавляется случайное число
из нормального распределения со средним 0 и разбросом `σ = 30 · p`.
Шум одинаков для всех трёх каналов, поэтому зерно серое, без цветных точек:

```
C_new = C + N(0, σ)
```

**4. Царапины.** Количество царапин — `30 · p`. Для каждой случайно выбираются
начальная точка `(x0, y0)`, длина, небольшой наклон `k ∈ [−0.1, 0.1]`
и яркость `b ∈ [40, 120]`. Для каждой строки `y` царапины столбец вычисляется как:

```
x = x0 + k · (y − y0)
```

и пиксель осветляется: `C_new = C + b`. Линии рисуются индексированием массива
по вычисленным координатам, без готовых функций рисования OpenCV.

**5. Пыль.** `600 · p` случайных пикселей: половина становится светлой (230),
половина тёмной (30).

**Параметр `-p`:** сила старения `p` от 0 до 1, по умолчанию `0.5`.
Царапины и пыль случайны, поэтому каждый запуск даёт немного другой результат.

**Пример:**

```
python main.py -i images/mountain.jpg -o old.jpg -f old_photo -p 0.7
```

### 8. Неоновый эффект (`neon`)

Выделяет контуры объектов и подсвечивает их, создавая эффект неоновых трубок
на тёмном фоне.

**1. Яркость и сглаживание.** Изображение переводится в оттенки серого
(формула фильтра `gray`) и размывается усреднением по окну 3×3:

```
Y_blur[i, j] = (1/9) · Σ Y[i + a, j + b],   a, b ∈ {−1, 0, 1}
```

Размытие убирает мелкий шум (например, текстуру травы), чтобы остались
только границы объектов.

**2. Поиск границ оператором Собеля.** Для каждого пикселя вычисляются
производные яркости по горизонтали и вертикали с помощью ядер:

```
      | −1  0  +1 |          | −1  −2  −1 |
Gx =  | −2  0  +2 |     Gy = |  0   0   0 |
      | −1  0  +1 |          | +1  +2  +1 |
```

Сила границы (модуль градиента), нормированная к диапазону [0, 1]:

```
E = √(Gx² + Gy²) / max(E)
```

На однородных участках `E ≈ 0`, на резких переходах яркости `E` велико.

**3. Порог.** Контуром считаются пиксели с `E > p`.

**4. Свечение.** Маска контуров размывается окном 3×3 четыре раза подряд,
получается мягкий ореол вокруг линий. Итоговая яркость подсветки:

```
L = min(1, lines + 1.2 · glow)
```

**5. Цвет и фон.** Цвет контура — цвет исходного пикселя, доведённый
до максимальной яркости (оттенок сохраняется):

```
C_neon = C / max(R, G, B) · 255
```

Фон затемняется до 15%, поверх него накладывается подсветка:

```
C_new = 0.15 · C + C_neon · L
```

Листва светится зелёным, цветы — розовым, небо — голубым.

**Параметр `-p`:** порог контуров `p` от 0 до 1 (не включая границы),
по умолчанию `0.3`. Чем меньше порог, тем больше контуров.

**Пример:**

```
python main.py -i images/mountain.jpg -o neon.jpg -f neon -p 0.3
```
