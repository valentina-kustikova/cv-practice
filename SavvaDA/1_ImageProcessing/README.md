# Лабораторная работа №1. Обработка изображений с использованием библиотеки OpenCV

## Описание

В данной лабораторной работе реализована Библиотека фильтров на Python для обработки изображений с использованием базовых
матричных операций NumPy. Все фильтры реализованы без помощи готовых функций OpenCV.

## Описание фильтров

### 1. Resize — изменение разрешения

**Математика.** Метод ближайшего соседа. Для каждого пикселя нового изображения
`(i, j)` находим соответствующую точку в исходном:

```
i_src = int(i / scale)
j_src = int(j / scale)
dst[i, j] = src[i_src, j_src]
```

Новые размеры: `H' = H * scale`, `W' = W * scale`.

**Реализация.** Векторная индексация NumPy:

```python
row_indices = (np.arange(new_h) / scale).astype(np.int32)
col_indices = (np.arange(new_w) / scale).astype(np.int32)
result = image[row_indices[:, None], col_indices]
```

**Запуск:**

```bash
python cli.py -f resize -i photo.jpg -o out.jpg --scale 0.5
```

---

### 2. RGB2GrayScale — перевод в оттенки серого

**Математика.** Взвешенная сумма каналов по стандарту ITU-R BT.601:

```
Y = 0.299 * R + 0.587 * G + 0.114 * B
```

Веса отражают восприятие яркости человеческим глазом: зелёный кажется ярче,
синий — тусклее. Сумма весов = 1.0.

**Реализация.** OpenCV хранит каналы в порядке BGR, поэтому:

```python
gray = 0.299 * r + 0.587 * g + 0.114 * b
gray = np.clip(gray, 0, 255).astype(np.uint8)
```

**Запуск:**

```bash
python cli.py -f gray -i photo.jpg -o out.jpg
```

---

### 3. Antique — фотоэффект «антиквариат»

**Математика.** Классическая формула сепии — линейное преобразование каналов:

```
R_new = 0.393 * R + 0.769 * G + 0.189 * B
G_new = 0.349 * R + 0.686 * G + 0.168 * B
B_new = 0.272 * R + 0.534 * G + 0.131 * B
```

Формула усиливает красный канал и ослабляет синий — получается тёплый
желтовато-коричневый тон.

Для регулировки силы эффекта используется линейная интерполяция:

```
result = original * (1 - intensity) + sepia * intensity
```

**Запуск:**

```bash
python cli.py -f antique -i photo.jpg -o out.jpg --intensity 0.7
```

---

### 4. Fade Color — выцветание

**Математика.** Два шага:

**Шаг 1. Снижение контраста** — «подтягивание» к среднему серому (128):

```
pixel_new = 128 + (pixel - 128) * contrast
```

где `contrast = 1.0 - intensity * 0.7`.

**Шаг 2. Подмешивание светлого тона** (цвет «пыли», например BGR `[200, 220, 240]`):

```
result = pixel_new * (1 - fade) + fade_color * fade
```

где `fade = intensity * 0.5`.

**Запуск:**

```bash
python cli.py -f fade -i photo.jpg -o out.jpg --intensity 0.5
```

---

### 5. Film — имитация инфракрасной плёнки

**Математика.** Три шага:

**Шаг 1. Цветовой сдвиг** — усиление красного, ослабление синего:

```
R_new = R * (1.0 + 0.30 * k)
G_new = G * (1.0 - 0.30 * k)
B_new = B * (1.0 - 0.50 * k)
```

где `k = intensity`.

**Шаг 2. Зернистость.** Добавление нормально распределённого шума:

```
noise ~ N(0, σ²),  σ = 12 * k
result = result + noise
```

Нормальное распределение выбрано потому, что оно физически достоверно:
сумма множества мелких случайных событий (зёрен галогенида серебра) даёт
именно колоколообразную кривую. 68% значений попадают в `±σ`, 95% — в `±2σ`,
99.7% — в `±3σ`.

**Шаг 3. Снижение контраста:**

```
result = 128 + (result - 128) * (1 - 0.1 * k)
```

**Запуск:**

```bash
python cli.py -f film -i photo.jpg -o out.jpg --intensity 1.0
```

### 6. Matte — овальная маска с белыми краями

**Математика.** Строим нормированное расстояние от центра до каждого пикселя:

```
dist = sqrt(((x - cx) / a)² + ((y - cy) / b)²)
```

где `(cx, cy)` — центр изображения, `a = cx * (1 - border)`, `b = cy * (1 - border)` —
полуоси эллипса.

* `dist = 0` в центре,
* `dist = 1` на границе эллипса,
* `dist > 1` снаружи.

Маска: `mask = (1 - clip(dist, 0, 1)) ** 2`.

* В центре `mask ≈ 1` (изображение сохраняется).
* На границе `mask = 0` (белый).

Возведение в квадрат делает переход **мягче**: значения близко к 1 остаются
высокими, а близко к 0 — быстро падают.

Финальное смешивание с белым:

```
white_amount = (1 - mask) * intensity
result = image * (1 - white_amount) + white * white_amount
```

**Параметры:**
* `--intensity` — сила выбеливания (0 — выкл, 1 — полный белый).
* `--border` — размер отступа (0.05 — большой овал, 0.35 — маленький).

**Запуск:**

```bash
python cli.py -f matte -i photo.jpg -o out.jpg --border 0.15 --intensity 0.5
```

### 7. Scratches — царапины и шум

**Математика.** Два шага:

**Шаг 1. Генерация царапин.** Для каждой из `count` царапин:
* случайная позиция `x` по горизонтали,
* случайные начало `y_start` и конец `y_end` по вертикали (царапина пересекает середину),
* случайный цвет: 70% — белый, 30% — чёрный,
* случайная толщина 1–2 пикселя.

Закрашиваем прямоугольник `img[y_start:y_end, x_min:x_max]`.

**Шаг 2. Зернистость.** Добавляем нормальный шум с `σ = 8 * intensity`.

**Шаг 3. Смешивание с оригиналом:**

```
result = original * (1 - intensity) + damaged * intensity
```

**Запуск:**

```bash
python cli.py -f scratches -i photo.jpg -o out.jpg --intensity 0.7
```

### 8. Neon — неоновый эффект

**Математика.** Четыре шага:

**Шаг 1. Grayscale.** По формуле BT.601 (см. фильтр 2).

**Шаг 2. Свёртка с ядром Собеля.** Ядро Собеля для горизонтальных границ:

```
Gx = [[-1,  0, +1],
      [-2,  0, +2],
      [-1,  0, +1]]
```

Для вертикальных:

```
Gy = [[-1, -2, -1],
      [ 0,  0,  0],
      [+1, +2, +1]]
```

Свёртка — операция, при которой к каждому пикселю применяется ядро 3×3:
берётся окрестность, поэлементно умножается на ядро и суммируется.

**Шаг 3. Величина градиента:**

```
magnitude = sqrt(Gx² + Gy²)
```

Большие значения → границы объектов.

**Шаг 4. Порог и подсветка.** Оставляем только сильные границы:

```
edges = magnitude > threshold
```

Формируем тёмный фон и накладываем контуры:

```
background = image * 0.15
result = background + edges * neon_color * intensity
```

**Параметры:**
* `--threshold` — порог выделения (больше — меньше контуров).
* `--intensity` — яркость неона.

**Запуск:**

```bash
python cli.py -f neon -i photo.jpg -o out.jpg --threshold 50
```

## Технические детали

### Типы данных

OpenCV хранит изображения в `uint8` (0…255). При арифметике с дробными
коэффициентами `uint8` может переполниться.
Поэтому **все фильтры** временно переводят `uint8` в `float32`, а в конце:

```python
result = np.clip(result, 0, 255).astype(np.uint8)
```

### Порядок каналов

OpenCV использует **BGR**, а не RGB. Поэтому во всех фильтрах:
* `image[:, :, 0]` — синий,
* `image[:, :, 1]` — зелёный,
* `image[:, :, 2]` — красный.

### Ограничения

* `cv2.resize`, `cv2.cvtColor`, `cv2.filter2D` и другие высокоуровневые
  функции **не используются**.
* Все операции — базовые над массивами NumPy (срезы, broadcasting, clip).
