# Практическая работа №1. Обработка изображений с использованием OpenCV

В лабораторной работе реализован набор фильтров для обработки изображений с использованием Python, NumPy и OpenCV.

Основные операции реализованы с помощью поэлементных и матричных операций над массивами NumPy. Высокоуровневые функции OpenCV для реализации самих фильтров (`cv2.resize()`, `cv2.cvtColor()`, `cv2.Sobel()` и аналогичные) не используются. OpenCV применяется только для чтения и сохранения изображений.

## Запуск

Программа запускается из каталога `1_ImageProcessing`:

```bash
python main.py -f <фильтр> -i <входное_изображение> -o <выходное_изображение>
```

Основные параметры:

* `-f`, `--filter` — тип применяемого фильтра;
* `-i`, `--input` — путь к исходному изображению;
* `-o`, `--output` — путь для сохранения результата.

Для некоторых фильтров предусмотрены дополнительные параметры.

## Реализованные фильтры

### 1. Изменение разрешения

Для изменения размера используется интерполяция методом ближайшего соседа (Nearest Neighbor).

Пусть исходное изображение имеет ширину `W` и высоту `H`, а результирующее — ширину `W′` и высоту `H′`.

Для каждого пикселя нового изображения `(x′, y′)` соответствующий пиксель исходного изображения определяется так:

```text
x = ⌊ x′ · W / W′ ⌋
y = ⌊ y′ · H / H′ ⌋
```

Полученное значение используется как значение пикселя нового изображения.

В реализации индексы вычисляются сразу для всех строк и столбцов, после чего формируется результирующая матрица NumPy.

---

### 2. Перевод изображения в оттенки серого

OpenCV хранит цветное изображение в порядке каналов BGR.

Яркость пикселя вычисляется как взвешенная сумма каналов:

```text
Y = 0.114·B + 0.587·G + 0.299·R
```

Коэффициенты учитывают различную чувствительность человеческого глаза к разным цветам.

Результат — одноканальное изображение со значениями от 0 до 255.

---

### 3. Эффект «Антиквариат»

Для получения эффекта сепии выполняется линейное преобразование цветовых каналов:

```text
R′ = 0.393·R + 0.769·G + 0.189·B
G′ = 0.349·R + 0.686·G + 0.168·B
B′ = 0.272·R + 0.534·G + 0.131·B
```

То же самое в матричной форме:

```text
┌ R′ ┐   ┌ 0.393  0.769  0.189 ┐   ┌ R ┐
│ G′ │ = │ 0.349  0.686  0.168 │ · │ G │
└ B′ ┘   └ 0.272  0.534  0.131 ┘   └ B ┘
```

После преобразования значения ограничиваются диапазоном:

```text
0 ≤ R′, G′, B′ ≤ 255
```

Это даёт характерный коричнево-жёлтый оттенок старой фотографии.

---

### 4. Эффект выцветания

Выцветание реализуется как линейная интерполяция между исходным изображением и белым цветом. Для каждого значения канала:

```text
I_out = α · I_in + (1 − α) · 255
```

где:

* `I_in` — исходное значение канала;
* `I_out` — новое значение канала;
* `α` — коэффициент сохранения исходного изображения (от 0 до 1).

При `α = 1` изображение не изменяется. При уменьшении `α` изображение становится светлее и приближается к белому.

---

### 5. Имитация плёнки

Для плёночного эффекта выполняется преобразование цветовых каналов:

```text
R′ = clip(1.6·G + 0.4·R, 0, 255)
G′ = clip(0.3·G + 0.2·B, 0, 255)
B′ = clip(0.8·B,         0, 255)
```

Функция `clip` ограничивает значения диапазоном `[0, 255]`.

Преобразование меняет соотношение каналов и создаёт выраженный плёночный / инфракрасный визуальный эффект.

---

### 6. Эффект Matte

Для создания белой овальной рамки используется эллиптическая маска.

Центр изображения — `(cx, cy)`. Для каждого пикселя вычисляется нормированное расстояние до центра:

```text
D(x, y) = (x − cx)² / a²  +  (y − cy)² / b²
```

Полуоси эллипса:

```text
a = 0.85 · cx
b = 0.85 · cy
```

Для плавного перехода к белому цвету используется маска:

```text
M(x, y) = clip( (D(x, y) − 0.7) / 0.3,  0,  1 )
```

Итоговое значение пикселя:

```text
I_out(x, y) = I_in(x, y) · (1 − M(x, y)) + 255 · M(x, y)
```

В центре изображения `M` близка к нулю, поэтому исходное изображение сохраняется. У краёв `M` приближается к единице, и изображение становится белым.

---

### 7. Царапины и шум

Фильтр состоит из двух частей.

#### Импульсный шум

Количество случайных шумовых пикселей:

```text
N = ⌊ r · H · W ⌋
```

где:

* `r` — коэффициент шума;
* `H` — высота изображения;
* `W` — ширина изображения.

Для выбранных случайных координат значение пикселя заменяется на белое (`255`).

#### Царапины

Дополнительно генерируется заданное количество случайных линий. Для каждой царапины выбираются:

* начальные координаты `x0`, `y0`;
* длина `L`;
* небольшое горизонтальное смещение `Δx`.

Координата `x` вдоль царапины изменяется линейно:

```text
x(y) = x0 + (y − y0) · Δx / L
```

Полученные пиксели заменяются на светлые значения, что создаёт эффект повреждённой старой фотографии.

---

### 8. Неоновый эффект

Сначала цветное изображение преобразуется в яркость:

```text
Y = 0.114·B + 0.587·G + 0.299·R
```

Для обнаружения границ используется оператор Собеля.

Горизонтальное ядро `Kx`:

```text
┌ −1   0   1 ┐
│ −2   0   2 │
└ −1   0   1 ┘
```

Вертикальное ядро `Ky`:

```text
┌ −1  −2  −1 ┐
│  0   0   0 │
└  1   2   1 ┘
```

Компоненты градиента вычисляются двумерной свёрткой (`*` — свёртка):

```text
Gx = Y * Kx
Gy = Y * Ky
```

Модуль градиента:

```text
G = √( Gx² + Gy² )
```

Полученная величина используется как интенсивность контура. Затем она распределяется по трём цветовым каналам с разными коэффициентами, благодаря чему контуры получают неоновую окраску.

Свёртка реализована средствами NumPy (циклы по элементам ядра), без вызова готовой функции Sobel из OpenCV.
