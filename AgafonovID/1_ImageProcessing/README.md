# Практическая работа №1. Обработка изображений с использованием OpenCV

В лабораторной работе реализован набор фильтров для обработки изображений с использованием Python, NumPy и OpenCV.

Основные операции реализованы с помощью поэлементных и матричных операций над массивами NumPy. Высокоуровневые функции OpenCV для реализации самих фильтров (`cv2.resize()`, `cv2.cvtColor()`, `cv2.Sobel()` и аналогичные) не используются. OpenCV применяется только для чтения и сохранения изображений.

## Запуск

Программа запускается из `1_ImageProcessing`:

```bash
python main.py -f <фильтр> -i <входное_изображение> -o <выходное_изображение>
```

Основные параметры:

* `-f`, `--filter` — тип применяемого фильтра;
* `-i`, `--input` — путь к исходному изображению;
* `-o`, `--output` — путь для сохранения результата.

Дополнительные параметры:
* `--width`, `--height` — размеры результата для `resize`;
* `--alpha` — доля исходного изображения для `fade` (от 0 до 1);
* `--radius` — радиус овальной маски для `matte` (от 0 до 1);
* `--noise-ratio`, `--num-lines` — доля шумовых пикселей и число царапин для `scratches`.

## Реализованные фильтры

### 1. Изменение разрешения

Для изменения размера используется интерполяция методом ближайшего соседа (Nearest Neighbor).

Пусть исходное изображение имеет ширину `W` и высоту `H`, а результирующее — ширину `W′` и высоту `H′`.

Для каждого пикселя нового изображения `(x′, y′)` соответствующий пиксель исходного изображения определяется так:

```text
x = ⌊ x′ · W / W′ ⌋
y = ⌊ y′ · H / H′ ⌋
```

Полученное значение используется как значение пикселя нового изображения.

В реализации индексы вычисляются сразу для всех строк и столбцов, после чего формируется результирующая матрица NumPy.

---

### 2. Перевод изображения в оттенки серого

OpenCV хранит цветное изображение в порядке каналов BGR.

Яркость пикселя вычисляется как взвешенная сумма каналов:

```text
Y = 0.114·B + 0.587·G + 0.299·R
```

Коэффициенты учитывают различную чувствительность человеческого глаза к разным цветам.

Результат — одноканальное изображение со значениями от 0 до 255.

---

### 3. Эффект «Антиквариат»

Для получения эффекта сепии выполняется линейное преобразование цветовых каналов:

```text
R′ = 0.393·R + 0.769·G + 0.189·B
G′ = 0.349·R + 0.686·G + 0.168·B
B′ = 0.272·R + 0.534·G + 0.131·B
```

То же самое в матричной форме:

```text
┌ R′ ┐   ┌ 0.393  0.769  0.189 ┐   ┌ R ┐
│ G′ │ = │ 0.349  0.686  0.168 │ · │ G │
└ B′ ┘   └ 0.272  0.534  0.131 ┘   └ B ┘
```

После преобразования значения ограничиваются диапазоном:

```text
0 ≤ R′, G′, B′ ≤ 255
```

Это даёт характерный коричнево-жёлтый оттенок старой фотографии.

Дополнительно накладывается небольшая виньетка: центр остаётся ярким, а края затемняются. Нормированное расстояние от центра:

```text
r(x, y) = √( ((x − cx)/cx)² + ((y − cy)/cy)² ) / √2      (0 ≤ r ≤ 1)
```

Коэффициент яркости:

```text
V(r) = 1 + g₀·(1 − r) − s·r²
```

где `g₀ = 0.08` — небольшое усиление центра, `s = 0.35` — сила виньетки. Итоговое значение:

```text
I_out = I_sepia · V(r)
```

---

### 4. Эффект выцветания

Выцветание реализуется как линейная интерполяция между исходным изображением и белым цветом. Для каждого значения канала:

```text
I_out = α · I_in + (1 − α) · 255
```

где:

* `I_in` — исходное значение канала;
* `I_out` — новое значение канала;
* `α` — коэффициент сохранения исходного изображения (от 0 до 1).

При `α = 1` изображение не изменяется. При уменьшении `α` изображение становится светлее и приближается к белому.

---

### 5. Имитация плёнки

Реализуется имитация инфракрасной плёнки с ложными цветами (эффект Вуда / Aerochrome). В инфракрасном диапазоне растительность отражает много ИК-излучения и выглядит яркой, а небо — тёмным.

Сначала строится вегетационный индекс, который служит прокси ближнего ИК-канала:

```text
V = 2·G − R − B
```

Затем он масштабируется в диапазон `[0, 255]`:

```text
IR = clip( 128 + k·V, 0, 255 )
```

где `k = 4.0` — усиление.

Ложный цвет формируется переносом ИК-канала в красный канал:

```text
R′ = IR
G′ = clip(0.35·R, 0, 255)
B′ = clip(0.60·B, 0, 255)
```

В результате растительность приобретает яркий красно-пурпурный оттенок, а небо становится тёмно-синим — характерная палитра инфракрасной плёнки.

---

### 6. Эффект Matte

Для создания белой овальной рамки используется эллиптическая маска.

Центр изображения — `(cx, cy)`. Для каждого пикселя вычисляется нормированное расстояние до центра:

```text
D(x, y) = (x − cx)² / a²  +  (y − cy)² / b²
```

Полуоси эллипса задаются параметром радиуса `ρ` (по умолчанию `ρ = 0.85`, диапазон `0..1`):

```text
a = ρ · cx
b = ρ · cy
```

Для плавного перехода к белому цвету используется маска:

```text
M(x, y) = clip( (D(x, y) − 0.7) / 0.3,  0,  1 )
```

Итоговое значение пикселя:

```text
I_out(x, y) = I_in(x, y) · (1 − M(x, y)) + 255 · M(x, y)
```

В центре изображения `M` близка к нулю, поэтому исходное изображение сохраняется. У краёв `M` приближается к единице, и изображение становится чистым белым (`255`). Параметр `--radius` управляет размером овала: меньше `ρ` — больше белых полей, больше `ρ` — шире сохраняемая область.

---

### 7. Царапины и шум

Фильтр состоит из двух частей.

#### Импульсный шум

Количество случайных шумовых пикселей:

```text
N = ⌊ r · H · W ⌋
```

где:

* `r` — коэффициент шума;
* `H` — высота изображения;
* `W` — ширина изображения.

Для выбранных случайных координат выполняется полупрозрачное смешивание с тоном `t` из диапазона `120..225`:

```text
I_out = 0.5 · I_in + 0.5 · t
```

Это даёт мягкое зерно/пыль без «выжигания» пикселей.

#### Царапины

Генерируется заданное количество царапин. Чтобы не было прямых ярких линий, каждая царапина:

* слегка изогнута (синусоидальное отклонение вдоль перпендикуляра);
* прерывистая (часть точек пропускается);
* полупрозрачная и неяркая (тон `170..220`, коэффициент смешивания `α = 0.25..0.5`).

Параметрическое задание линии (`t ∈ [0, 1]`):

```text
x(t) = x0 + L·t·cos θ + β·sin(πt)·(−sin θ)
y(t) = y0 + L·t·sin θ + β·sin(πt)·( cos θ)
```

где `θ` — случайный угол, `L` — длина, `β` — амплитуда изгиба (до `0.12·L`). Смешивание выполняется по формуле:

```text
I_out = (1 − α)·I_in + α·t
```

Параметры `--noise-ratio` и `--num-lines` задают долю шумовых пикселей и число царапин.

### 8. Неоновый эффект

Сначала цветное изображение преобразуется в яркость:

```text
Y = 0.114·B + 0.587·G + 0.299·R
```

Для обнаружения границ используется оператор Собеля.

Горизонтальное ядро `Kx`:

```text
┌ −1   0   1 ┐
│ −2   0   2 │
└ −1   0   1 ┘
```

Вертикальное ядро `Ky`:

```text
┌ −1  −2  −1 ┐
│  0   0   0 │
└  1   2   1 ┘
```

Компоненты градиента вычисляются двумерной свёрткой (`*` — свёртка):

```text
Gx = Y * Kx
Gy = Y * Ky
```

Модуль градиента:

```text
G = √( Gx² + Gy² )
```

Модуль градиента нормируется, после чего к нему применяется степенная кривая, оставляющая свечение только на сильных контурах:

```text
E = ( clip(G / 4, 0, 255) / 255 )^1.6
```

Для мягкого свечения к контурам добавляется их размытие (ядро 3×3):

```text
E_glow = E + 0.7 · (E * K_box)
```

Неоновый цвет задаётся в порядке BGR (циан) и масштабируется интенсивностью контура:

```text
glow_B = 1.00 · E_glow · 255 · k
glow_G = 0.80 · E_glow · 255 · k
glow_R = 0.20 · E_glow · 255 · k
```

где `k = 1.5` — усиление свечения.

Ключевое отличие: свечение **накладывается на исходное изображение**, а не на чёрный фон:

```text
I_out = clip(I_in + glow, 0, 255)
```

Свёртка реализована средствами NumPy (циклы по элементам ядра), без вызова готовой функции Sobel из OpenCV.
